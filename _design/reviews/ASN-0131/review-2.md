## Revision list

1. **`[DEFECT]` — The content-subspace caller obligation (`W ⊆ s_C`) is missing entirely, and the retraction claims silently depend on it.** *Design commitments* and *What must be built → region resolver* never state that the region must lie in the content subspace (`∀ v ∈ W : subspace(v) = s_C`), that this yields `I ⊆ dom(Σ.C)` (S3★), and that the operation **does not check it** (a deliberate caller-obligation/common-case-fast contract the note dedicates a paragraph to). This is not cosmetic: the digest's retraction reasoning asserts the from-set/to-set are "content-disjoint **unconditionally**" and that retraction is "net-removal-only" — but per the note (RE-RET) those hold *because* `I ⊆ dom(Σ.C)`, i.e. *because* `W ⊆ s_C`. With the premise unstated, those guarantees are unmoored. **Do this:** add the obligation to *Design commitments*; state it's unenforced by the operation; note it is the premise the from/to-set disjointness and net-removal claims rest on; and add that link-subspace regions are **out of scope (Open Question 7)** — green accepts them but returns an *empty* result rather than crashing (Q3), so a builder must either trust the caller or document the empty/undefined behavior.

2. **`[SHARPENING]` — Tie the shared index (touching spans) to the whole-endset enumerator (whole endset) at the point Option B is recommended.** *What must be built* specifies the enumerator to produce "every `(slot, endset)`" — the *whole* endset (RE-WHOLE / RE-DEF's `e = Σ.L(a).eᵢ`). But Option B (spanfilade-style index, queried by region image) yields only the *touching* spans, one per matching crum. The divergence is flagged later in *Decisions*, but a builder picking Option B for the enumerator could believe it satisfies the adopted convention. Make explicit, where Option B is proposed: the shared index delivers the touching-spans reading; honoring RE-WHOLE requires an *additional* gather of the link's remaining `(link, slot)` spans.

3. **`[SHARPENING]` — Surface the degenerate cases (RE-BND) explicitly.** The digest never lists them. Add a short line: empty image (`W ∩ dom(Σ.M(d)) = ∅`, e.g. a freshly-registered document) ⇒ `∅`; no addressable links ⇒ `∅`; and an *empty* from/to endset slot is never surfaced (`coverage(∅) = ∅`; only the type slot is required non-empty, L3). These fall out of the touch test, but the empty-from/to-slot fact is a real builder gotcha worth stating.
