## Revision list

**1. "What must be built" (span value bullet): drop "enforce level-uniformity" from the constructor — it over-states the note and contradicts the digest's own Guarantees section.** The note exhibits `([1,3,5],[0,2])` as a *valid span*: it satisfies T12 (width `[0,2] > 0`, action point `k=2 ≤ #start=3`) but is **not** level-uniform (`#s=3 ≠ #ℓ=2`). The note makes level-uniformity a precondition on construction *operations* (and the Gregory split aborts at the *operation*, Q14/Q15), never a condition of span existence — it needs the value to be representable to use it as the width-recovery cautionary example. This also contradicts the Guarantees section, which correctly gates level "at the boundary." Fix: the span constructor enforces **T12** (positive width + action point ≤ #start); level-*compatibility* is intrinsically pairwise and is enforced at the operation gate; making level-*uniformity* a span-type invariant is a defensible builder *choice*, not a forced requirement — present it as such or push it to the gate.

**2. "Implementation approaches" (pairwise engine): merge's guard is a single comparison, not the full classifier.** The digest correctly isolates intersection as self-guarding, then says merge "must be gated by classification." Merge needs only `max start ≤ min reach` (separated ⟺ `max start > min reach`; adjacent ⟺ `=`; overlapping ⟺ `<`) — detecting case (i) alone. Full five-way SC is required only for *difference* (S11d dispatches every case). State this so the cheapest mechanism is visible: merge = one comparison + `WF(min start, max reach)`; reserve the full classifier for difference. This completes the digest's own analytical move (it already distinguished intersection) and matches the Lampson cheapest-mechanism discipline the section invokes.

**3. "CRDT/S10" + "Decisions": scope the join to a single tumbler level.** S10's hypothesis is "level-uniform and mutually level-compatible *across all sets*." The coordination-free union therefore forms a join-semilattice only *within one shared tumbler length*; differently-leveled span-sets are outside S10 and must not be folded into the commutative merge. The digest caveats "union-only, not difference" but omits this level-scope caveat — add it, or a builder will over-generalize the parallel-accumulation claim. (Minor, same paragraph: idempotence is a correct inference but is *not* literally in S10, which states only commutativity/associativity — mark it derived.)

**4. Surface the forced rationale that difference is *why* span-sets are a first-class type.** The note proves (S11 tightness, via convexity S0) that a containment difference is *irreducible* to a single span, and states "the system provides span-sets precisely for representing such non-contiguous remainders." The digest lists span-sets as a component and bounds difference ≤2 but never connects them: the span-set type is not a convenience collection, it is *forced* because no single span can represent a two-span remainder. Add this to Design commitments — it tells the builder the span-set type is non-negotiable and why.

**5. "Normalization" sites: attribute the "insertion/emission" gloss as inference.** The note labels the two merge sites "enfilade-level" (`isanextensionnd`) and "output-level" (`putvspaninlist`) and says both enforce adjacency/overlap conditions; it does **not** characterize them as running "during structural insertion" and "at emission." Either fall back to the note's own "enfilade-level / output-level" labels or mark the insertion/emission reading as the digest's interpretation, so it isn't taken as note-grounded.

**6. "Decisions for the builder": add the pairwise return-shape decision and the strict-interior split precondition.** (a) Intersection fans out to ≤1 and difference to ≤2 — the builder must decide whether all pairwise ops return a *uniform span-set* or a sum type (`None | One | Two`); the digest implies the fan-outs but never raises the choice. (b) Split's cut must be *strictly* interior (`start < p < reach`, per the note's InteriorPoint definition); `p = start` or `p = reach` yields a zero-width part — the forbidden empty-span state. State this precondition next to the empty-designation guarantee.

**7. (Minor) S7 commitment: note the worst-case covering cost `|Σ| = |P|`.** The digest captures "cover, not represent exactly" but not the size: covering a scattered finite target can cost one span per position, with no compression guarantee. Half a line in the S7 commitment so a builder covering populated positions isn't surprised.
