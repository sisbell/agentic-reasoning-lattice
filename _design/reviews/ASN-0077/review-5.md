## Revision list

1. **"Design commitments → Transclusion": `any link is an equally good witness` is ambiguous in a domain where "link" is a first-class object (`dom(L)`).** `[SHARPENING]` O4's witnesses are the *documents* d₂…dₙ whose arrangements record the shared I-address — not link objects. The intended reading ("any link *of the chain*") is correct, but in a digest that elsewhere meticulously separates the content and link subspaces, this collides with Xanadu's `dom(L)`. Replace with "any document (transcluder) in the chain is an equally good witness."

2. **"Permanence / recovery": the "no address reuse" half of the permanence basis is mis-cited to (P0/P3).** `[SHARPENING]` P0/P3 give *non-removal* (`dom(C) ⊆ dom(C')`); they do not state "no reuse." The note's O5 actually derives permanence from **P3 (membership preservation) + O3 (origin is a pure projection of the address)** — value-stability comes from purity, not from a non-reuse axiom. The "distinct allocations ⇒ distinct addresses" guarantee that makes the answer *meaningful* is OriginBasedIdentity (S4, ASN-0036), which the digest already invokes implicitly elsewhere (O9). Tighten to "permanence = addresses persist (P0/P3) + origin is a function of the address (O3); never reuse a content address (S4) keeps the answer meaningful." The engineering takeaway is sound; only the attribution is loose.

3. **"Design commitments" vs. "Guarantees": `authoritative` is used in two senses.** `[SHARPENING]` The commitments say an index need "not be non-authoritative"; the guarantees say derivability "breaks the moment an index is treated as authoritative and allowed to disagree." These reconcile (a trusted-but-reconciled index is fine; a diverging one is not), but the surface contradiction is avoidable. Unify the wording: an index may serve as the *primary lookup* provided it stays reconciled to the projection (address wins on conflict); it breaks only if allowed to *diverge*.

Sections that are solid and should not be touched: the forced/conventional taxonomy; the WF_V admissibility treatment (including the derived-not-tested single-subspace confinement and the empty-document vs. empty-intersection asymmetry); the granfilade boundary-walk's `dom(C)` filter (correctly grounded in K.λ allocating links in the same granfilade, Q2/Q12); the Q19 versioning clarification; and the V-span three-way edit contract.
