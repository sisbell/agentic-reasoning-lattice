## Review of Design Digest — ASN-0084

This is a strong digest: accurate to the note, properly grounded, and committal where the note supports a position. The forced/conventional split is correct (content-immutability, relabeling/bijection, two-shapes, depth-2 scope, partiality all genuinely forced; run-partition-as-storage correctly demoted to conventional). The Green evidence is used exactly as intended — as a cautionary contrast (subspace-blind corruption, response-before-check, `abort()` on straddling cut) and a confirmation of depth-2 V-layout — with no fabricated source-level claims. The central recommendation (structural splice on implicit positions; displacement formulas as *oracle*, not algorithm) is the right Lampson call and is internally consistent with the per-subspace-storage and confinement recommendations. The derived run-count bound `|Δ| ≤ n` is **sound** (I checked it: `Δ = #splits − #seam-merges`, both in `[0,n]`; the no-cascade argument via (a)/(b) holds, and `Δ = +n` is achievable), and it is correctly flagged as beyond-note. R-RI → "membership reverse index is rearrange-invariant" is a genuine, correct design lever.

I found no material defects. Three non-load-bearing sharpenings:

1. **`The arrangement map` (absolute-vs-implicit) — `[SHARPENING]`** The parenthetical "the note's entire Displacement Analysis (forward by `w_β`, backward by `w_α + w_μ`, the μ sub-cases)" silently mixes a *3-cut* term (α forward by `w_β`) with a *4-cut* term (β backward by `w_α + w_μ`) — no single form has both (3-cut β is backward by `w_α`; 4-cut α is forward by `w_β + w_μ`). Both terms are true, so this is not wrong, but since this is the one section a builder who *chooses* absolute-V-starts will mine for arithmetic, label each term by form (or present the two per-form displacement sets cleanly) so it cannot be read as one form's displacements.

2. **`Canonicalization` (run-count bound) — `[SHARPENING]`** The closing step writes "`#seam-merges ≤ #seams = n`," but the digest itself says "≤ `n` region seams" one clause earlier — empty exteriors yield fewer than `n` seams. The bound `|Δ| ≤ n` is unaffected (it only needs `#seam-merges ≤ n`), but state it consistently as `≤ n` rather than `= n` to avoid overstating the seam count in the boundary configurations the digest elsewhere takes care to handle (the empty-exterior worked example).

3. **`What must be built` (validator) — `[SHARPENING]`** "`V_S(d) ≠ ∅` (ii, in fact subsumed by coverage given CS5)" — the redundancy is real (`c₀ ∈ V_S(d)` follows, so `V_S(d) ≠ ∅`), but the derivation leans on CS2 (for `c₀ < c_last`) and CS3/CS4 (for `c₀` being a depth-2 S-position) as much as on CS5 (which only supplies positivity). Either tighten to "subsumed by coverage together with CS2–CS5" or drop the singling-out of CS5.

Sections that are genuinely solid and need no change: the `Guarantees to uphold` table (every by-construction-vs-active-enforcement call is correct, including the subtle one — canonical *meaning* is free, canonical *representation* needs active merge); `Subspace confinement` (correct Lampson "put the function where it belongs," correctly tied to the implicit-position decision as one knob, not two); `Cut validation and atomicity` (the `V_S(d) = {[1,1]}` counterexample correctly demonstrates coverage is load-bearing for width-positivity); and `How it fits` (dependency attributions to ASN-0036/0034 are all note-supported).
