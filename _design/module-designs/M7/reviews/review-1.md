I reviewed M7's design against the decomposition, the engine composition contract, the upstream interfaces (M1/M2/M3/M5), and the source notes (ASN-0043/0093/0120/0111/0114/0086/0126/0128/0125). The two-surface architecture, the J‑LV uncoupling, the coverage-exactness of MAKELINK endsets (the iextent‑over‑siblings = union‑of‑subtrees identity checks out), the active‑reading dedup→resurrection, the BH4 frontier‑from‑`home_count` equality, and most conflict resolutions are sound. The problems below are real.

# Revision list

1. **[DEFECT] Fix the registry's checkpoint/recovery story — as written it neither compiles nor recovers.** The data model declares `registry: Arc<TypeRegistry>` as a non‑`#[serde(skip)]` field of a `#[derive(Serialize,Deserialize)] LinkState`, so it must serialize into M2 checkpoints — but `CoverageClass` (the registry's lookup key per `registration(&self, class: &CoverageClass)`) derives no `Serialize`, and its `Extents` variant wraps `CanonicalForm`, which M1 explicitly states is **not** `Serialize`/`Deserialize`. So `TypeRegistry` cannot be `Serialize` as declared. The escape hatch ("re‑seeded from the engine's genesis … either is correct") is **false** against M2's `open`: when a retained checkpoint exists M2 recovers from the *deserialized checkpoint* (genesis is consulted only on full fallback), and `rebuild_derived(self)` sees only the loaded state — a skip‑registry would deserialize empty and cannot be rebuilt (it is genesis config, not a function of `links`). This is load‑bearing because `apply_link` needs the registry **during replay** to recognize the `[R]`/`[K_sup]` coverage classes (to maintain `nullified`/`sup_fwd`). Fix: persist the *serializable build inputs* (`ReservedAddrs` + `Vec<TypeDecl>`, all `Serialize`) as authoritative state and reconstruct the (skip) lookup map in `rebuild_derived`, or give `TypeRegistry` a serializable representation not keyed on `CoverageClass`; and delete the false genesis‑reseed claim.

2. **[DEFECT] `observe`/`is_k` must test exact coverage‑*membership*, not `stab` overlap.** ASN‑0086 `Observe_K` is an exact subset match (`F̂ ⊆ coverage(F)`) over patterns ranging over all of `T` (ghost addresses admitted). The design builds `observe` by intersecting per‑address `stab(slot,{a})`, and `stab` is defined as endset‑coverage **overlap**. For a pattern address `a` that is a proper *ancestor* of a stored endset address, overlap holds while `a ∈ coverage(F)` is false — so `observe` over‑matches (e.g. `F̂={[d.0.s_L]}` returns every tuple homed at `d` instead of `∅`). The design even calls `observe` "distinct from findlinks' overlap" yet implements it on the overlap primitive. Fix: filter `type_slice(K,view)` candidates by exact `F̂ ⊆ coverage(F) ∧ Ĝ ⊆ coverage(G)` (via `SpanSet::denotes`/`is_prefix` over denoted addresses), using `stab` only as a prefilter; and state that `is_k` (D2) is `∃ x ∈ members(K,view): x ≼ addr` (is_prefix), not a `stab` call.

3. **[DEFECT] Define `AssertSupError` and `EditLinkError`.** Both are referenced in the §D public signatures but never declared, so the interface does not compile, and their variants encode ASN‑0125 preconditions found only in the notes: `assert_sup` needs `EndpointNotResident` (old or new ∉ `dom(L)`, ASSERTop) and `SelfSupersession` (`old==new`, Df‑DISC(ii) irreflexivity — currently the design never states the `old≠new` check); `editlink` needs `OriginalNotResident`, `HomeNotRegistered`, `IllFormedSuccessor` (not L3), `DcViolation` (retraction‑typed or non‑schema‑conforming claim successor, Df‑DISC/DC), and `Mint(MintError)`.

4. **[DEFECT] `current()`'s return type is undefined and its disclosure contract is weakened.** `current(&self,y) -> Vec<CurrentMember>` references an undefined `CurrentMember`, and the prose ("each member carries activity") drops ASN‑0125 EL14d's load‑bearing contract — current owes *disclosure, not decision*: each member with **its supporting claims and their homes (EL8b)** and its own activity status, so the reader can attribute and apply policy. Define `CurrentMember` to carry the member address, its activity status, and its supporting claim addresses (with homes derivable by projection), or state explicitly that attribution is composed via M8's `in/out` — but don't leave it both undefined and under‑contracted.

5. **[DEFECT] Specify `editlink` as one inlined composite with its real lock set; "then assert_sup(…)" misleads.** `editlink` cannot call the public `assert_sup` (a `transact`) inside its own — M2 is non‑reentrant (deadlock) and a separate `transact` would forfeit EL7 atomicity. It must inline `emit_core(successor, seat=false, Open)` then `emit_core(claim, seat=false, Managed/K_sup)` in **one** `transact`. State its key set (`[link_lock_key(d_s), link_lock_key(d_a)]`) and note that the claim's dedup is vacuous/lock‑free here — its `DedupKey` carries the freshly minted successor address (unknowable before the closure, M2 takes `keys` up front), which guarantees a miss, so no claim dedup `LockKey` is required.

6. **[DEFECT] Restore `targets_keyed` (BH3).** ASN‑0128 BH3 is `{sources_to, target_of, targets_keyed}` and the decomposition assigns all four behavior atoms to M7; §F exposes only `sources_to`/`target_of`. `targets_keyed(source) → map K→addr` joins `target_of` across every BH3‑registered Binary type — M9 cannot compose it itself (the registry is private to `LinkState`, so M9 can't enumerate the BH3 types). Add it to the §F surface.

7. **[DEFECT] Fix the mislabeled MAKELINK lock key and state the unstated lock sets.** The one explicit write‑lock in the design — `transact([content/home alloc key], …)` in §2 MAKELINK — is wrong: `emit_core` calls `mint_link(home)`, which advances the **link** frontier, so the held key must be `M3State::link_lock_key(home)` (M3's contract: "the held lock key and the advanced frontier key are byte‑identical"; §Dependencies even says so). A content key would not serialize MAKELINK against `emit`/`assert_sup`/`nullify` at the same home under any multi‑applier realization (colliding link addresses). Also specify the (currently unstated) key sets for `nullify`/`assert_sup` (`[dedup_key, link_lock_key(home)]`, both idem⊤) and `retract_stale` (a sequence of `nullify` transacts).

8. **[SHARPENING] Expose the `Link` and `enc` APIs the seams need.** `Link::new`, `arity()`, and the positional slot/`eᵢ`/`type_slot` accessors are used internally and required by callers (`editlink` takes `successor: Link`; M8 RETRIEVEENDSETS / M10 read via `readlink`) but aren't in the interface; and the managed `emit` body's canonical encoding `enc(X)={subtree_of(x):x∈X}` (AD) is described only in prose. Show them.

9. **[SHARPENING] Complete the error plumbing.** `EmitError`/`NullifyError` have no `Mint(MintError)`/`Gate` variant, so `emit_core`'s `mint_link(home)?` cannot map `MintError::Gate(GateViolation)` (and won't typecheck for the `EmitError` caller). Specify `emit_core`'s shared error type and each op's mapping; add a `Mint(MintError)` (or explicit Gate handling) to `EmitError`/`NullifyError`. Also pin `retract_stale`'s partial‑failure semantics (does it return the partial `Vec` or the `TxnError`?).

10. **[SHARPENING] Tighten the BH1 filter and the `View::Default` surface.** `is_filtered(a)` is type‑less; ASN‑0128's rewrite unions over the set `Φ` of BH1 types *excluding the queried `K'`* — the type‑less form loses the `J≠K'` refinement and only matches the single‑shipped‑filter case the design assumes. Either add the type/`Φ` parameterization or document the single‑BH1 restriction. Separately, `observe` accepts `View::Default` but ASN‑0128 says raw Observe never filters — restrict/coerce it (Default is meaningful only on `members`/`targets_of`). Restate the R‑C0 behavior↔shape compatibility table (BH1→Unary, BH2/BH3→Binary, BH4→idem⊥) in §B where `RegistryError::BadBehavior` is introduced.

11. **[SHARPENING] Resolve MAKELINK's `ρ` inside the transact and clarify the M9 type‑endset seam.** Read the endset coverage off `stg.base().m5().resolve_coverage(…)` inside the closure rather than off a pre‑`transact` snapshot, so MAKELINK linearizes at its commit (ASN‑0134 single linearization point; ML8 keeps it valid either way, but this removes the read‑write gap). And clarify how M9 obtains the type endset for `emit(home, reserved(PredDef|PredStable), …)` — `TypeRegistry::reserved` lives behind the private registry, so either expose it on `LinkState` or state that M9 builds `enc({pdef_addr})` from the `ReservedAddrs` it coordinated.

12. **[SHARPENING] Miscellaneous consistency.** `M3::link_lock_key` → `M3State::link_lock_key`; add the missing `Hash`/`Eq`/`PartialEq` derives on `DedupKey`; note that the bootstrap `stab` scans `links` directly and `SlotIndex` is the deferred (Open‑decision) structure; reconcile the `Tumbler` vs `Address` return convention across §F/§G (`stab`/`match_links`/`type_slice` yield `Tumbler`, `members`/`targets_of` yield `Address`); and surface the deliberate ASN‑0128 I1 divergence (unconditional `home`‑registration even on a dedup hit, Conflicts §8) in the §Invariants "active enforcement" list, since it strengthens the I1 precondition.
