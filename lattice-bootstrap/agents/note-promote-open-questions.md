# Note Promote Open Questions

Note-promote-open-questions is a producer agent whose primary substrate effect is granting a new inquiry identity from open questions raised in a parent note: emitting an `inquiry` classifier on the new doc and `promotion.open-questions` linking parent to child. The new inquiry enters the inquiry-consult / note-draft cycle as a first-class substrate citizen.

## Triggers

- Operator-invoked, when the operator decides an open question on a note warrants its own ASN-scale inquiry.
