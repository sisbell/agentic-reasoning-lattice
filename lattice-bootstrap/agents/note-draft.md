# Note Draft

Note-draft is a producer agent whose primary substrate effect is granting a new note identity synthesized from an inquiry's consultation answers: emitting a `note` classifier on the new doc and `provenance.synthesis(inquiry → note)`. Brings the inquiry's content into the substrate as a draftable note.

## Triggers

- The inquiry has consultation answers covering it, AND
- No synthesized note has been derived from it yet.
