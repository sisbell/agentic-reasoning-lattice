Proves that every level-uniform, mutually level-compatible span-set has a normalized equivalent with the same coverage. The construction sorts spans by start position, then performs a single left-to-right scan that merges overlapping or adjacent spans into maximal intervals and emits each interval when a gap is detected, using a loop invariant to confirm that coverage is preserved throughout. Strict separation of emitted starts (N2) follows directly from the emit condition, and strict ordering of emitted starts (N1) follows because each new interval opens only beyond the previous interval's reach.
