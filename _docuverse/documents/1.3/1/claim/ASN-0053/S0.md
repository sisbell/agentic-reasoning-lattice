**S0 (Convexity).** `(A p, q, r : p ∈ ⟦σ⟧ ∧ r ∈ ⟦σ⟧ ∧ p ≤ q ≤ r : q ∈ ⟦σ⟧)`

*Proof.* By the half-open-interval Definition, p ∈ ⟦σ⟧ unfolds to start(σ) ≤ p < reach(σ) and r ∈ ⟦σ⟧ to start(σ) ≤ r < reach(σ), while the obligation q ∈ ⟦σ⟧ unfolds to start(σ) ≤ q ∧ q < reach(σ). We would like to chain start(σ) ≤ p ≤ q ≤ r < reach(σ) and read off start(σ) ≤ q < reach(σ) at a stroke; but T1 exports only the strict relation — its transitivity postcondition (c), `(A a, b, c ∈ T : a < b ∧ b < c : a < c)`, together with the abbreviation `a ≤ b ≡ a < b ∨ a = b`. The composition of two ≤-steps, and that of a ≤-step with a <-step, are consequences of these two, not citations of T1; we derive each by unfolding the abbreviation.

*Lower bound* start(σ) ≤ q. Compose start(σ) ≤ p (from p ∈ ⟦σ⟧) with p ≤ q (hypothesis). Unfolding both abbreviations distributes into four cases: if start(σ) < p ∧ p < q, postcondition (c) gives start(σ) < q; if start(σ) < p ∧ p = q, substituting q for p in start(σ) < p gives start(σ) < q; if start(σ) = p ∧ p < q, substituting start(σ) for p in p < q gives start(σ) < q; and if start(σ) = p ∧ p = q, transitivity of equality gives start(σ) = q. The first three cases yield start(σ) < q, the fourth start(σ) = q; in every case start(σ) < q ∨ start(σ) = q holds, which folds back to start(σ) ≤ q.

*Upper bound* q < reach(σ). Compose q ≤ r (hypothesis) with r < reach(σ) (from r ∈ ⟦σ⟧). Unfolding the abbreviation on q ≤ r distributes into two cases: if q < r, then with r < reach(σ) postcondition (c) gives q < reach(σ); if q = r, substituting q for r in r < reach(σ) gives q < reach(σ). Both cases yield q < reach(σ).

Conjoining the two bounds, start(σ) ≤ q ∧ q < reach(σ), which is q ∈ ⟦σ⟧ by the Definition.  ∎

This convexity rests solely on T1's strict order: the ≤-transitivity and the mixed ≤-< transitivity invoked above are not posited but derived from postcondition (c) and the abbreviation — the same four-case unfolding by which NAT-order records ≤-transitivity on ℕ as a named consequence. Every position between two members of a span is therefore itself a member; a span cannot "skip" a position. Sub-addresses like [1, 3, 0, 5] that fall numerically between [1, 3] and [1, 7] are genuinely interior to any span containing both endpoints, because `tumblercmp` compares tumblers lexicographically without treating zero-separators specially (Gregory, Q11).

*Formal Contract:*

- *Preconditions:* `p ∈ ⟦σ⟧ ∧ r ∈ ⟦σ⟧ ∧ p ≤ q ≤ r`
- *Postconditions:* `q ∈ ⟦σ⟧`
- *Definition:* span membership is the half-open interval over T1 addresses — `x ∈ ⟦σ⟧ ⟺ start(σ) ≤ x < reach(σ)`; and `≤` abbreviates T1's strict order, `a ≤ b ≡ a < b ∨ a = b`.
- *Axiom:* T1 exports the strict order `<` with its transitivity postcondition (c), `(A a, b, c ∈ T : a < b ∧ b < c : a < c)`. The non-strict compositions the proof needs — `start(σ) ≤ q` from `start(σ) ≤ p` and `p ≤ q`, and `q < reach(σ)` from `q ≤ r` and `r < reach(σ)` — are *not* T1 exports; each is derived in the proof by case analysis on the abbreviation, every case reducing to (c) or to substitution of equals.
- *Frame:* σ is fixed; the claim asserts closure of ⟦σ⟧ under betweenness with no state transition.

- *Depends:*
  - T1 (LexicographicOrder, ASN-0034) — supplies the strict order `<` on tumbler addresses, its transitivity postcondition (c), and the abbreviation `a ≤ b ≡ a < b ∨ a = b`. The proof composes the bracketing hypotheses into start(σ) ≤ q < reach(σ) by case analysis on the abbreviation, reducing each non-strict step to (c) or to substitution of equals; it does not cite a ≤-transitivity, which T1 does not export
