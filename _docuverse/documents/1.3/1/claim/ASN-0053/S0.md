**S0** (*Convexity*). `(A p, q, r : p ∈ ⟦σ⟧ ∧ r ∈ ⟦σ⟧ ∧ p ≤ q ≤ r : q ∈ ⟦σ⟧)`

*Proof.* If start(σ) ≤ p ≤ q ≤ r < reach(σ), then start(σ) ≤ q < reach(σ), so q ∈ ⟦σ⟧.  ∎

This follows solely from T1 being a total order. Every position between two members of a span is itself a member — a span cannot "skip" a position. Sub-addresses like [1, 3, 0, 5] that fall numerically between [1, 3] and [1, 7] are genuinely interior to any span containing both endpoints, because `tumblercmp` compares tumblers lexicographically without treating zero-separators specially (Gregory, Q11).

*Formal Contract:*

- *Preconditions:* `p ∈ ⟦σ⟧ ∧ r ∈ ⟦σ⟧ ∧ p ≤ q ≤ r`
- *Postconditions:* `q ∈ ⟦σ⟧`
- *Definition:* span membership is the half-open interval over T1 addresses — `x ∈ ⟦σ⟧ ⟺ start(σ) ≤ x < reach(σ)`.
- *Axiom:* `≤` on T1 addresses is a total order; in particular it is transitive, so `start(σ) ≤ p` and `p ≤ q` give `start(σ) ≤ q`, and `q ≤ r` with `r < reach(σ)` give `q < reach(σ)`.
- *Frame:* σ is fixed; the claim asserts closure of ⟦σ⟧ under betweenness with no state transition.

- *Depends:*
  - T1 (LexicographicOrder, ASN-0034) — supplies the strict total order on tumbler addresses; the proof invokes its transitivity to derive start(σ) ≤ q < reach(σ) from the bracketing inequalities, and the Axiom clause names T1's total-order property directly
