**S2 (EmptyDistinction).** The empty set of positions is not the denotation of any span. Every well-formed span denotes a non-empty set.

We are proving that the denotation map from spans to sets of positions never produces the empty set: for every well-formed span, the set of positions it denotes contains at least one element. Equivalently, ∅ has no preimage under denotation — there is no span whose meaning is "no positions."

Fix a well-formed span. By construction it is given by a start position s together with a length ℓ, and it denotes the half-open interval of positions

  ⟦s, ℓ⟧ = [s, s ⊕ ℓ) = { p : s ≤ p < s ⊕ ℓ },

where ⊕ advances a position by a length. Well-formedness imposes two conditions on this data, both preconditions of Definition (Span) — exactly the conditions T12 assumes: the length is strictly positive, Pos(ℓ) (i.e. ℓ > 0); and the span fits within the stream, actionPoint(ℓ) ≤ #s. This second condition is a comparison of natural numbers — actionPoint(ℓ) is the ℕ action point of the length — not of the end offset s ⊕ ℓ, which is a tumbler.

The argument has a single step. The set we must show non-empty is, by Definition (Span), span(s, ℓ) = { t : s ≤ t < s ⊕ ℓ } — precisely the denotation ⟦s, ℓ⟧ written above. Under the hypotheses just recorded, Pos(ℓ) and actionPoint(ℓ) ≤ #s, T12 (span well-definedness) establishes its postcondition (b), s ∈ span(s, ℓ). Hence

  s ∈ ⟦s, ℓ⟧,

with the start position itself the witness — T12 obtains s ∈ span(s, ℓ) from s ≤ s together with the strict advancement s < s ⊕ ℓ that a positive length forces. Therefore the denotation contains at least the position s, and so ⟦s, ℓ⟧ ≠ ∅. Since the span was an arbitrary well-formed span, no well-formed span denotes ∅. ∎

This is the distinction that matters downstream: when two disjoint spans are intersected, the result is "no span" — the empty set, which by the above is the denotation of no span at all — rather than a zero-width span. A zero-width span would require ℓ = 0, which well-formedness forbids — Pos(ℓ) is a precondition of every well-formed span; the empty intersection therefore falls outside the image of denotation entirely.

*Formal Contract:*

- *Definition:* A well-formed span (s, ℓ) denotes the half-open interval ⟦s, ℓ⟧ = [s, s ⊕ ℓ) = { p : s ≤ p < s ⊕ ℓ }, where s ⊕ ℓ is its (exclusive) end offset.
- *Preconditions:* The span is well-formed — the preconditions of Definition (Span), equivalently the preconditions of T12: ℓ ∈ T, Pos(ℓ) (i.e. ℓ > 0), and actionPoint(ℓ) ≤ #s. The last is a comparison of natural numbers (actionPoint(ℓ) ∈ ℕ), not the type-incoherent comparison of the tumbler s ⊕ ℓ against #s.
- *Postconditions:* ⟦s, ℓ⟧ ≠ ∅; concretely s ∈ ⟦s, ℓ⟧ — exactly T12's postcondition (b), s ∈ span(s, ℓ), read through the set equality ⟦s, ℓ⟧ = span(s, ℓ) — so the denotation has at least one position. Consequently ∅ is not in the image of the denotation map.

- *Depends:*
  - T12 (SpanWellDefinedness, ASN-0034) — supplies its postcondition (b), s ∈ span(s, ℓ). Since span(s, ℓ) = { t : s ≤ t < s ⊕ ℓ } is, by Definition (Span), the denotation ⟦s, ℓ⟧, this postcondition is exactly S2's conclusion: the denotation contains its start position and so is non-empty. T12 does not supply S2's preconditions — Pos(ℓ) (i.e. ℓ > 0) and actionPoint(ℓ) ≤ #s are S2's own hypotheses, the preconditions of Definition (Span) that T12 likewise assumes and from which T12 in turn derives (b) (via s ≤ s and the strict advancement s < s ⊕ ℓ a positive length forces).
