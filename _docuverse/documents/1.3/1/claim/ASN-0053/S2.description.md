Proves that the denotation map on well-formed spans never produces the empty set: every well-formed span contains at least its start position, because the strict-positivity axiom on lengths forces the end offset strictly past the start. As a consequence, the empty set lies entirely outside the image of denotation — the empty intersection of two disjoint spans is not a zero-width span but a set with no preimage, a distinction that prevents zero-length spans from contaminating downstream interval arithmetic.
