**subspace (VPositionSubspaceIdentifier).** A V-position carries its subspace identity in its own leading component; we make that reading explicit, naming the projection the arrangement-contiguity invariants downstream will range over. For any tumbler `v` of depth `1 ≤ #v`, define:

`subspace(v) = v₁`

extracting the subspace identifier as the first component of a V-position. Both symbols on the right-hand side are T0's (CarrierSetDefinition, ASN-0034): `#·` is T0's length operator `#· : T → ℕ`, and `v₁` is the value at index `1` of T0's component projection `i ↦ vᵢ : {j ∈ ℕ : 1 ≤ j ≤ #v} → ℕ`. We observe that this projection returns a component at index `1` exactly when `1` lies in its index domain `{j ∈ ℕ : 1 ≤ j ≤ #v}` — the `j = 1` instance of that domain's membership condition `1 ≤ j ≤ #v`, which reduces to `1 ≤ #v`. This is the depth guard the definition states, and writing it first-class commits us to its two symbols: the lower bound `1` is NAT-closure's `1 ∈ ℕ` and the relation `≤` is NAT-order's order on ℕ. T0 inscribes this same `1` and `≤` into its own index-domain template `{j ∈ ℕ : 1 ≤ j ≤ #v}` but grounds them through its own dependence on NAT-closure and NAT-order rather than exporting them as postconditions; so a consumer that writes the guard directly, as we do, must ground its `1` and `≤` from those two foundations itself, taking from T0 only the projection and the length operator T0 genuinely exports. So `subspace(v)` is well-defined precisely under that guard; and since T0's nonemptiness clause `(A a ∈ T :: 1 ≤ #a)` already forces `1 ≤ #v` for every `v ∈ T`, the read is total on the carrier. We introduce no structure of our own: `subspace` is T0's first-component projection under a name chosen for the role its value plays, so that subspace membership is a direct read of an address component rather than a lookup against any external structure.

*Formal Contract:*

- *Definition:* For any tumbler `v ∈ T` with `1 ≤ #v`, `subspace(v) = v₁` — the value at index `1` of T0's component projection `i ↦ vᵢ`. The definition introduces no constraint of its own beyond naming this first component the V-position's subspace identifier.
