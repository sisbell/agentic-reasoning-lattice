**D-CTG-depth (SharedPrefixReduction).** For depth m ≥ 3, all positions in a non-empty V_1(d) — the text-subspace projection `{v ∈ dom(Σ.M(d)) : subspace(v) = 1}` defined in V-sub (SubspaceProjection) — share every interior component: every component i with `2 ≤ i ∧ i + 1 ≤ m`. Contiguity reduces to contiguity of the last component alone — structurally identical to the depth 2 case.

*Proof.* Let V_1(d) be non-empty with common depth `m` (S8-depth) and `m ≥ 3` — a scope restriction ensuring the interior index range `2 ≤ i ∧ i + 1 ≤ m` is non-empty, so the shared-prefix claim has content. We write the interior bound additively as `i + 1 ≤ m` throughout, never as a predecessor of m: the NAT-* foundations of ASN-0034 furnish `+`, `<`, `≤`, `1` on ℕ but no subtraction or predecessor symbol. The `m = 2` case, where that range is empty and the claim is vacuous, is handled separately in D-SEQ's `m = 2` case. Suppose for contradiction that V_1(d) contains two positions u and x (both depth m) that disagree somewhere in the interior range. Negating the postcondition presents them as an unordered pair, so we first fix their ordering. They differ at an interior component, hence by T3 (CanonicalRepresentation, ASN-0034) — tumblers differing in any component are distinct — u ≠ x, which excludes the u = x branch of T1's trichotomy on T (postcondition (b): for any a, b ∈ T exactly one of a < b, a = b, b < a holds, applicable since u, x ∈ V_1(d) ⊆ T). The two surviving branches u < x and x < u are interchanged by relabeling the pair, and the construction is invariant under that relabeling: the disagreement predicate uᵢ ≠ xᵢ is symmetric in u and x, so the interior disagreement set is unchanged by the swap, and the witness construction below is anchored entirely on the smaller member of the pair — copying that member's prefix and raising one component above it — reaching the pair only through its smaller and larger members. A refutation of one ordering is therefore a refutation of the other, and we take u < x without loss of generality. The set `{i : 2 ≤ i ∧ i + 1 ≤ m ∧ uᵢ ≠ xᵢ}` of interior components at which they differ is then a non-empty subset of ℕ, so by NAT-wellorder (NatWellOrdering, ASN-0034) — the least-element principle for ℕ — it has a least element. Let j be that first point of disagreement, with 2 ≤ j ∧ j + 1 ≤ m (the bound holds because j belongs to the interior set). Then uᵢ = xᵢ for all i < j — for interior i by the minimality of j, and at component 1 by the shared subspace value u₁ = x₁ = 1. We now read uⱼ < xⱼ off u < x. From u < x, T1 furnishes a witness position k with uᵢ = xᵢ for all i < k together with either (i) k ≤ min(m, m) ∧ uₖ < xₖ or (ii) k = m + 1 ≤ m; since u and x share depth m, clause (ii) would demand m + 1 ≤ m — impossible, since NAT-addcompat's strict successor inequality `n < n + 1` (NatAdditionOrderAndSuccessor, ASN-0034) at `n := m` gives m < m + 1, which by NAT-order's trichotomy excludes m + 1 ≤ m. So clause (i) holds and uₖ < xₖ. It remains to pin this witness to k = j. Were k < j, then k satisfies 1 ≤ k < j, where we have already established agreement, giving uₖ = xₖ and contradicting uₖ < xₖ; so k ≥ j. Were k > j, then the witness's own agreement clause `(A i : 1 ≤ i < k : uᵢ = xᵢ)` covers i = j, giving uⱼ = xⱼ and contradicting j's standing as a point of disagreement; so k ≤ j. Hence k = j, and clause (i) at this position reads uⱼ < xⱼ.

We construct infinitely many intermediates. For any natural number n > uⱼ₊₁, define w of length m by:

- wᵢ = uᵢ for 1 ≤ i ≤ j (agreeing with u on the first j components),
- wⱼ₊₁ = n,
- wᵢ = 1 for j + 2 ≤ i ≤ m (an empty range when j + 1 = m, in which case wⱼ₊₁ = w_m is already the last component; otherwise this clause fills components j + 2 through m).

Every component of w lies in ℕ — wᵢ = uᵢ ∈ ℕ for 1 ≤ i ≤ j since u ∈ T, wⱼ₊₁ = n ∈ ℕ, and wᵢ = 1 ∈ ℕ for j + 2 ≤ i ≤ m, the constant `1` lying in ℕ by NAT-closure (NatArithmeticClosureAndIdentity, ASN-0034) — and w has length m ≥ 3 ≥ 1, so by T0's comprehension clause (CarrierSetDefinition, ASN-0034), instantiated at length m and this component map, w ∈ T: the construction yields a genuine tumbler, which is what later lets us instantiate D-CTG's inner v ∈ T quantifier at the constructed w. Then w has depth m (it has m components by construction), and subspace(w) = w₁ = u₁ = 1 (since j ≥ 2, the first component is copied from u). We verify u < w < x:

- **w > u**: w agrees with u on components 1 through j. At component j + 1, wⱼ₊₁ = n > uⱼ₊₁. Since j + 1 ≤ m = min(m, m), by T1(i), w > u.
- **w < x**: w agrees with x on every component i with 1 ≤ i < j (since u and x agree on these components by the definition of j). At component j, wⱼ = uⱼ < xⱼ. T1(i)'s position condition asks for j ≤ min(m, m) = m, which we obtain in the sharper form j < m directly from the additive interior bound j + 1 ≤ m: NAT-addcompat's strict successor inequality `n < n + 1` (NatAdditionOrderAndSuccessor, ASN-0034) at `n := j` gives j < j + 1, and chaining this with j + 1 ≤ m through NAT-order's transitivity yields j < m. Hence j < m = min(m, m), so by T1(i), w < x.

Before invoking D-CTG we must check its inner-quantifier guard on w, of which the only conjunct not yet in hand is the zero-freeness `zeros(w) = 0` — where `zeros` is T4's zero-count `zeros(t) = |{i : 1 ≤ i ≤ #t ∧ tᵢ = 0}|` (HierarchicalParsing, ASN-0034). By NAT-card's empty-set characterization `|S| = 0 ⟺ S = ∅` (NatFiniteSetCardinality, ASN-0034), `zeros(t) = 0` holds exactly when the component-filter `{i : 1 ≤ i ≤ #t ∧ tᵢ = 0}` is empty — that is, when no component of t is zero. We use this zeros-to-positivity bridge in the direction that turns the constructed w's component-positivity into `zeros(w) = 0`. By construction, every component of w is positive: wᵢ = uᵢ > 0 for i ≤ j by S8a's positivity *Consequence*, which exports `(A i : 1 ≤ i ≤ #u : uᵢ > 0)` and so gives u's components their strict positivity directly (u ∈ V_1(d) ⊆ dom(M(d)), so S8a applies); for the new component, wⱼ₊₁ = n with n > uⱼ₊₁ by construction and uⱼ₊₁ > 0 by that same S8a Consequence, so NAT-order's transitivity of `<` (`0 < uⱼ₊₁ < n ⟹ 0 < n`, NatStrictTotalOrder, ASN-0034), instantiated at the ℕ-valued uⱼ₊₁ and n, gives wⱼ₊₁ = n > 0; and wᵢ = 1 > 0 for j + 2 ≤ i ≤ m, the strict inequality `1 > 0` being NAT-closure's *Consequence* `0 < 1` (NatArithmeticClosureAndIdentity, ASN-0034). Hence `(A i : 1 ≤ i ≤ #w : wᵢ > 0)`; each positive component is in particular non-zero, so the zero-filter `{i : 1 ≤ i ≤ #w ∧ wᵢ = 0}` is empty and its cardinality is 0 by NAT-card — this is `zeros(w) = 0`, so w meets D-CTG's guard. S8a itself is not among those guards: its depth half #w ≥ 2 plays no part in the contiguity step, and in any case holds independently, since #w = m ≥ 3 ≥ 2. The dependence in fact runs the other way — D-CTG's conclusion places w in V_1(d) ⊆ dom(M(d)), where every position satisfies S8a, so w's satisfying the full S8a is a consequence of the membership we are about to derive, not a precondition for deriving it.

Since u < w < x, subspace(w) = 1, #w = m = #u, and zeros(w) = 0, D-CTG requires w ∈ V_1(d). We now exhibit infinitely many admissible values of n, each read off T0(a)'s postcondition. That postcondition delivers not a bare natural but a tumbler: instantiated at a supplied tumbler t, a component index i, and a bound M ∈ ℕ, T0(a) (UnboundedComponentValues, ASN-0034) furnishes a tumbler t′ ∈ T with #t′ = #t that agrees with t at every component k ≠ i and has t′ᵢ > M. We instantiate it at t = u and i = j + 1 — placing the large value at exactly the component our witness w varies — and read off the natural n := t′ⱼ₊₁ ∈ ℕ (a component of a tumbler, hence in the carrier ℕ by T0), which satisfies n > M. Iterating the bound: starting from M₀ = uⱼ₊₁, this instantiation supplies a tumbler whose (j + 1)-th component n₁ > M₀; setting M₁ = n₁ and re-instantiating at t = u, i = j + 1, M = M₁ supplies a further tumbler whose (j + 1)-th component n₂ > M₁ ≥ n₁; continuing, we obtain a strictly increasing sequence n₁ < n₂ < n₃ < … of natural numbers, all exceeding uⱼ₊₁. The sequence is infinite and pairwise distinct, and distinct values of n yield distinct witnesses: writing w⁽ᵏ⁾ for the depth-m tumbler the construction builds at n := nₖ — its (j + 1)-th component being nₖ — indices k ≠ ℓ give nₖ ≠ nₗ, so w⁽ᵏ⁾ and w⁽ˡ⁾ differ at component j + 1 and are unequal by T3 (CanonicalRepresentation, ASN-0034). Each w⁽ᵏ⁾ is an instance of the generic witness w just placed in V_1(d), so D-CTG deposits every w⁽ᵏ⁾ in V_1(d) ⊆ dom(Σ.M(d)).

To finish we must turn this abundance into a contradiction with S8-fin, and we must draw it from S8-fin's actual content — an enumerating bijection from an initial segment of ℕ — not from the bare word *finite*: the absurdity is that dom(Σ.M(d)), enumerated by a finite segment, would carry more distinct positions than that segment has indices, and we extract it arithmetically. Instantiate S8-fin at our document d. It furnishes a bound N ∈ ℕ and a bijection f : {j ∈ ℕ : 1 ≤ j ≤ N} → dom(Σ.M(d)) — total into the domain, injective by its clause `(A i, j : 1 ≤ i < j ≤ N : f.i ≠ f.j)`, and surjective by its clause `(A v : v ∈ dom(Σ.M(d)) : (E j : 1 ≤ j ≤ N : f.j = v))`; we name the bound N, holding it apart from the sequence values nₖ. The sequence n₁ < n₂ < … being infinite has at least N + 1 terms, so we keep the first N + 1 witnesses w⁽¹⁾, …, w⁽ᴺ⁺¹⁾, all distinct and all in dom(Σ.M(d)). By the surjectivity clause each is enumerated, so for 1 ≤ k ≤ N + 1 we may choose jₖ ∈ {j ∈ ℕ : 1 ≤ j ≤ N} with f.jₖ = w⁽ᵏ⁾. The assignment k ↦ jₖ is injective: were jₖ = jₗ for some k ≠ ℓ, the one value f assigns that index would be both w⁽ᵏ⁾ and w⁽ˡ⁾, forcing w⁽ᵏ⁾ = w⁽ˡ⁾ against their distinctness — this is f read as the single-valued function its typing f : {j ∈ ℕ : 1 ≤ j ≤ N} → dom(Σ.M(d)) makes it, the injectivity clause being the companion half of the same bijection. Hence its image {jₖ : 1 ≤ k ≤ N + 1} is a subset of {j ∈ ℕ : 1 ≤ j ≤ N} carrying N + 1 pairwise-distinct members, and on this set two readings of NAT-card (NatFiniteSetCardinality, ASN-0034) collide. Its upper-bound clause `(A n ∈ ℕ, S : S ⊆ {j ∈ ℕ : 1 ≤ j ≤ n} :: |S| ≤ n)`, at n := N and S := {jₖ : 1 ≤ k ≤ N + 1}, gives |{jₖ : 1 ≤ k ≤ N + 1}| ≤ N. Its value clause fixes |S| as the unique q ∈ ℕ for which a strictly increasing enumeration `g : {r ∈ ℕ : 1 ≤ r ≤ q} → ℕ` of S exists, and to read |S| off this clause we must *exhibit* such a g: that the members of S are totally ordered — NAT-order's trichotomy — does not of itself hand us the sorting, which must be built, not posited. We build it by successive minimum extraction, the construction NAT-wellorder (NatWellOrdering, ASN-0034) already performed once above to name the first disagreement j, now iterated under the invariant Q: *every minimum so far drawn lies strictly below every member of the residual, the residual being the part of S not yet drawn*. Set R₁ := S. At step r, while the residual Rᵣ ⊆ ℕ is non-empty, NAT-wellorder — invoked afresh at each step, exactly as the least-element principle was invoked to name j — furnishes its least element; we set g.r := min Rᵣ and pass to the residual Rᵣ₊₁ := Rᵣ \ {g.r}. Each drawn minimum strictly dominates those before it: g.r ≤ every member of Rᵣ by its minimality, so g.r ≤ every member of the smaller Rᵣ₊₁ ⊆ Rᵣ, while g.r ∉ Rᵣ₊₁ by removal, whence g.r < every member of Rᵣ₊₁ by trichotomy — every later minimum being drawn from Rᵣ₊₁, this is the invariant Q carried one step forward. The bound function is the count of S's not-yet-drawn members: it starts at the N + 1 pairwise-distinct values jₖ delivered by the injective k ↦ jₖ, strictly decreases by one at each extraction, and so empties the residual after exactly N + 1 steps, indexing the draws by precisely {r ∈ ℕ : 1 ≤ r ≤ N + 1}. The resulting g : {r ∈ ℕ : 1 ≤ r ≤ N + 1} → ℕ enumerates S in strictly increasing order by Q, and is exactly the witness the value clause requires at q := N + 1; by that clause's uniqueness of q, |{jₖ : 1 ≤ k ≤ N + 1}| = N + 1. Putting the two readings together, N + 1 = |{jₖ : 1 ≤ k ≤ N + 1}| ≤ N, that is N + 1 ≤ N. But NAT-addcompat's strict successor inequality `(A n ∈ ℕ :: n < n + 1)` (NatAdditionOrderAndSuccessor, ASN-0034) at n := N gives N < N + 1, and chaining N < N + 1 with N + 1 ≤ N through NAT-order's transitivity yields N < N, which NAT-order's irreflexivity `(A n ∈ ℕ :: ¬(n < n))` (NatStrictTotalOrder, ASN-0034) forbids. This is the contradiction the construction was built to reach: no initial segment {j ∈ ℕ : 1 ≤ j ≤ N} enumerates a dom(Σ.M(d)) holding the N + 1 distinct positions w⁽¹⁾, …, w⁽ᴺ⁺¹⁾ that D-CTG forces into V_1(d).

Therefore the supposed disagreeing pair cannot exist: the case u < x is refuted by the contradiction just reached, x < u collapses onto it by the relabeling fixed at the outset, and u = x was excluded by the disagreement itself. No two positions in V_1(d) can disagree at any component j with 2 ≤ j ∧ j + 1 ≤ m; every pair agrees on every interior component. This is the shared-prefix result, and it is the whole content the lemma carries downstream.

Since subspace(p) = p₁ = 1 for every p ∈ V_1(d), this agreement extends downward to component 1: any two positions of V_1(d) agree on their entire prefix — every component but the last — and so differ from one another only at the last component m. Contiguity among the positions of V_1(d) is thereby settled at component m alone — structurally identical to the depth-2 case, where the shared prefix is the lone subspace component v₁ = 1 (at m = 2 only the first component precedes the last). We record this reduction to the last component as an immediate reading-off of the shared prefix, not as a separate result: once every position is known to share every component but the last, the last component is the only site of variation, and any ordering or contiguity question among the positions is decided there. ∎

Nelson's statement specifies not just contiguity but also the starting ordinal: "addresses 1 through 100," not "42 through 141." All ordinal numbering in the tumbler system starts at 1: the first child is always .1 (LM 4/20), link positions within a document begin at 1 (LM 4/31), and position 0 is structurally unavailable since zero serves as a field separator (T4, ASN-0034). V-positions follow the same convention.

*Formal Contract:*

- *Preconditions:*
  - V_1(d) ≠ ∅ (non-empty).
  - All positions in V_1(d) share a common depth m (S8-depth), with m ≥ 3 — a scope restriction, not a derived bound: at m ≥ 3 the interior index range 2 ≤ i ∧ i + 1 ≤ m is non-empty, so the shared-prefix claim has content, whereas the m = 2 case, where that range is empty and the claim is vacuous, is handled separately in D-SEQ's m = 2 case.
  - Every position p ∈ V_1(d) has subspace(p) = p₁ = 1.
  - V_1(d) ⊆ dom(M(d)), and every position in dom(M(d)) satisfies S8a, whose positivity *Consequence* supplies `#p ≥ 2 ∧ (A i : 1 ≤ i ≤ #p : pᵢ > 0)` — the strict-positivity reading of S8a's Axiom `zeros(p) = 0 ∧ #p ≥ 2`.
  - V_1(d) is contiguous in the position order (D-CTG): if u, x ∈ V_1(d), u < w < x, subspace(w) = 1, #w = #u, and zeros(w) = 0, then w ∈ V_1(d).
  - dom(M(d)) is finite (S8-fin), in the grounded form S8-fin posits: for the document d there exist a bound N ∈ ℕ and a bijection f : {j ∈ ℕ : 1 ≤ j ≤ N} → dom(Σ.M(d)) — total, injective (`(A i, j : 1 ≤ i < j ≤ N : f.i ≠ f.j)`), and surjective (`(A v : v ∈ dom(Σ.M(d)) : (E j : 1 ≤ j ≤ N : f.j = v))`). The proof instantiates this bijection and pulls N + 1 selected positions back through its surjectivity to N + 1 pairwise-distinct indices in {j ∈ ℕ : 1 ≤ j ≤ N}, bounding the number of distinct positions the construction can deposit.
  - Component values are unbounded (T0(a), ASN-0034): instantiated at a tumbler t, a component index i, and a bound M ∈ ℕ, T0(a) supplies a tumbler t′ ∈ T with #t′ = #t agreeing with t at every component k ≠ i and with t′ᵢ > M; the i-th component is then a natural n = t′ᵢ > M. The proof instantiates this at t = u and i = j + 1, extracting n = t′ⱼ₊₁.

- *Postconditions:*
  - `(A u, x : u ∈ V_1(d) ∧ x ∈ V_1(d) : (A i : 2 ≤ i ∧ i + 1 ≤ m : uᵢ = xᵢ))` — every pair of positions in V_1(d) agrees on every interior component (those i with 2 ≤ i ∧ i + 1 ≤ m). This is the shared-prefix result D-SEQ consumes (Step 1, Case m ≥ 3) to pin every position to the form [1, …, 1, k]. Combined with subspace(p) = p₁ = 1, which fixes component 1, the agreement covers the whole prefix (every component but the last — those i with 1 ≤ i ∧ i + 1 ≤ m); the positions of V_1(d) then differ only at the last component, so their contiguity is settled at component m alone — the same structural condition as the depth-2 case. This last reduction is an immediate reading-off of the shared prefix, not a separately consumed result.

- *Definition:* For positions u, x ∈ V_1(d) (u < x, both depth m) whose first disagreement is at component j with 2 ≤ j ∧ j + 1 ≤ m, and for any n > uⱼ₊₁, the intermediate witness w of depth m is constructed by: wᵢ = uᵢ for 1 ≤ i ≤ j; wⱼ₊₁ = n; wᵢ = 1 for j + 2 ≤ i ≤ m (an empty clause when j + 1 = m).
