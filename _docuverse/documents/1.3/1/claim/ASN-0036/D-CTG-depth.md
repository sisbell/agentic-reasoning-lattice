**D-CTG-depth (SharedPrefixReduction).** For depth m ≥ 3, all positions in a non-empty V_1(d) — the text-subspace projection `{v ∈ dom(Σ.M(d)) : subspace(v) = 1}` defined in V-sub (SubspaceProjection) — share every interior component: every component i with `2 ≤ i ∧ i + 1 ≤ m`. Contiguity reduces to contiguity of the last component alone — structurally identical to the depth 2 case.

*Proof.* Let V_1(d) be non-empty with common depth `m` (S8-depth) and `m ≥ 3` — a scope restriction ensuring the interior index range `2 ≤ i ∧ i + 1 ≤ m` is non-empty, so the shared-prefix claim has content. We write the interior bound additively as `i + 1 ≤ m` throughout, never as a predecessor of m: the NAT-* foundations of ASN-0034 furnish `+`, `<`, `≤`, `1` on ℕ but no subtraction or predecessor symbol. The `m = 2` case, where that range is empty and the claim is vacuous, is handled separately in D-SEQ's `m = 2` case. Suppose for contradiction that V_1(d) contains two positions u and x with u < x (both depth m) that disagree somewhere in the interior range: the set `{i : 2 ≤ i ∧ i + 1 ≤ m ∧ uᵢ ≠ xᵢ}` of interior components at which they differ is then a non-empty subset of ℕ, so by NAT-wellorder (NatWellOrdering, ASN-0034) — the least-element principle for ℕ — it has a least element. Let j be that first point of disagreement, with 2 ≤ j ∧ j + 1 ≤ m (the bound holds because j belongs to the interior set). Then uᵢ = xᵢ for all i < j — for interior i by the minimality of j, and at component 1 by the shared subspace value u₁ = x₁ = 1. We now read uⱼ < xⱼ off u < x. From u < x, T1 furnishes a witness position k with uᵢ = xᵢ for all i < k together with either (i) k ≤ min(m, m) ∧ uₖ < xₖ or (ii) k = m + 1 ≤ m; since u and x share depth m, clause (ii) would demand the impossible m + 1 ≤ m, so clause (i) holds and uₖ < xₖ. It remains to pin this witness to k = j. Were k < j, then k satisfies 1 ≤ k < j, where we have already established agreement, giving uₖ = xₖ and contradicting uₖ < xₖ; so k ≥ j. Were k > j, then the witness's own agreement clause `(A i : 1 ≤ i < k : uᵢ = xᵢ)` covers i = j, giving uⱼ = xⱼ and contradicting j's standing as a point of disagreement; so k ≤ j. Hence k = j, and clause (i) at this position reads uⱼ < xⱼ.

We construct infinitely many intermediates. For any natural number n > uⱼ₊₁, define w of length m by:

- wᵢ = uᵢ for 1 ≤ i ≤ j (agreeing with u on the first j components),
- wⱼ₊₁ = n,
- wᵢ = 1 for j + 2 ≤ i ≤ m (an empty range when j + 1 = m, in which case wⱼ₊₁ = w_m is already the last component; otherwise this clause fills components j + 2 through m).

Every component of w lies in ℕ — wᵢ = uᵢ ∈ ℕ for 1 ≤ i ≤ j since u ∈ T, wⱼ₊₁ = n ∈ ℕ, and wᵢ = 1 ∈ ℕ for j + 2 ≤ i ≤ m, the constant `1` lying in ℕ by NAT-closure (NatArithmeticClosureAndIdentity, ASN-0034) — and w has length m ≥ 3 ≥ 1, so by T0's comprehension clause (CarrierSetDefinition, ASN-0034), instantiated at length m and this component map, w ∈ T: the construction yields a genuine tumbler, which is what later lets us instantiate D-CTG's inner v ∈ T quantifier at the constructed w. Then w has depth m (it has m components by construction), and subspace(w) = w₁ = u₁ = 1 (since j ≥ 2, the first component is copied from u). We verify u < w < x:

- **w > u**: w agrees with u on components 1 through j. At component j + 1, wⱼ₊₁ = n > uⱼ₊₁. Since j + 1 ≤ m = min(m, m), by T1(i), w > u.
- **w < x**: w agrees with x on every component i with 1 ≤ i < j (since u and x agree on these components by the definition of j). At component j, wⱼ = uⱼ < xⱼ. By NAT-discrete's discreteness of ℕ — the axiom `j < m ⟹ j + 1 ≤ m` (NatDiscreteness, ASN-0034), which on ℕ makes the additive interior bound `j + 1 ≤ m` and the strict comparison `j < m` interchangeable — the interior bound j + 1 ≤ m yields j < m = min(m, m), so by T1(i), w < x.

Before invoking D-CTG we must check its inner-quantifier guard on w, of which the only conjunct not yet in hand is the zero-freeness `zeros(w) = 0` — where `zeros` is T4's zero-count `zeros(t) = |{i : 1 ≤ i ≤ #t ∧ tᵢ = 0}|` (HierarchicalParsing, ASN-0034). By NAT-card's empty-set characterization `|S| = 0 ⟺ S = ∅` (NatFiniteSetCardinality, ASN-0034), `zeros(t) = 0` holds exactly when the component-filter `{i : 1 ≤ i ≤ #t ∧ tᵢ = 0}` is empty — that is, when no component of t is zero. We use this zeros-to-positivity bridge in the direction that turns the constructed w's component-positivity into `zeros(w) = 0`. By construction, every component of w is positive: wᵢ = uᵢ > 0 for i ≤ j by S8a applied to u, whose well-formedness predicate `(A i : 1 ≤ i ≤ #u : uᵢ > 0)` gives u's components their strict positivity directly (u ∈ V_1(d) ⊆ dom(M(d)), so S8a applies); for the new component, wⱼ₊₁ = n with n > uⱼ₊₁ by construction and uⱼ₊₁ > 0 by that same S8a predicate, so NAT-order's transitivity of `<` (`0 < uⱼ₊₁ < n ⟹ 0 < n`, NatStrictTotalOrder, ASN-0034), instantiated at the ℕ-valued uⱼ₊₁ and n, gives wⱼ₊₁ = n > 0; and wᵢ = 1 > 0 for j + 2 ≤ i ≤ m, the strict inequality `1 > 0` being NAT-closure's *Consequence* `0 < 1` (NatArithmeticClosureAndIdentity, ASN-0034). Hence `(A i : 1 ≤ i ≤ #w : wᵢ > 0)`; each positive component is in particular non-zero, so the zero-filter `{i : 1 ≤ i ≤ #w ∧ wᵢ = 0}` is empty and its cardinality is 0 by NAT-card — this is `zeros(w) = 0`, so w meets D-CTG's guard. S8a itself is not among those guards: its depth half #w ≥ 2 plays no part in the contiguity step, and in any case holds independently, since #w = m ≥ 3 ≥ 2. The dependence in fact runs the other way — D-CTG's conclusion places w in V_1(d) ⊆ dom(M(d)), where every position satisfies S8a, so w's satisfying the full S8a is a consequence of the membership we are about to derive, not a precondition for deriving it.

Since u < w < x, subspace(w) = 1, #w = m = #u, and zeros(w) = 0, D-CTG requires w ∈ V_1(d). We now exhibit infinitely many admissible values of n, each read off T0(a)'s postcondition. That postcondition delivers not a bare natural but a tumbler: instantiated at a supplied tumbler t, a component index i, and a bound M ∈ ℕ, T0(a) (UnboundedComponentValues, ASN-0034) furnishes a tumbler t′ ∈ T with #t′ = #t that agrees with t at every component k ≠ i and has t′ᵢ > M. We instantiate it at t = u and i = j + 1 — placing the large value at exactly the component our witness w varies — and read off the natural n := t′ⱼ₊₁ ∈ ℕ (a component of a tumbler, hence in the carrier ℕ by T0), which satisfies n > M. Iterating the bound: starting from M₀ = uⱼ₊₁, this instantiation supplies a tumbler whose (j + 1)-th component n₁ > M₀; setting M₁ = n₁ and re-instantiating at t = u, i = j + 1, M = M₁ supplies a further tumbler whose (j + 1)-th component n₂ > M₁ ≥ n₁; continuing, we obtain a strictly increasing sequence n₁ < n₂ < n₃ < … of natural numbers, all exceeding uⱼ₊₁. The sequence is infinite and pairwise distinct. Distinct values of n yield distinct tumblers w (they differ at component j + 1, so by T3, CanonicalRepresentation, ASN-0034, they are unequal). This produces infinitely many distinct positions in V_1(d), contradicting S8-fin (dom(M(d)) is finite).

Therefore no two positions in V_1(d) can disagree at any component j with 2 ≤ j ∧ j + 1 ≤ m: every pair agrees on every interior component. This is the shared-prefix result, and it is the whole content the lemma carries downstream.

Since subspace(p) = p₁ = 1 for every p ∈ V_1(d), this agreement extends downward to component 1: any two positions of V_1(d) agree on their entire prefix — every component but the last — and so differ from one another only at the last component m. Contiguity among the positions of V_1(d) is thereby settled at component m alone — structurally identical to the depth-2 case, where the shared prefix is the lone subspace component v₁ = 1 (at m = 2 only the first component precedes the last). We record this reduction to the last component as an immediate reading-off of the shared prefix, not as a separate result: once every position is known to share every component but the last, the last component is the only site of variation, and any ordering or contiguity question among the positions is decided there. ∎

Nelson's statement specifies not just contiguity but also the starting ordinal: "addresses 1 through 100," not "42 through 141." All ordinal numbering in the tumbler system starts at 1: the first child is always .1 (LM 4/20), link positions within a document begin at 1 (LM 4/31), and position 0 is structurally unavailable since zero serves as a field separator (T4, ASN-0034). V-positions follow the same convention.

*Formal Contract:*

- *Preconditions:*
  - V_1(d) ≠ ∅ (non-empty).
  - All positions in V_1(d) share a common depth m (S8-depth), with m ≥ 3 — a scope restriction, not a derived bound: at m ≥ 3 the interior index range 2 ≤ i ∧ i + 1 ≤ m is non-empty, so the shared-prefix claim has content, whereas the m = 2 case, where that range is empty and the claim is vacuous, is handled separately in D-SEQ's m = 2 case.
  - Every position p ∈ V_1(d) has subspace(p) = p₁ = 1.
  - V_1(d) ⊆ dom(M(d)), and every position in dom(M(d)) satisfies S8a: `#p ≥ 2 ∧ (A i : 1 ≤ i ≤ #p : pᵢ > 0)`.
  - V_1(d) is contiguous in the position order (D-CTG): if u, x ∈ V_1(d), u < w < x, subspace(w) = 1, #w = #u, and zeros(w) = 0, then w ∈ V_1(d).
  - dom(M(d)) is finite (S8-fin).
  - Component values are unbounded (T0(a), ASN-0034): instantiated at a tumbler t, a component index i, and a bound M ∈ ℕ, T0(a) supplies a tumbler t′ ∈ T with #t′ = #t agreeing with t at every component k ≠ i and with t′ᵢ > M; the i-th component is then a natural n = t′ᵢ > M. The proof instantiates this at t = u and i = j + 1, extracting n = t′ⱼ₊₁.

- *Postconditions:*
  - `(A u, x : u ∈ V_1(d) ∧ x ∈ V_1(d) : (A i : 2 ≤ i ∧ i + 1 ≤ m : uᵢ = xᵢ))` — every pair of positions in V_1(d) agrees on every interior component (those i with 2 ≤ i ∧ i + 1 ≤ m). This is the shared-prefix result D-SEQ consumes (Step 1, Case m ≥ 3) to pin every position to the form [1, …, 1, k]. Combined with subspace(p) = p₁ = 1, which fixes component 1, the agreement covers the whole prefix (every component but the last — those i with 1 ≤ i ∧ i + 1 ≤ m); the positions of V_1(d) then differ only at the last component, so their contiguity is settled at component m alone — the same structural condition as the depth-2 case. This last reduction is an immediate reading-off of the shared prefix, not a separately consumed result.

- *Definition:* For positions u, x ∈ V_1(d) (u < x, both depth m) whose first disagreement is at component j with 2 ≤ j ∧ j + 1 ≤ m, and for any n > uⱼ₊₁, the intermediate witness w of depth m is constructed by: wᵢ = uᵢ for 1 ≤ i ≤ j; wⱼ₊₁ = n; wᵢ = 1 for j + 2 ≤ i ≤ m (an empty clause when j + 1 = m).
