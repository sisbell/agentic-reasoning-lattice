**D-CTG-depth (SharedPrefixReduction).** For depth m ≥ 3, all positions in a non-empty V_1(d) — the text-subspace projection `{v ∈ dom(Σ.M(d)) : subspace(v) = 1}` defined in V-sub (SubspaceProjection) — share every interior component: every component i with `2 ≤ i ∧ i + 1 ≤ m`. Contiguity reduces to contiguity of the last component alone — structurally identical to the depth 2 case.

*Proof.* Let V_1(d) be non-empty with common depth `m` (S8-depth) and `m ≥ 3` — a scope restriction ensuring the interior index range `2 ≤ i ∧ i + 1 ≤ m` is non-empty, so the shared-prefix claim has content. We write the interior bound additively as `i + 1 ≤ m` throughout, never as a predecessor of m: the NAT-* foundations of ASN-0034 furnish `+`, `<`, `≤`, `1` on ℕ but no subtraction or predecessor symbol. The `m = 2` case, where that range is empty and the claim is vacuous, is handled separately in D-SEQ's `m = 2` case. Suppose for contradiction that V_1(d) contains two positions u and x (both depth m) that disagree somewhere in the interior range. Negating the postcondition presents them as an unordered pair, so we first fix their ordering. They differ at an interior component, hence by T3 (CanonicalRepresentation, ASN-0034) — tumblers differing in any component are distinct — u ≠ x, which excludes the u = x branch of T1's trichotomy on T (postcondition (b): for any a, b ∈ T exactly one of a < b, a = b, b < a holds, applicable since u, x ∈ V_1(d) ⊆ T). The two surviving branches u < x and x < u are interchanged by relabeling the pair, and the construction is invariant under that relabeling: the disagreement predicate uᵢ ≠ xᵢ is symmetric in u and x, so the interior disagreement set is unchanged by the swap, and the witness construction below is anchored entirely on the smaller member of the pair — copying that member's prefix and raising one component above it — reaching the pair only through its smaller and larger members. A refutation of one ordering is therefore a refutation of the other, and we take u < x without loss of generality. The set `{i : 2 ≤ i ∧ i + 1 ≤ m ∧ uᵢ ≠ xᵢ}` of interior components at which they differ is then a non-empty subset of ℕ, so by NAT-wellorder (NatWellOrdering, ASN-0034) — the least-element principle for ℕ — it has a least element. Let j be that first point of disagreement, with 2 ≤ j ∧ j + 1 ≤ m (the bound holds because j belongs to the interior set). Then uᵢ = xᵢ for all i with 1 ≤ i < j. At component 1 this is the shared subspace value u₁ = x₁ = 1; for an index i with 2 ≤ i < j it is the minimality of j, but invoking that minimality first asks that i lie in the interior disagreement set's index range `2 ≤ i ∧ i + 1 ≤ m`. The lower bound 2 ≤ i is at hand; for the upper bound, i < j chains with j < m — the interior bound j + 1 ≤ m descended to j < m by NAT-addcompat's strict successor inequality j < j + 1 and NAT-order's transitivity — through a further NAT-order transitivity to i < m, whence i + 1 ≤ m by NAT-discrete's (NatDiscreteness, ASN-0034) forward direction `m < n ⟹ m + 1 ≤ n` at `(m, n) := (i, m)`. With i so placed in the range, were uᵢ ≠ xᵢ then i would be a member of `{i : 2 ≤ i ∧ i + 1 ≤ m ∧ uᵢ ≠ xᵢ}` strictly below j, contradicting j's standing as that set's least element; hence uᵢ = xᵢ. So u and x agree on every component of the prefix below j. We now read uⱼ < xⱼ off u < x. From u < x, T1 furnishes a witness position k with uᵢ = xᵢ for all i < k together with either (i) k ≤ min(m, m) ∧ uₖ < xₖ or (ii) k = m + 1 ≤ m; since u and x share depth m, clause (ii) would demand m + 1 ≤ m — impossible, since NAT-addcompat's strict successor inequality `n < n + 1` (NatAdditionOrderAndSuccessor, ASN-0034) at `n := m` gives m < m + 1, which by NAT-order's trichotomy excludes m + 1 ≤ m. So clause (i) holds and uₖ < xₖ. It remains to pin this witness to k = j. Were k < j, then 1 ≤ k < j places k among the prefix indices below j on which u and x agree — at k = 1 by the shared subspace value u₁ = x₁ = 1, at k ≥ 2 by the interior placement k + 1 ≤ m that NAT-discrete draws from k < m at `(m, n) := (k, m)` — giving uₖ = xₖ and contradicting clause (i)'s uₖ < xₖ; so k ≥ j. Were k > j, then the witness's own agreement clause `(A i : 1 ≤ i < k : uᵢ = xᵢ)` covers i = j, giving uⱼ = xⱼ and contradicting j's standing as a point of disagreement; so k ≤ j. Hence k = j, and clause (i) at this position reads uⱼ < xⱼ.

We construct an intermediate for each admissible value of n. For any natural number n > uⱼ₊₁, define w of length m by:

- wᵢ = uᵢ for 1 ≤ i ≤ j (agreeing with u on the first j components),
- wⱼ₊₁ = n,
- wᵢ = 1 for j + 2 ≤ i ≤ m (an empty range when j + 1 = m, in which case wⱼ₊₁ = w_m is already the last component; otherwise this clause fills components j + 2 through m).

Every component of w lies in ℕ — wᵢ = uᵢ ∈ ℕ for 1 ≤ i ≤ j since u ∈ T, wⱼ₊₁ = n ∈ ℕ, and wᵢ = 1 ∈ ℕ for j + 2 ≤ i ≤ m, the constant `1` lying in ℕ by NAT-closure (NatArithmeticClosureAndIdentity, ASN-0034) — and w has length m ≥ 3 ≥ 1, so by T0's comprehension clause (CarrierSetDefinition, ASN-0034), instantiated at length m and this component map, w ∈ T: the construction yields a genuine tumbler, which is what later lets us instantiate D-CTG's inner v ∈ T quantifier at the constructed w. Then w has depth m (it has m components by construction), and subspace(w) = w₁ = u₁ = 1 (since j ≥ 2, the first component is copied from u). We verify u < w < x:

- **w > u**: w agrees with u on components 1 through j. At component j + 1, wⱼ₊₁ = n > uⱼ₊₁. Since j + 1 ≤ m = min(m, m), by T1(i), w > u.
- **w < x**: w agrees with x on every component i with 1 ≤ i < j (since u and x agree on these components by the definition of j). At component j, wⱼ = uⱼ < xⱼ. T1(i)'s position condition asks for j ≤ min(m, m) = m, which we obtain in the sharper form j < m directly from the additive interior bound j + 1 ≤ m: NAT-addcompat's strict successor inequality `n < n + 1` (NatAdditionOrderAndSuccessor, ASN-0034) at `n := j` gives j < j + 1, and chaining this with j + 1 ≤ m through NAT-order's transitivity yields j < m. Hence j < m = min(m, m), so by T1(i), w < x.

Before invoking D-CTG we must check its inner-quantifier guard on w, of which the only conjunct not yet in hand is the zero-freeness `zeros(w) = 0` — where `zeros` is T4's zero-count `zeros(t) = |{i : 1 ≤ i ≤ #t ∧ tᵢ = 0}|` (HierarchicalParsing, ASN-0034). By NAT-card's empty-set characterization `|S| = 0 ⟺ S = ∅` (NatFiniteSetCardinality, ASN-0034), `zeros(t) = 0` holds exactly when the component-filter `{i : 1 ≤ i ≤ #t ∧ tᵢ = 0}` is empty — that is, when no component of t is zero. We use this zeros-to-positivity bridge in the direction that turns the constructed w's component-positivity into `zeros(w) = 0`. By construction, every component of w is positive: wᵢ = uᵢ > 0 for i ≤ j by S8a's positivity *Consequence*, which exports `(A i : 1 ≤ i ≤ #u : uᵢ > 0)` and so gives u's components their strict positivity directly (u ∈ V_1(d) ⊆ dom(M(d)), so S8a applies); for the new component, wⱼ₊₁ = n with n > uⱼ₊₁ by construction and uⱼ₊₁ > 0 by that same S8a Consequence, so NAT-order's transitivity of `<` (`0 < uⱼ₊₁ < n ⟹ 0 < n`, NatStrictTotalOrder, ASN-0034), instantiated at the ℕ-valued uⱼ₊₁ and n, gives wⱼ₊₁ = n > 0; and wᵢ = 1 > 0 for j + 2 ≤ i ≤ m, the strict inequality `1 > 0` being NAT-closure's *Consequence* `0 < 1` (NatArithmeticClosureAndIdentity, ASN-0034). Hence `(A i : 1 ≤ i ≤ #w : wᵢ > 0)`; each positive component is in particular non-zero, so the zero-filter `{i : 1 ≤ i ≤ #w ∧ wᵢ = 0}` is empty and its cardinality is 0 by NAT-card — this is `zeros(w) = 0`, so w meets D-CTG's guard. S8a itself is not among those guards: its depth half #w ≥ 2 plays no part in the contiguity step, and in any case holds independently, since #w = m ≥ 3 ≥ 2. The dependence in fact runs the other way — D-CTG's conclusion places w in V_1(d) ⊆ dom(M(d)), where every position satisfies S8a, so w's satisfying the full S8a is a consequence of the membership we are about to derive, not a precondition for deriving it.

Since u < w < x, subspace(w) = 1, #w = m = #u, and zeros(w) = 0, D-CTG requires w ∈ V_1(d). The witness was built from an arbitrary admissible value n > uⱼ₊₁, so each such n deposits a position in V_1(d) ⊆ dom(Σ.M(d)); moreover distinct admissible values yield distinct positions, since two witnesses built at n ≠ n′ differ at component j + 1 — their sole varying component — and are unequal by T3 (CanonicalRepresentation, ASN-0034). The admissible values are drawn from T0(a), whose postcondition delivers not a bare natural but a tumbler: instantiated at a supplied tumbler t, a component index i, and a bound M ∈ ℕ, T0(a) (UnboundedComponentValues, ASN-0034) furnishes a tumbler t′ ∈ T with #t′ = #t that agrees with t at every component k ≠ i and has t′ᵢ > M. We instantiate it at t = u and i = j + 1 — placing the large value at exactly the component our witness w varies — and read off the natural n := t′ⱼ₊₁ ∈ ℕ (a component of a tumbler, hence in the carrier ℕ by T0), which satisfies n > M. One such application clears any single bound M; how many applications we shall need is set not in advance but by S8-fin's enumeration of the domain.

To reach a contradiction we must deposit in dom(Σ.M(d)) more distinct positions than its enumeration can hold, and we must draw the absurdity from S8-fin's actual content — an enumerating bijection from an initial segment of ℕ — not from the bare word *finite*: the absurdity is that dom(Σ.M(d)), enumerated by a finite segment, would carry more distinct positions than that segment has indices, and we extract it arithmetically. So we read that bijection off first, letting its bound fix how many witnesses to build. Instantiate S8-fin at our document d. It furnishes a bound N ∈ ℕ and a bijection f : {r ∈ ℕ : 1 ≤ r ≤ N} → dom(Σ.M(d)) — total into the domain, injective by its clause `(A i, r : 1 ≤ i < r ≤ N : f.i ≠ f.r)`, and surjective by its clause `(A v : v ∈ dom(Σ.M(d)) : (E r : 1 ≤ r ≤ N : f.r = v))`; we name the bound N, holding it apart from the witness values nₖ to come. With N fixed we invoke T0(a) exactly N + 1 times, each application feeding its output back as the next bound. Starting from M₀ = uⱼ₊₁, the instantiation at t = u, i = j + 1, M = M₀ supplies a tumbler whose (j + 1)-th component is some n₁ > M₀; setting M₁ = n₁ and re-instantiating at t = u, i = j + 1, M = M₁ supplies a tumbler whose (j + 1)-th component n₂ > M₁ = n₁; iterating this for a total of N + 1 applications produces a strictly increasing run n₁ < n₂ < … of exactly N + 1 naturals, all exceeding uⱼ₊₁. This is a finite iteration of fixed length N + 1: each nₖ is one application of T0(a) to the displayed bound, the count set by S8-fin's N, so the construction commits to no infinite object and invokes no choice principle — only N + 1 successive existential instantiations. The N + 1 values being pairwise distinct, their witnesses w⁽¹⁾, …, w⁽ᴺ⁺¹⁾ — where w⁽ᵏ⁾ is the construction's output at n := nₖ, its (j + 1)-th component nₖ — are pairwise distinct by the T3 argument above, and each, an instance of the generic witness just placed in V_1(d), lies in dom(Σ.M(d)). By the surjectivity clause each is enumerated, so for 1 ≤ k ≤ N + 1 we may choose rₖ ∈ {r ∈ ℕ : 1 ≤ r ≤ N} with f.rₖ = w⁽ᵏ⁾. The assignment k ↦ rₖ is injective: were rₖ = rₗ for some k ≠ ℓ, the one value f assigns that index would be both w⁽ᵏ⁾ and w⁽ˡ⁾, forcing w⁽ᵏ⁾ = w⁽ˡ⁾ against their distinctness — this is f read as the single-valued function its typing f : {r ∈ ℕ : 1 ≤ r ≤ N} → dom(Σ.M(d)) makes it, the injectivity clause being the companion half of the same bijection. Hence its image {rₖ : 1 ≤ k ≤ N + 1} is a subset of {r ∈ ℕ : 1 ≤ r ≤ N} carrying N + 1 pairwise-distinct members, and on this set an upper bound and an exact count collide. NAT-card's (NatFiniteSetCardinality, ASN-0034) upper-bound clause `(A n ∈ ℕ, S : S ⊆ {r ∈ ℕ : 1 ≤ r ≤ n} :: |S| ≤ n)`, at n := N and S := {rₖ : 1 ≤ k ≤ N + 1}, gives |{rₖ : 1 ≤ k ≤ N + 1}| ≤ N. For the exact count we invoke D-INJ (InjectiveImageCardinality), instantiated at P := N + 1 and n := N: the assignment k ↦ rₖ is an injection from {k ∈ ℕ : 1 ≤ k ≤ N + 1} into {r ∈ ℕ : 1 ≤ r ≤ N} — injective by the single-valuedness of f just used, and landing in that segment because each rₖ was selected from {r ∈ ℕ : 1 ≤ r ≤ N} — so D-INJ reads its image's cardinality as |{rₖ : 1 ≤ k ≤ N + 1}| = N + 1. D-INJ discharges, by an explicit induction on the segment length {k ∈ ℕ : 1 ≤ k ≤ N + 1}, exactly the step a bare counting argument would leave circular: it *builds* the strictly increasing length-(N + 1) enumeration NAT-card's value clause demands — deleting the least value, renumbering the surviving indices to apply the induction hypothesis, and prepending the least value to the sorted remainder — with the number of enumeration slots fixed by the induction, not by positing that a successive-minimum draw runs for N + 1 steps (which would presuppose the very cardinality N + 1 being derived). The lemma carries no `N + 1 ≤ N` hypothesis, so it applies in this regime where the segment {1 ≤ k ≤ N + 1} is longer than its target {1 ≤ r ≤ N}. Putting the upper bound against the exact count, N + 1 = |{rₖ : 1 ≤ k ≤ N + 1}| ≤ N, that is N + 1 ≤ N. But NAT-addcompat's strict successor inequality `(A n ∈ ℕ :: n < n + 1)` (NatAdditionOrderAndSuccessor, ASN-0034) at n := N gives N < N + 1, and chaining N < N + 1 with N + 1 ≤ N through NAT-order's transitivity yields N < N, which NAT-order's irreflexivity `(A n ∈ ℕ :: ¬(n < n))` (NatStrictTotalOrder, ASN-0034) forbids. This is the contradiction the construction was built to reach: no initial segment {r ∈ ℕ : 1 ≤ r ≤ N} enumerates a dom(Σ.M(d)) holding the N + 1 distinct positions w⁽¹⁾, …, w⁽ᴺ⁺¹⁾ that D-CTG forces into V_1(d).

Therefore the supposed disagreeing pair cannot exist: the case u < x is refuted by the contradiction just reached, x < u collapses onto it by the relabeling fixed at the outset, and u = x was excluded by the disagreement itself. No two positions in V_1(d) can disagree at any component j with 2 ≤ j ∧ j + 1 ≤ m; every pair agrees on every interior component. This is the shared-prefix result, and it is the whole content the lemma carries downstream.

Since subspace(p) = p₁ = 1 for every p ∈ V_1(d), this agreement extends downward to component 1: any two positions of V_1(d) agree on their entire prefix — every component but the last — and so differ from one another only at the last component m. Contiguity among the positions of V_1(d) is thereby settled at component m alone — structurally identical to the depth-2 case, where the shared prefix is the lone subspace component v₁ = 1 (at m = 2 only the first component precedes the last). We record this reduction to the last component as an immediate reading-off of the shared prefix, not as a separate result: once every position is known to share every component but the last, the last component is the only site of variation, and any ordering or contiguity question among the positions is decided there. ∎

Nelson's statement specifies not just contiguity but also the starting ordinal: "addresses 1 through 100," not "42 through 141." All ordinal numbering in the tumbler system starts at 1: the first child is always .1 (LM 4/20), link positions within a document begin at 1 (LM 4/31), and position 0 is structurally unavailable since zero serves as a field separator (T4, ASN-0034). V-positions follow the same convention.

*Formal Contract:*

- *Preconditions:*
  - V_1(d) ≠ ∅ (non-empty).
  - All positions in V_1(d) share a common depth m (S8-depth), with m ≥ 3 — a scope restriction, not a derived bound: at m ≥ 3 the interior index range 2 ≤ i ∧ i + 1 ≤ m is non-empty, so the shared-prefix claim has content, whereas the m = 2 case, where that range is empty and the claim is vacuous, is handled separately in D-SEQ's m = 2 case.
  - Every position p ∈ V_1(d) has subspace(p) = p₁ = 1.
  - V_1(d) ⊆ dom(M(d)), and every position in dom(M(d)) satisfies S8a, whose positivity *Consequence* supplies `#p ≥ 2 ∧ (A i : 1 ≤ i ≤ #p : pᵢ > 0)` — the strict-positivity reading of S8a's Axiom `zeros(p) = 0 ∧ #p ≥ 2`.
  - V_1(d) is contiguous in the position order (D-CTG): if u, x ∈ V_1(d), u < w < x, subspace(w) = 1, #w = #u, and zeros(w) = 0, then w ∈ V_1(d).
  - dom(M(d)) is finite (S8-fin), in the grounded form S8-fin posits: for the document d there exist a bound N ∈ ℕ and a bijection f : {r ∈ ℕ : 1 ≤ r ≤ N} → dom(Σ.M(d)) — total, injective (`(A i, r : 1 ≤ i < r ≤ N : f.i ≠ f.r)`), and surjective (`(A v : v ∈ dom(Σ.M(d)) : (E r : 1 ≤ r ≤ N : f.r = v))`). The proof reads off this N first to fix the count, then builds N + 1 distinct positions by N + 1 applications of T0(a) and pulls them back through its surjectivity to N + 1 pairwise-distinct indices in {r ∈ ℕ : 1 ≤ r ≤ N}, the impossible N + 1 ≤ N being the contradiction.
  - Component values are unbounded (T0(a), ASN-0034): instantiated at a tumbler t, a component index i, and a bound M ∈ ℕ, T0(a) supplies a tumbler t′ ∈ T with #t′ = #t agreeing with t at every component k ≠ i and with t′ᵢ > M; the i-th component is then a natural n = t′ᵢ > M. The proof instantiates this at t = u and i = j + 1, extracting n = t′ⱼ₊₁, and applies it exactly N + 1 times (with N drawn first from S8-fin), each application feeding the previous output back as the bound, to extract a strictly increasing run of N + 1 naturals n₁ < n₂ < … — a finite iteration of fixed length, not an infinite sequence.

- *Postconditions:*
  - `(A u, x : u ∈ V_1(d) ∧ x ∈ V_1(d) : (A i : 2 ≤ i ∧ i + 1 ≤ m : uᵢ = xᵢ))` — every pair of positions in V_1(d) agrees on every interior component (those i with 2 ≤ i ∧ i + 1 ≤ m). This is the shared-prefix result D-SEQ consumes (Step 1, Case m ≥ 3) to pin every position to the form [1, …, 1, k]. Combined with subspace(p) = p₁ = 1, which fixes component 1, the agreement covers the whole prefix (every component but the last — those i with 1 ≤ i ∧ i + 1 ≤ m); the positions of V_1(d) then differ only at the last component, so their contiguity is settled at component m alone — the same structural condition as the depth-2 case. This last reduction is an immediate reading-off of the shared prefix, not a separately consumed result.

- *Definition:* For positions u, x ∈ V_1(d) (u < x, both depth m) whose first disagreement is at component j with 2 ≤ j ∧ j + 1 ≤ m, and for any n > uⱼ₊₁, the intermediate witness w of depth m is constructed by: wᵢ = uᵢ for 1 ≤ i ≤ j; wⱼ₊₁ = n; wᵢ = 1 for j + 2 ≤ i ≤ m (an empty clause when j + 1 = m).

- *Depends:*
  - V-sub (SubspaceProjection) — supplies the definition of the text-subspace projection `V_1(d) = {v ∈ dom(Σ.M(d)) : subspace(v) = 1}` the proof reasons about; the preconditions `V_1(d) ≠ ∅` and `V_1(d) ⊆ dom(M(d))`, and the membership tests `u, x ∈ V_1(d)` and `w ∈ V_1(d)`, are all stated against this set, each membership unfolding to `· ∈ dom(Σ.M(d)) ∧ subspace(·) = 1`
  - S8-depth (FixedDepthVPositions) — supplies the shared depth `m` for all positions in V_1(d), consumed as the proof's starting invariant that all elements have a common depth before the contradiction is constructed
  - T1 (LexicographicOrder, ASN-0034) — supplies two postconditions of the lexicographic order. Its trichotomy on T (postcondition (b): for any a, b ∈ T exactly one of a < b, a = b, b < a) is invoked at the contradiction's outset to fix the ordering of the negated postcondition's unordered pair: with u = x excluded by T3, the two ordered branches u < x and x < u remain, and relabeling collapses x < u onto u < x — the disagreement predicate and the witness construction being symmetric under the swap — so the single ordering u < x is treated without loss of generality. Its component-comparison clause (i) is invoked in the shared-prefix construction to read uⱼ < xⱼ off u < x and to derive u < w and w < x for the constructed intermediate w from its first differing component (component j + 1 for w > u, component j for w < x)
  - NAT-order (NatStrictTotalOrder, ASN-0034) — supplies the transitivity of `<` on ℕ, `(A m, n, p ∈ ℕ : m < n ∧ n < p : m < p)`, instantiated at `(0, uⱼ₊₁, n)` in the zero-freeness check to conclude the new component wⱼ₊₁ = n is positive (`0 < uⱼ₊₁ < n ⟹ 0 < n`) from S8a's positivity *Consequence* (`uⱼ₊₁ > 0`) and the construction's n > uⱼ₊₁; this component-positivity of wⱼ₊₁ is one of the three cases establishing `(A i : 1 ≤ i ≤ #w : wᵢ > 0)`, i.e. the `zeros(w) = 0` guard D-CTG requires. The same order supplies, alongside NAT-addcompat's strict successor inequality, two further steps: its trichotomy makes `m + 1 ≤ m` false against `m < m + 1` (ruling out T1 clause (ii) when #u = #x = m), and its transitivity chains `j < j + 1` with the interior bound `j + 1 ≤ m` into `j < m` (which the w < x branch consumes for T1 clause (i)'s position condition). The closing finiteness step draws on the same order twice more: its transitivity chains `N < N + 1` (NAT-addcompat) with the counting bound `N + 1 ≤ N` — NAT-card's upper bound set against D-INJ's exact count — into `N < N`; and its irreflexivity `(A n ∈ ℕ :: ¬(n < n))` rejects `N < N`, completing the contradiction. The trichotomy that verifies the constructed enumeration strictly increases now operates inside D-INJ, where that enumeration is built from `{rₖ : 1 ≤ k ≤ N + 1}`
  - NAT-addcompat (NatAdditionOrderAndSuccessor, ASN-0034) — supplies the strict successor inequality `(A n ∈ ℕ :: n < n + 1)`, instantiated at three points. At `n := m` it gives `m < m + 1`, which by NAT-order's trichotomy makes `m + 1 ≤ m` false; this discharges the impossibility of T1 clause (ii)'s `k = m + 1 ≤ m` when u and x share depth m, forcing clause (i) and so uₖ < xₖ. At `n := j` it gives `j < j + 1`, which chained with the interior bound `j + 1 ≤ m` through NAT-order's transitivity yields `j < m`, consumed in the w < x branch to meet T1 clause (i)'s position condition (witness index k = j ≤ min(m, m) = m). At `n := N` — S8-fin's enumeration bound — it gives `N < N + 1`, which set against the counting bound `N + 1 ≤ N` (NAT-card's upper bound on the pulled-back index set against D-INJ's exact count) yields `N < N` through NAT-order's transitivity, the contradiction that closes the finiteness step
  - NAT-discrete (NatDiscreteness, ASN-0034) — supplies discreteness `m < n ⟹ m + 1 ≤ n`, its forward direction instantiated at `(m, n) := (i, m)` to place every prefix index i with 2 ≤ i < j inside the interior disagreement set's index range. From i < j and j < m (the interior bound j + 1 ≤ m descended to j < m by NAT-addcompat's j < j + 1 and NAT-order's transitivity) NAT-order's transitivity gives i < m, and this discreteness descends i < m to the interior upper bound i + 1 ≤ m; with 2 ≤ i ∧ i + 1 ≤ m in hand, j's minimality forces uᵢ = xᵢ, so u and x agree across the whole prefix below j. This below-j agreement is exactly what the k = j pinning's `k < j` sub-case consumes: a witness index k < j carries uₖ = xₖ against clause (i)'s uₖ < xₖ — the sub-case k = 1 closing on the shared subspace value u₁ = x₁ = 1, the sub-case k ≥ 2 on this same discreteness at `(m, n) := (k, m)` (k < m ⟹ k + 1 ≤ m) placing k in the interior range so minimality applies — and it is also what the w < x branch relies on to read w's agreement with x on the components 1 ≤ i < j. The listed order axioms cannot reach it unaided: NAT-order's transitivity passes the chain i < j < m only to the strict i < m, one short of the i + 1 ≤ m interior membership demands, so without discreteness the prefix agreement below j is ungrounded and both the k = j pinning (whence uⱼ < xⱼ, which drives the witness construction) and the w < x verification lose their footing
  - NAT-wellorder (NatWellOrdering, ASN-0034) — supplies the least-element principle for ℕ (every non-empty subset of ℕ has a least element).
