**S7 (StructuralAttribution).** For every `a ∈ dom(Σ.C)`, define the *origin* as the document-level prefix obtained by truncating the element field:

`origin(a) = N(a).0.U(a).0.D(a)`

This is the full document tumbler `N.0.U.0.D` — uniquely identifying the allocating document across the system.

Since I-addresses are permanent (S0) and unique (GlobalUniqueness, ASN-0034), this attribution is permanent and unseverable.

We note a subtlety. S7 identifies the document that ALLOCATED the I-address — the document where the content was first created. This is distinct from the document where the content currently appears. When content is transcluded from document B into document A, the reader viewing A sees the content, but S7 traces it to B. The distinction between "where I am reading" (Vstream context, document A) and "where this came from" (Istream structure, document B) is precisely the two-stream separation made visible.

*Proof.* We wish to show that for every `a ∈ dom(Σ.C)`, the function `origin(a) = N(a).0.U(a).0.D(a)` is well-defined, uniquely identifies the document that allocated `a`, and that this identification is permanent and unseverable.

**Well-definedness.** Fix `a ∈ dom(Σ.C)`. Before decomposing `a` into fields we must establish that `a` is T4-valid, for it is T4-validity — not the bare separator count — that licenses T4's field-decomposition machinery; `zeros(a) = 3` alone fixes the *number* of separators but says nothing about their adjacency or the boundary components, which are precisely the constraints T4 imposes. We obtain T4-validity from the allocation discipline. By S7a (document-scoped allocation), the baptism that placed `a` into `dom(Σ.C)` is itself an allocation event under T10a (ASN-0034): `a ∈ dom(A_element)`, where `A_element` is the document owner's element allocator — a node of the global allocator tree `𝒯`. T10a.4 (T4PreservationUnderDiscipline, ASN-0034) asserts that for every allocator `A ∈ 𝒯` and every `t ∈ dom(A)`, `t` is T4-valid; instantiating it at `A := A_element` and `t := a` — legitimate precisely because S7a places `A_element ∈ 𝒯` and `a ∈ dom(A_element)`, the two memberships of distinct types the instantiation requires — yields that `a` is T4-valid, so T4's field-decomposition machinery applies to `a`. By S7b (element-level I-addresses) we additionally have `zeros(a) = 3`, placing `a` at the element level with all four identifying fields present. By T4 (HierarchicalParsing, ASN-0034), `zeros(a) = 3` means `a` contains exactly three zero-valued field separators, and the partial projections supplied by T4b (UniqueParse, ASN-0034) — `N(a)`, `U(a)`, `D(a)`, `E(a)` — extract the node, user, document, and element fields respectively, each a finite sequence of natural numbers whose components are strictly positive — strict positivity not re-derived here but taken directly from T4b's own postcondition, under which every defined projection returns a sequence over `ℕ⁺` (= `{n ∈ ℕ : 0 < n}`), its components already postconditioned strictly positive by the very foundation we have just invoked to obtain the projections. T4 supplies the separator/zero-count structure (`zeros(a) = 3` with no two zeros adjacent and non-zero first and last components); the equivalent reading that each present field is non-empty — has at least one component — is T4a (SyntacticEquivalence, ASN-0034). The projections `N(a)`, `U(a)`, and `D(a)` are therefore all well-defined with at least one strictly positive component each. The truncation `origin(a)` — formed by concatenating the node field, a zero separator, the user field, a zero separator, and the document field — must now be established as a tumbler in its own right, for to call it a *well-defined tumbler* is precisely to assert `origin(a) ∈ T`, and T-membership is licensed only by T0 (CarrierSetDefinition, ASN-0034). We present `origin(a)` to T0 as a length together with a component map into ℕ. Its length is the left-associated sum `p = (((#N(a) + 1) + #U(a)) + 1) + #D(a)` — we fix this grouping once, addition not being posited commutative at this stratum, so that the sub-expressions named below (the second separator's position, the total length `p` itself) are unambiguous — a sum of naturals, hence `p ∈ ℕ` by NAT-closure's closure of `+` (ASN-0034). Of this length T0's comprehension asks only the lower bound `p ≥ 1`, which we read straight off the leading field: T4a's non-emptiness of the N field gives `#N(a) ≥ 1`, while the trailing summands `#U(a) + 1 + #D(a)` are naturals and so `≥ 0` by NAT-zero's minimality (ASN-0034); NAT-addcompat's order-compatibility of `+` (ASN-0034) then adds the fixed prefix `#N(a) + 1` to `0 ≤ #U(a) + 1 + #D(a)` and lifts `#N(a) ≥ 1` through `+ 1`, yielding `p ≥ #N(a) + 1 ≥ 2` (the constant `2 := 1 + 1 ∈ ℕ` by NAT-closure), hence in particular the `p ≥ 1` the comprehension requires. Its component map `r : {j ∈ ℕ : 1 ≤ j ≤ p} → ℕ` carries the leading `#N(a)` positions to the components of `N(a)`, position `#N(a) + 1` to the separator `0`, the next `#U(a)` positions to the components of `U(a)`, position `((#N(a) + 1) + #U(a)) + 1` to the separator `0`, and the final `#D(a)` positions to the components of `D(a)`; every field component lies in `ℕ⁺ ⊆ ℕ` (T4b's strict-positivity postcondition) and each separator is `0 ∈ ℕ` (NAT-zero, ASN-0034), so `r` is everywhere valued in ℕ. T0's comprehension clause `(A p ∈ ℕ : p ≥ 1 : (A r : {j ∈ ℕ : 1 ≤ j ≤ p} → ℕ :: (E t ∈ T :: #t = p ∧ (A i ∈ ℕ : 1 ≤ i ≤ p : tᵢ = r(i)))))`, instantiated at this length `p ≥ 1` and this component map `r`, supplies a `t ∈ T` with `#t = p` and `tᵢ = r(i)` at each position; that `t` is `origin(a)`, so `origin(a) ∈ T` and the truncation is a well-defined tumbler. With `origin(a) ∈ T` in hand, we compute its separator count from T4's zero-count definition `zeros(t) = |{i : 1 ≤ i ≤ #t ∧ tᵢ = 0}|`, instantiated at `t := origin(a)`. The two equalities the comprehension clause returned — `#origin(a) = p` and `origin(a)ᵢ = r(i)` for every `i` with `1 ≤ i ≤ p` — let us rewrite this count over the constructed map: `zeros(origin(a)) = |{i : 1 ≤ i ≤ p ∧ r(i) = 0}|`. We evaluate this index set by inspecting `r` position by position: each field position carries a component of `N(a)`, `U(a)`, or `D(a)`, every one lying in `ℕ⁺` (T4b's strict-positivity postcondition) and hence `≠ 0`, while the only positions `r` sends to `0` are the two separators, at `#N(a) + 1` and `((#N(a) + 1) + #U(a)) + 1`. Hence `{i : 1 ≤ i ≤ p ∧ r(i) = 0} = {#N(a) + 1, ((#N(a) + 1) + #U(a)) + 1}`. These two indices are distinct: their difference is `(((#N(a) + 1) + #U(a)) + 1) − (#N(a) + 1)`, which we evaluate in two steps. The constructive position `((#N(a) + 1) + #U(a)) + 1` is left-associated — the trailing separator `+ 1` added outermost — whereas NAT-sub's left-telescoping `(n + m) − n = m` fires only when the subtrahend `#N(a) + 1` stands as the minuend's leading summand; addition is not posited commutative here, so the two notations are not interchangeable and we must re-associate explicitly. NAT-addassoc (ASN-0034) — associativity `(m + n) + k = m + (n + k)` — at `m := #N(a) + 1`, `n := #U(a)`, `k := 1` supplies `((#N(a) + 1) + #U(a)) + 1 = (#N(a) + 1) + (#U(a) + 1)`, bringing the minuend to the leading-summand form. NAT-sub's left-telescoping (ASN-0034) at `n := #N(a) + 1`, `m := #U(a) + 1` then returns `((#N(a) + 1) + (#U(a) + 1)) − (#N(a) + 1) = #U(a) + 1` — the map `r` lays the two separators down with exactly the `#U(a)` user positions between them, so the second sits `#U(a) + 1` beyond the first. T4a's non-emptiness of the U field — `#U(a) ≥ 1`, already established above — lifts through `+ 1` by NAT-addcompat's order-compatibility (ASN-0034) to `#U(a) + 1 ≥ 2`. Now we order the two positions. Their positive difference does not, by itself, order them: NAT-order's clauses — irreflexivity, transitivity, trichotomy, the `≤`-definition — do not license passing from the positivity of a difference to the strict ordering of the two quantities differenced, absent an additive bridge tying that difference back to `+`. We argue instead from the additive form `((#N(a) + 1) + #U(a)) + 1 = (#N(a) + 1) + (#U(a) + 1)` that the NAT-addassoc re-association above already put in hand. NAT-addcompat's strict successor `n < n + 1` (ASN-0034) at `n := #N(a) + 1` gives `#N(a) + 1 < (#N(a) + 1) + 1`. The bound `#U(a) + 1 ≥ 2` just obtained gives in particular `1 ≤ #U(a) + 1` (with `2 > 1` from NAT-addcompat's successor at `n := 1`, read as `>` by NAT-order); NAT-addcompat's left order-compatibility (ASN-0034), adding the fixed summand `#N(a) + 1` on the left of `1 ≤ #U(a) + 1`, gives `(#N(a) + 1) + 1 ≤ (#N(a) + 1) + (#U(a) + 1) = ((#N(a) + 1) + #U(a)) + 1`. NAT-order's `≤`-definition `m ≤ n ⟺ m < n ∨ m = n` unfolds this `≤` into a strict sub-case `(#N(a) + 1) + 1 < ((#N(a) + 1) + #U(a)) + 1`, which NAT-order's transitivity chains with `#N(a) + 1 < (#N(a) + 1) + 1` to `#N(a) + 1 < ((#N(a) + 1) + #U(a)) + 1`, and an equality sub-case `(#N(a) + 1) + 1 = ((#N(a) + 1) + #U(a)) + 1`, which substituted into `#N(a) + 1 < (#N(a) + 1) + 1` by indiscernibility of `=` rewrites it to the same `#N(a) + 1 < ((#N(a) + 1) + #U(a)) + 1`. Either sub-case yields `#N(a) + 1 < ((#N(a) + 1) + #U(a)) + 1`, the strict separation of the two zero positions; the two indices are thus distinct, since equality would collapse this to the irreflexivity-forbidden `#N(a) + 1 < #N(a) + 1`. That this two-element index set has cardinality `2` is NAT-card's enumeration characterisation of `|·|`, read at `n = p`: the index set `{#N(a) + 1, ((#N(a) + 1) + #U(a)) + 1}` is a subset of `{1, …, p} ⊆ ℕ` — both members are positions in `r`'s domain `{j ∈ ℕ : 1 ≤ j ≤ p}` — and its two distinct members enumerate it in strictly increasing order, `#N(a) + 1 < ((#N(a) + 1) + #U(a)) + 1` just shown, an enumeration of length `2`; so `|{#N(a) + 1, ((#N(a) + 1) + #U(a)) + 1}| = 2`, and therefore `zeros(origin(a)) = 2`. This zero count is but the first of the four conjuncts T4-validity demands, and it is membership in T4's *T4-valid* subset — not the zero count read in isolation — that entitles us to speak of `origin(a)`'s *level* in the hierarchy at all; so before placing `origin(a)` anywhere we discharge the remaining three conjuncts, T4's field-segment constraint, each off the very component map `r` we have just catalogued position by position. *No two zeros adjacent* — `(A i : 1 ≤ i < p : ¬(origin(a)ᵢ = 0 ∧ origin(a)ᵢ₊₁ = 0))`. Suppose to the contrary that for some `i` with `1 ≤ i < p` both `origin(a)ᵢ = 0` and `origin(a)ᵢ₊₁ = 0`; the comprehension equalities rewrite these as `r(i) = 0` and `r(i + 1) = 0` (the second licensed since `i < p` gives `i + 1 ≤ p` by NAT-discrete's discreteness, ASN-0034), so both `i` and `i + 1` lie in the zero-index set we pinned down exactly, `{#N(a) + 1, ((#N(a) + 1) + #U(a)) + 1}`. Writing `X` for the second zero position `((#N(a) + 1) + #U(a)) + 1`, each of `i` and `i + 1` independently equals one of the two members `#N(a) + 1` or `X` — a four-case domain, three of whose assignments we must eliminate before the fourth survives, naming for each the NAT-order clause that closes it rather than letting the orderings *force* the answer unexamined. *Case `i = #N(a) + 1` and `i + 1 = #N(a) + 1`:* the two right-hand sides coincide, so `i = i + 1` by transitivity of `=`; substituted into the successor ordering `i < i + 1` (NAT-addcompat's `n < n + 1`) this reads `i < i`, which NAT-order's irreflexivity `¬(i < i)` forbids. *Case `i = X` and `i + 1 = X`:* identically the right-hand sides coincide, `i = i + 1`, and again `i < i` against NAT-order's irreflexivity `¬(i < i)`. *Case `i = X` and `i + 1 = #N(a) + 1`:* substituting both into the separation `#N(a) + 1 < X` already established between the two zero positions yields `i + 1 < i`, which conjoined with the successor ordering `i < i + 1` is `i < i + 1 ∧ i + 1 < i` — exactly what NAT-order's exactly-one trichotomy clause `¬(i < i + 1 ∧ i + 1 < i)` (instantiated at `m := i`, `n := i + 1`) forbids, no element of ℕ both preceding and following another. *Case `i = #N(a) + 1` and `i + 1 = X`:* the sole assignment surviving the three eliminations, which we therefore carry forward — `i = #N(a) + 1` and `i + 1 = X = ((#N(a) + 1) + #U(a)) + 1`, the latter re-associated to `i + 1 = (#N(a) + 1) + (#U(a) + 1)` by the NAT-addassoc step already performed above. We pin the contradiction by computing the gap between these two supposedly consecutive indices in two ways and equating the results — an equation licensed because NAT-sub's partial subtraction is a *function*, so the same minuend-subtrahend pair has exactly one difference. Read off the adjacency itself, the indices are consecutive, and NAT-sub's left-telescoping `(n + m) − n = m` at `n := i`, `m := 1` returns `(i + 1) − i = 1`. Read off the field decomposition, that same difference `(i + 1) − i` — under `i = #N(a) + 1` and `i + 1 = (#N(a) + 1) + (#U(a) + 1)` — is `((#N(a) + 1) + (#U(a) + 1)) − (#N(a) + 1)`, which NAT-sub's left-telescoping at `n := #N(a) + 1`, `m := #U(a) + 1` returns as `#U(a) + 1`. Both expressions denote the one value `(i + 1) − i`; subtraction being single-valued, its two computed outputs coincide, so `1 = #U(a) + 1`. Now T4a's non-emptiness of the U field (`#U(a) ≥ 1`) lifts by NAT-addcompat (ASN-0034) to `#U(a) + 1 ≥ 2`, so substituting the equation just obtained gives `1 = #U(a) + 1 ≥ 2`, i.e. `1 ≥ 2`; with `2 > 1` (NAT-addcompat's strict successor at `n := 1`, giving `1 < 1 + 1 = 2`; NAT-order's `>`-definition converts this to `2 > 1`) we now hold both `1 ≥ 2` — equivalently `2 ≤ 1` by NAT-order's `≥`-definition `m ≥ n ⟺ n ≤ m` — and `2 > 1` — equivalently `1 < 2` by its `>`-definition `m > n ⟺ n < m` — from which the irreflexivity-violating `1 < 1` must be reached. This is not a single transitive step, for `2 ≤ 1` is a `≤`-bound, not a strict `<`, and the two readings it permits close by different principles: NAT-order defines `≤` as the disjunction `m ≤ n ⟺ m < n ∨ m = n`, so `2 ≤ 1` unfolds at `m := 2, n := 1` into the sub-cases `2 < 1` and `2 = 1`, and we reach `1 < 1` in each. In the strict sub-case `2 < 1`, NAT-order's transitivity axiom `m < n ∧ n < p ⟹ m < p` — both hypotheses now strict — chains `1 < 2` with `2 < 1` at `m := 1, n := 2, p := 1` to `1 < 1`. In the equality sub-case `2 = 1`, substituting `2 = 1` into that same strict inequality `1 < 2` by indiscernibility of `=` rewrites it directly to `1 < 1` — a congruence step the transitivity axiom does not supply. Either sub-case delivers `1 < 1`, which NAT-order's irreflexivity `¬(1 < 1)` refutes — irreflexivity of `<` at `1` is the contradicted fact. No such `i` exists. *First component non-zero* — `origin(a)₁ ≠ 0`. T4a's non-emptiness of the N field gives `#N(a) ≥ 1`, so position `1` falls in the leading node block, strictly before the first separator at `#N(a) + 1 ≥ 2`; the comprehension equality at `i = 1` reads `origin(a)₁ = r(1) = N(a)₁`, the first node component, which T4b postconditions strictly positive, so `origin(a)₁ ∈ ℕ⁺` and `origin(a)₁ ≠ 0`. *Last component non-zero* — `origin(a)ₚ ≠ 0` at the last position `p = #origin(a)`. T4a's non-emptiness of the D field gives `#D(a) ≥ 1`, so `p = (((#N(a) + 1) + #U(a)) + 1) + #D(a) ≥ (((#N(a) + 1) + #U(a)) + 1) + 1`, one position past the second separator at `((#N(a) + 1) + #U(a)) + 1`; position `p` thus falls in the trailing document block, and the comprehension equality at `i = p` reads `origin(a)ₚ = r(p) = D(a)_{#D(a)}`, the last document component, again strictly positive by T4b, so `origin(a)ₚ ≠ 0`. The three field-segment conjuncts assembled with the zero-count bound `zeros(origin(a)) = 2 ≤ 3` exhaust T4's T4-valid predicate `zeros(t) ≤ 3 ∧ (A i : 1 ≤ i < #t : ¬(tᵢ = 0 ∧ tᵢ₊₁ = 0)) ∧ t₁ ≠ 0 ∧ t_{#t} ≠ 0` at `t := origin(a)`; hence `origin(a)` is T4-valid, and only now — the level labels being defined precisely on the T4-valid subset — does its zero count `zeros(origin(a)) = 2` place `origin(a)` at the document level in T4's hierarchy.

**Identification.** By S7a (document-scoped allocation), every I-address is allocated under the tumbler prefix of the document that created it. The document-level prefix of `a` — precisely `origin(a)`, the tumbler `N.0.U.0.D` obtained by truncating the element field — identifies the document whose owner performed the allocation that placed `a` into `dom(C)`. This is not a lookup or annotation: the address structurally encodes its provenance. S7a ensures that `origin(a)` IS the allocating document's tumbler.

**Uniqueness across documents.** We must establish that distinct allocating documents yield distinct origins. S7d (DocumentAllocationDiscipline) supplies two facts: every document is addressed by a document-level tumbler arising from an allocation event under T10a's discipline, and distinct documents arise from distinct allocation *events*. The second fact separates distinct documents only at the level of events; what it does not by itself supply is the passage from distinct events to distinct *addresses* — for two distinct allocation events could, a priori, still emit the same tumbler value. That passage is exactly GlobalUniqueness (ASN-0034), whose invariant is that addresses arising from distinct allocation events in any reachable state are distinct. Its precondition is met here: S7d's first fact places each document-level tumbler as an address produced by an allocation event under T10a, so the two documents' tumblers are addresses of distinct allocation events. Instantiating GlobalUniqueness at those two events therefore lifts S7d's event-distinctness to tumbler-distinctness — distinct documents have distinct document-level tumblers. By T3 (CanonicalRepresentation, ASN-0034), this distinctness is decidable by component-wise comparison. Since the Identification step established that `origin(a)` IS the allocating document's tumbler, for any `a₁, a₂ ∈ dom(Σ.C)` allocated under distinct documents we conclude `origin(a₁) ≠ origin(a₂)`. The origin function discriminates allocating documents without ambiguity.

**Permanence.** By S0 (content immutability), once `a ∈ dom(Σ.C)`, then `a ∈ dom(Σ'.C)` for all successor states `Σ'` — the address persists. Since `a` is a tumbler — a fixed sequence of components, not a mutable reference — and `origin(a)` is computed from the components of `a` alone via T4's deterministic field decomposition, `origin(a)` yields the same result in every state in which `a` exists. ∎

*Formal Contract:*

- *Definition:* For `a ∈ dom(Σ.C)`, `origin(a) = N(a).0.U(a).0.D(a)` — the document-level tumbler obtained by truncating the element field `E(a)` from `a`, formed by concatenating the node field, a zero separator, the user field, a zero separator, and the document field.
- *Preconditions:* `a ∈ dom(Σ.C)`; `A_element ∈ 𝒯 ∧ a ∈ dom(A_element)` for the document owner's T10a-conforming element allocator (S7a) — the two memberships of distinct types that license T10a.4's instantiation at `A := A_element, t := a`, yielding `a` T4-valid; `zeros(a) = 3` (S7b, element-level I-address).
- *Postconditions:* `origin(a)` is a well-defined tumbler — `origin(a) ∈ T` by T0's comprehension clause, instantiated at the concatenation length `p = (((#N(a) + 1) + #U(a)) + 1) + #D(a) ≥ 1` and the component map carrying each position to its field component (in `ℕ⁺ ⊆ ℕ` by T4b) or to a zero separator (`0 ∈ ℕ`) — with `zeros(origin(a)) = 2` obtained by applying T4's zero-count definition `zeros(t) = |{i : 1 ≤ i ≤ #t ∧ tᵢ = 0}|` to that component map, whose only two zeros are the separators at `#N(a) + 1` and `((#N(a) + 1) + #U(a)) + 1` (distinct because the second strictly exceeds the first: from the additive form `((#N(a) + 1) + #U(a)) + 1 = (#N(a) + 1) + (#U(a) + 1)` (NAT-addassoc), NAT-addcompat's strict successor gives `#N(a) + 1 < (#N(a) + 1) + 1` and its left order-compatibility — adding `#N(a) + 1` on the left of `1 ≤ #U(a) + 1`, T4a's `#U(a) ≥ 1` lifted — gives `(#N(a) + 1) + 1 ≤ (#N(a) + 1) + (#U(a) + 1)`, the two chained by NAT-order's `≤`-definition and transitivity to `#N(a) + 1 < ((#N(a) + 1) + #U(a)) + 1`; their difference is `#U(a) + 1 ≥ 2`); `origin(a)` is moreover T4-valid — the four conjuncts of T4's T4-valid predicate `zeros(t) ≤ 3 ∧ (A i : 1 ≤ i < #t : ¬(tᵢ = 0 ∧ tᵢ₊₁ = 0)) ∧ t₁ ≠ 0 ∧ t_{#t} ≠ 0` discharged at `t := origin(a)` by `zeros(origin(a)) = 2 ≤ 3`, by the two zero positions being non-adjacent — their difference `#U(a) + 1 ≥ 2` (T4a's `#U(a) ≥ 1` via NAT-addcompat, as in the distinctness clause above) keeps the two separators at least two indices apart, hence never at consecutive positions `i`, `i + 1`, the full four-case adjacency contradiction being carried out in the Well-definedness section and not repeated here — and by the boundary components `origin(a)₁ = N(a)₁` and `origin(a)ₚ = D(a)_{#D(a)}` being strictly positive (T4b) at positions `1` and `p`, which lie in the node and document field blocks since `#N(a) ≥ 1` and `#D(a) ≥ 1` (T4a) — and it is this T4-validity that places `origin(a)` at the document level in T4's hierarchy; `origin(a)` equals the tumbler of the document that allocated `a` (S7a); for any `a₁, a₂ ∈ dom(Σ.C)` allocated under distinct documents, `origin(a₁) ≠ origin(a₂)` (S7d's distinct allocation events lifted to distinct addresses by GlobalUniqueness; decidable by T3).
- *Invariant:* For every `Σ → Σ'`, if `a ∈ dom(Σ.C)` then `a ∈ dom(Σ'.C)` (S0) and `origin(a)` is unchanged — the attribution is permanent and unseverable.
- *Frame:* `origin(a)` is a pure function of the components of `a` alone; it reads no state beyond `dom(Σ.C)` membership and modifies nothing.

Σ.C is reachable transitively through S7a and S7b — both ranging over this same `dom(Σ.C)` — but S7's direct use of the symbol in its definition, preconditions, and frame is what obliges the direct citation, so that the dependency specification is self-contained.
  - S0 (ContentImmutability) — supplies the persistence guarantee `a ∈ dom(Σ.C) ⟹ a ∈ dom(Σ'.C)` used in the Permanence step to establish that `origin(a)` is unchanged across all successor states
  - S7a (DocumentScopedAllocation) — supplies (i) the allocation rule that the document-level prefix of `a` equals the allocating document's tumbler, used in the Identification step to ground `origin(a) IS the allocating document's tumbler`; and (ii) the two memberships of distinct types `A_element ∈ 𝒯` (the element allocator is a node of the tree) and `a ∈ dom(A_element)` (the address lies in its domain), used in Well-definedness to license the T10a.4 instantiation at `A := A_element, t := a`

  - S7d (DocumentAllocationDiscipline) — supplies that every document's document-level tumbler arises from an allocation event under T10a's discipline and that distinct documents arise from distinct allocation *events*; the Uniqueness step feeds this event-level separation to GlobalUniqueness.
