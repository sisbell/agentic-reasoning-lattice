- `→` — binary state-transition relation; `Σ → Σ'` asserts that `Σ'` is a valid successor state of `Σ`
- `C` — content-map component of a state; `Σ.C` is the function mapping stored addresses to their content values in state `Σ`
- `dom` — domain operator on a map; `dom(Σ.C)` is the set of addresses at which content has been stored in state `Σ`
