Establishes referential integrity as a well-formedness invariant: every V-position in every document's arrangement must point to an I-address that exists in the content store, so there are no dangling references. Combined with S1's store monotonicity, this guarantees that once a reference is valid it remains valid through all subsequent transitions. The converse is deliberately excluded — content may persist in the store without being referenced by any current arrangement, which is required for historical reconstruction.
