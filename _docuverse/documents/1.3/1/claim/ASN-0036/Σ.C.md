**Σ.C (ContentStore).** The *content store* `Σ.C : T ⇀ Val`: a partial function mapping Istream addresses to content values. `T` is the set of tumblers (ASN-0034); `Val`, its codomain, is an unspecified nonempty set of content values, opaque at this level of abstraction. This codomain annotation `Σ.C : T ⇀ Val` is the content-side counterpart of the arrangement declaration `Σ.M(d) : T ⇀ T` (S2), and grounds every later use of `Val` — in particular the witnesses of S5, which draw an arbitrary `w ∈ Val`. The domain `dom(Σ.C)` is the set of I-addresses at which content has been stored.
