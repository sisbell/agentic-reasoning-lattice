**D-SEQ (SequentialPositions).** For each document d, if V_1(d) is non-empty, then there exists n ≥ 1 such that:

`V_1(d) = {[1, 1, ..., 1, k] : 1 ≤ k ≤ n}`

where the tuple has length m, the common V-position depth in the text subspace (S8-depth). By S8a, every V-position has depth `≥ 2`, so `m ≥ 2`; the derivation below relies on this lower bound. At depth 2 this gives V_1(d) = {[1, k] : 1 ≤ k ≤ n}, a single unbroken block of ordinals — the form contiguity (D-CTG, Step 3) acquires once the arrangement's finiteness (S8-fin, Step 4) bounds it — matching Nelson's "addresses 1 through n."

*Proof.* Let V_1(d) be non-empty and let m be the common depth of all V-positions in the text subspace (S8-depth guarantees a common depth exists). By S8a, every V-position has `#v ≥ 2`, so `m ≥ 2`.

**Step 1: shared prefix.** We show that every position in V_1(d) has the form [1, 1, …, 1, k] — that is, components 2 through m − 1 are all equal to 1, with only the last component varying.

*Case m = 2.* Every position has exactly two components. By the definition `V_1(d) = {v ∈ dom(M(d)) : subspace(v) = 1}` together with `subspace(v) = v₁`, every position in V_1(d) has `v₁ = 1` — the subspace identifier sits at component 1. The second component is a single ordinal. There are no intermediate components (components 2 through m − 1 is the empty range 2 through 1), so the shared-prefix condition holds vacuously. Every position is [1, k] for some k, which is [1, 1, …, 1, k] with zero intervening 1s.

*Case m ≥ 3.* By the definition `V_1(d) = {v ∈ dom(M(d)) : subspace(v) = 1}` together with `subspace(v) = v₁`, every position has `v₁ = 1` — the subspace identifier sits at component 1. By D-CTG-depth (SharedPrefixReduction), all positions in V_1(d) share components 2 through m − 1. By D-MIN (VMinimumPosition), the minimum element of V_1(d) is [1, 1, …, 1] — a tuple of length m with every component equal to 1. Since the minimum shares components 2 through m − 1 with every other position, and those components of the minimum are all 1, every position in V_1(d) has components 2 through m − 1 equal to 1. Together with `v₁ = 1`, every position is therefore [1, 1, …, 1, k] for some value k at the m-th component.

**Step 2: minimum k.** By D-MIN, min(V_1(d)) = [1, 1, …, 1] of length m. In the representation [1, 1, …, 1, k], the minimum has k = 1 at the last component. Since the minimum is in V_1(d), the set of k-values attained by positions in V_1(d) includes 1.

**Step 3: contiguity of k-values.** Let k₁ < k₂ be two values attained by positions v₁ = [1, 1, …, 1, k₁] and v₂ = [1, 1, …, 1, k₂] in V_1(d); the comparison `<` here — and every comparison among k-values below — is the strict total order on ℕ supplied by NAT-order (NatStrictTotalOrder, ASN-0034), the order on component values that T1's lexicographic rule consumes at the first differing component but does not itself re-export for arbitrary naturals. Both have subspace 1 and depth m. By T1(i) (LexicographicOrder, ASN-0034), v₁ < v₂ since they agree on components 1 through m − 1 and differ first at component m where k₁ < k₂. For any k ∈ ℕ with k₁ < k < k₂, form the tuple w = [1, 1, …, 1, k] of length m: its leading m − 1 components are all 1 ∈ ℕ — the constant `1` lying in ℕ by NAT-closure (NatArithmeticClosureAndIdentity, ASN-0034) — and its last component is k ∈ ℕ, so by T0's comprehension clause (CarrierSetDefinition, ASN-0034), instantiated at length m and this component map, w ∈ T. This w satisfies subspace(w) = 1, #w = m, and v₁ < w < v₂ (again by T1(i), since w agrees with both on components 1 through m − 1 and k₁ < k < k₂ at component m). Moreover we must discharge D-CTG's remaining guard `zeros(w) = 0`, where `zeros` is T4's zero-count `zeros(t) = |{i : 1 ≤ i ≤ #t ∧ tᵢ = 0}|` (HierarchicalParsing, ASN-0034). Writing `S = {i : 1 ≤ i ≤ #w ∧ wᵢ = 0}` for the index set `zeros` counts, NAT-card (NatFiniteSetCardinality, ASN-0034) fixes `|S|` as the unique `k ∈ ℕ` admitting a strictly increasing `f : {j : 1 ≤ j ≤ k} → ℕ` that enumerates `S` as `{f.j : 1 ≤ j ≤ k}`; instantiating that value-clause axiom at `k = 0`, the domain `{j : 1 ≤ j ≤ 0}` is empty, so the lone candidate `f` is the empty function with image `∅`, whence `k = 0` enumerates `S` exactly when `S = ∅` and, by the uniqueness of that `k`, `|S| = 0 ⟺ S = ∅`. NAT-card's contract exports this biconditional only as the `k = 0` instance of its value-clause axiom, not as a packaged empty-set consequence, so — on S8a's own stated terms for the identical fact ("not a packaged consequence... derive it here rather than cite it by name"), exactly as D-CTG-depth grounds it inline for its own constructed witness — we ground it here rather than attribute it to NAT-card as an already-exported characterization; nor may we borrow it from S8a, whose positivity *Consequence* is scoped to members of dom(Σ.M(d)) and so cannot certify the constructed w before w's own domain membership is in hand — deriving that membership, via D-CTG below, being the very point of this step. Reading `|S| = 0 ⟺ S = ∅` on `zeros(w) = |S|`, the guard `zeros(w) = 0` holds exactly when the zero-filter `S` is empty — that is, when no component of w is zero. Every component of w is strictly positive: the leading m − 1 components are each the constant `1`, positive by NAT-closure's *Consequence* `0 < 1` (read as `1 > 0`); and the last component k exceeds k₁ — the last component of v₁ ∈ V_1(d) ⊆ dom(M(d)), itself positive by S8a's positivity *Consequence* — so k > k₁ > 0 gives k > 0 by NAT-order's transitivity of `<` (`0 < k₁ < k ⟹ 0 < k`). Hence `(A i : 1 ≤ i ≤ #w : wᵢ > 0)`; each positive component is in particular non-zero, so the zero-filter `S` is empty and, by the `k = 0` biconditional just grounded, its cardinality is 0 — this is `zeros(w) = 0`. The depth half #w = m ≥ 2 inherits the bound S8a places on v₁. With w ∈ T grounding D-CTG's inner v ∈ T quantifier, D-CTG (VContiguity) gives w ∈ V_1(d). Therefore every k ∈ ℕ between any two attained k-values is itself attained — the k-values form a contiguous range.

**Step 4: finiteness.** By S8-fin (Finite arrangement), dom(M(d)) is finite, so V_1(d) ⊆ dom(M(d)) is finite. The k-values form a finite contiguous range.

**Assembly.** The k-values form a finite contiguous set of positive integers (Step 3, Step 4) that contains 1 (Step 2). To pin the postcondition's bound n we must exhibit a *greatest* k-value, and the strict total order alone does not hand us one: NAT-order's irreflexivity, transitivity, and trichotomy order any two naturals but carry no greatest-element principle for a finite set — ℕ has no top, so a greatest element must be *built* from finiteness, not read off the order — and NAT-wellorder furnishes least, not greatest, elements. We build it by induction on the enumeration S8-fin already supplies.

By S8-fin (FiniteArrangement) there are an N ∈ ℕ and a bijection f : {j ∈ ℕ : 1 ≤ j ≤ N} → dom(Σ.M(d)); since V_1(d) ≠ ∅ and V_1(d) ⊆ dom(Σ.M(d)), f's surjectivity lands some index in Q₀ = {j ∈ ℕ : 1 ≤ j ≤ N ∧ f.j ∈ V_1(d)}, so Q₀ ≠ ∅ and N ≥ 1. Define e : {j ∈ ℕ : 1 ≤ j ≤ N} → ℕ by e.j = k when f.j ∈ V_1(d) carries the Step 1 form [1, 1, …, 1, k] (its last component, an attained k-value), and e.j = 1 otherwise. The image {e.j : j ∈ Q₀} is exactly the set of k-values: each e.j with j ∈ Q₀ is an attained value by construction, and conversely every attained k is the last component of some v ∈ V_1(d), which is f.j for some j — necessarily j ∈ Q₀, since f.j = v ∈ V_1(d) — by f's surjectivity, whence e.j = k.

Writing `a ≤ b` for NAT-order's reflexive closure `a < b ∨ a = b`, we now establish, by induction on N, the *greatest-element principle* P(N): *for every h : {j ∈ ℕ : 1 ≤ j ≤ N} → ℕ and every non-empty Q ⊆ {j ∈ ℕ : 1 ≤ j ≤ N} there is an index J ∈ Q with `(A j : j ∈ Q : h.j ≤ h.J)`*. The recursion is the from-`1` specialization of NAT-induction's (NatInduction) generation-from-`0` principle: over the NAT-* axioms induction is not derivable from the order, so well-ordering — which would in any case extract a *least* element — cannot drive it. NAT-induction generates its predicate from the base element `0`, so the formal base of our induction is P(0), and the from-`1` reading is no shortcut around that base but the assertion P(0) ⇒ P(1), which the step below discharges. *Base N = 0:* the index segment {j ∈ ℕ : 1 ≤ j ≤ 0} is empty — no natural j meets 1 ≤ j ≤ 0 — so it carries no non-empty subset Q at all, and P(0)'s universal guard *(for every non-empty Q ⊆ {j : 1 ≤ j ≤ 0} …)* is unmet; P(0) holds vacuously, NAT-induction's own from-`0` base. *Step N → N + 1:* take a non-empty Q ⊆ {j ∈ ℕ : 1 ≤ j ≤ N + 1} and set Q⁻ = Q ∩ {j : 1 ≤ j ≤ N}, the successor decomposition splitting the segment at its top index N + 1. The split rests on the segment identity {j : 1 ≤ j ≤ N + 1} = {j : 1 ≤ j ≤ N} ∪ {N + 1}, an inference of *index* arithmetic on ℕ — distinct from the value comparisons the induction otherwise runs on the h.j, though both fall to NAT-order here — holding in both directions by the discreteness of ℕ at a successor, the dual of the identity D-MIN's parallel least-element induction establishes. For ⊇, each element of the right-hand union must meet both bounds 1 ≤ j and j ≤ N + 1 of the left-hand segment: an index j with 1 ≤ j ≤ N carries its lower bound 1 ≤ j unchanged and meets the upper bound because NAT-addcompat's strict successor inequality N < N + 1 chains with j ≤ N under NAT-order's transitivity to j ≤ N + 1, while the singleton's element N + 1 owes its upper bound N + 1 ≤ N + 1 to the equality disjunct of NAT-order's ≤-definition m ≤ n ⟺ m < n ∨ m = n and its lower bound 1 ≤ N + 1 — not reflexive, and so derived — to a three-step seed at the floor of ℕ: NAT-zero's second clause (A n ∈ ℕ :: 0 < n ∨ 0 = n) at n := N reads 0 ≤ N, NAT-addcompat's right-order compatibility (A m, n, p ∈ ℕ : p ≤ n : p + m ≤ n + m) at p := 0, n := N, m := 1 discharges that antecedent to 0 + 1 ≤ N + 1, and NAT-closure's left identity (A n ∈ ℕ :: 0 + n = n) at n := 1 rewrites 0 + 1 to 1, delivering 1 ≤ N + 1. For ⊆, an index with 1 ≤ j ≤ N + 1 is either N + 1 itself — landing in the singleton — or has j ≠ N + 1, hence j < N + 1; were N < j, NAT-discrete's m < n ⇒ m + 1 ≤ n at (N, j) would force N + 1 ≤ j, collapsing against j < N + 1 to N + 1 < N + 1, barred by NAT-order's irreflexivity, so ¬(N < j) and thus j ≤ N by NAT-order's totality. Nothing strictly between N and N + 1 escapes the split. If Q⁻ = ∅ then Q = {N + 1} and J = N + 1 serves, `h.(N + 1) ≤ h.(N + 1)` by reflexivity (the equality disjunct of `≤`); instantiated at N = 0 — where {j : 1 ≤ j ≤ 1} = {1} forces Q⁻ = Q ∩ ∅ = ∅, hence Q = {1} and J = 1 — this branch is exactly the bridge P(0) ⇒ P(1), recovering the lone-index maximum the from-`1` reading takes as its base. Otherwise the induction hypothesis P(N), applied to h restricted to {j ∈ ℕ : 1 ≤ j ≤ N} and the non-empty Q⁻, hands an index J′ ∈ Q⁻ with h.j ≤ h.J′ for all j ∈ Q⁻. If N + 1 ∉ Q then Q = Q⁻ and J = J′ serves. If N + 1 ∈ Q, NAT-order's trichotomy on (h.J′, h.(N + 1)) leaves h.(N + 1) < h.J′, h.(N + 1) = h.J′, or h.J′ < h.(N + 1). The first two give h.(N + 1) ≤ h.J′, so J = J′ still maximizes over all of Q: every j ∈ Q⁻ has h.j ≤ h.J′, and the new index satisfies h.(N + 1) ≤ h.J′. The third gives J = N + 1: every j ∈ Q⁻ has h.j ≤ h.J′ < h.(N + 1), hence h.j ≤ h.(N + 1) by the mixed `≤`-then-`<` step — split on the `≤`-definition, `h.j < h.J′` closing through NAT-order's pure `<`-transitivity and `h.j = h.J′` through indiscernibility of `=` — while h.(N + 1) ≤ h.(N + 1) by reflexivity. P(N + 1) holds, and the induction closes.

Instantiating P at h := e and Q := Q₀ yields an index J ∈ Q₀ with e.j ≤ e.J throughout Q₀; since J ∈ Q₀ the value e.J is f.J's last component, an attained k-value, and we set n = e.J. As the image of e over Q₀ is exactly the k-values, n is a k-value and dominates every k-value — the greatest element sought. Then n ≥ 1, since the attained value 1 gives 1 ≤ n. By Step 3 applied between the attained endpoints 1 and n, every integer with 1 < k < n is attained, so with the endpoints themselves {1, …, n} ⊆ k-values; and n dominating every k-value gives k-values ⊆ {1, …, n}. Hence the k-values are exactly {1, 2, …, n}. By Step 1, V_1(d) = {[1, 1, …, 1, k] : 1 ≤ k ≤ n}. ∎

D-CTG is a design constraint on well-formed document states. We verify the base case: before any operations, dom(M(d)) = ∅ for all d (the arrangement is a partial function; no content has been allocated, so no V-mapping exists), so V_1(d) = ∅. D-CTG holds vacuously (no u, q exist to trigger its antecedent), and D-MIN holds vacuously (its antecedent requires V_1(d) non-empty).

*Formal Contract:*

- *Preconditions:* V_1(d) is non-empty. The document state is well-formed, so the contiguity constraint D-CTG (VContiguity) and the minimality property D-MIN (VMinimumPosition) hold. All V-positions in the text subspace share a common depth m (S8-depth), with `m ≥ 2` (S8a), and dom(M(d)) is finite (S8-fin).
- *Postconditions:* There exists n ≥ 1 such that V_1(d) = {[1, 1, …, 1, k] : 1 ≤ k ≤ n}, where each tuple has length m. Equivalently, the m-th-component values attained by the positions of V_1(d) are exactly the contiguous set {1, 2, …, n}.
- *Invariant:* In every well-formed state reachable from the empty base state (dom(M(d)) = ∅), D-CTG and D-MIN hold, and consequently V_1(d) is either empty or of the sequential form {[1, 1, …, 1, k] : 1 ≤ k ≤ n}. Across each transition s → s' that preserves well-formedness, this characterization is preserved; the base state satisfies it vacuously since V_1(d) = ∅.

The *existence* of the greatest element n is not the order's to give: a finite non-empty subset of ℕ has a greatest element by induction on the enumeration length (NAT-induction, below), the strict total order furnishing no greatest-element principle of its own — ℕ has no top. Once n is in hand, the range bounds `1 ≤ k ≤ n` are read in this order
