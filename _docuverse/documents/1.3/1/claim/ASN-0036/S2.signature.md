- `Σ.M` — the arrangement component of the strand state; declared as a partial function `T ⇀ T` mapping each document's V-positions to I-addresses
- `T` — the common carrier type serving as both domain and codomain of the arrangement mapping
- `⇀` — the partial-function type constructor; `A ⇀ B` denotes the type of partial functions from `A` to `B` (at most one image per domain element)
- `dom` — the domain-of-definition operator; `dom(f)` is the set of arguments on which partial function `f` is defined
