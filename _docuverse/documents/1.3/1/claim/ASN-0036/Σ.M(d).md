**Σ.M(d) (Arrangement).** The second component of the strand state is the object an edit mutates. Where the content store `Σ.C` (ContentStore) holds *what* has been written and never changes, the *arrangement* of a document records *how* that document currently lays its content out — and it is exactly this component that editing rewrites. We are naming that object and fixing its type.

For a document `d` we write `Σ.M(d)` for its arrangement and posit it a partial function on the tumbler carrier `T`:

`Σ.M(d) : T ⇀ T`

`T` is the carrier set of tumblers (CarrierSetDefinition, ASN-0034) — the same carrier at whose addresses `Σ.C : T ⇀ Val` stores content. Both ends of the arrangement live in that one carrier: a domain element is a *Vstream position*, the coordinate at which content appears in the reader's view of `d`, and a range element is an *Istream address*, the permanent location at which the referenced content is stored. The arrangement is the value at `d` of a family `Σ.M`; each document is itself named by a document-level tumbler, `d ∈ T`, so `Σ.M` assigns to every `d ∈ T` its arrangement `Σ.M(d) : T ⇀ T`.

The partiality is the substance of the declaration, not decoration. A document arranges only finitely many of the infinitely many tumblers `T` admits, so we read `dom(Σ.M(d))` — the domain of definition of the partial function `Σ.M(d)` — as the set of V-positions *currently active* in `d`, a subset of the carrier: `dom(Σ.M(d)) ⊆ T`. Its image `ran(Σ.M(d)) ⊆ T` is the set of I-addresses `d` currently references. Writing the type with the partial arrow `⇀` rather than the total `→` is precisely what licenses every later claim to treat `dom(Σ.M(d))` as a proper subset of `T` and to apply `Σ.M(d)(v)` only under the guard `v ∈ dom(Σ.M(d))` — the strict partial-function reading AX-2 leans on when it carries that guard explicitly before evaluating `Σ.M(d)(v)`.

We fix the type and nothing more. This claim posits the arrangement as a per-document `T ⇀ T` partial function and names its domain and range; it imposes no constraint on *which* arrangements may arise. Those constraints are the work of the claims downstream, each of which grounds the arrangement symbol it speaks of here, at this defining claim: AX-1 fixes the base arrangement empty, AX-2 grounds every newly established mapping in stored content, S2 reads single-valuedness off the very `T ⇀ T` type fixed here, S8a confines the active keys to well-formed V-positions, S8-depth makes a subspace's active keys share one depth, and V-sub carves `dom(Σ.M(d))` into per-subspace projections. Each speaks of `Σ.M(d)` or `dom(Σ.M(d))`; each is grounded at the type this claim supplies.

*Formal Contract:*

- *Definition:* The *arrangement* `Σ.M` assigns to each document `d ∈ T` — a document-level tumbler — its arrangement `Σ.M(d) : T ⇀ T`, a partial function on the tumbler carrier `T` (CarrierSetDefinition, ASN-0034). A domain element of `Σ.M(d)` is a *Vstream position* and a range element an *Istream address*, each a tumbler in `T`. The domain of definition `dom(Σ.M(d)) ⊆ T` is the set of V-positions currently active in `d`; the image `ran(Σ.M(d)) ⊆ T` is the set of I-addresses `d` currently references; the application `Σ.M(d)(v)` is defined exactly for `v ∈ dom(Σ.M(d))`. The partial-function arrow `⇀` and the domain-of-definition operator `dom(·)` are the ambient partial-function vocabulary; for `Σ.M(d)` they are fixed by this declaration, so `dom(Σ.M(d))` denotes the domain on which the posited `T ⇀ T` partial function is defined. The definition introduces no constraint of its own beyond typing the arrangement as a per-document `T ⇀ T` partial function and naming its domain and range.

- *Depends:*
  - T0 (CarrierSetDefinition, ASN-0034) — supplies the carrier set `T` of tumblers in which every position of the arrangement lives: the document index `d ∈ T`, the Vstream positions of `dom(Σ.M(d)) ⊆ T`, and the Istream addresses of `ran(Σ.M(d)) ⊆ T` are all elements of this one carrier, and `Σ.M(d) : T ⇀ T` is typed by it at both ends. Grounding `T` here is what lets every claim that later reads `dom(Σ.M(d))` — AX-1, AX-2, S2, S8a, S8-depth, V-sub — rest on a typed carrier rather than an ungrounded symbol; the same carrier `Σ.C` draws on for its own `T ⇀ Val` declaration
