**D-MIN (VMinimumPosition).** For each document d with V_1(d) non-empty:

`min(V_1(d)) = [1, 1, ..., 1]`

where the tuple has length m — the common depth of V-positions in the text subspace, fixed by S8-depth — and every component is 1. At depth 2 this reads min(V_1(d)) = [1, 1].

This is a *design requirement* on well-formed strand states, not a derived result. We are fixing where a document's text begins. V-positions are 1-indexed: by convention every component is counted upward from 1, so the least position the text subspace can offer is the all-ones tuple [1, 1, ..., 1]. That tuple stands as a first-class constant on the right of the equation, so before we may equate min(V_1(d)) to it we must establish that it names a genuine tumbler. T0's comprehension axiom, instantiated at length p = m (the common depth fixed by S8-depth; m ≥ 1, every tumbler being nonempty) and the constant component map r ≡ 1, yields a t ∈ T with #t = m and tᵢ = 1 at every index i — exactly [1, 1, ..., 1] — and its single component value is the natural number 1 ∈ ℕ that NAT-closure names. D-MIN requires that a non-empty document actually *reaches* that floor — its text block is anchored at the origin of its subspace. We call this the *left-anchoring* invariant and impose it on every reachable state.

**Existence and uniqueness of the minimum.** Before we may write min(V_1(d)) at all we owe its well-definedness — that a non-empty V_1(d) carries a unique `<`-least element. T1 renders any two tumblers comparable (totality) and chains comparisons (transitivity), but pairwise comparability does not of itself deliver a global minimum over the whole finite set: that an arbitrary traversal of V_1(d) settles on the `<`-least element is a statement about the *cardinality* of V_1(d), won by induction on it, not read off the order axioms. NAT-wellorder is no shortcut — it well-orders ℕ, whereas V_1(d) ⊆ T holds *tumblers*, and we have established no order-preserving injection of (T, `<`) into (ℕ, <). We induct instead on the length of S8-fin's enumeration, the very shape D-SEQ's Assembly runs for the dual greatest-element fact.

By S8-fin there are an N ∈ ℕ and a bijection f : {j ∈ ℕ : 1 ≤ j ≤ N} → dom(Σ.M(d)); since V_1(d) ≠ ∅ and V_1(d) ⊆ dom(Σ.M(d)), f's surjectivity lands some index in Q₀ = {j : 1 ≤ j ≤ N ∧ f.j ∈ V_1(d)}, so Q₀ ≠ ∅ and N ≥ 1. Writing `t ≤ t'` for the reflexive closure `t < t' ∨ t = t'` of T1's order, we establish by induction on N the *least-index principle* P(N): *for every g : {j ∈ ℕ : 1 ≤ j ≤ N} → T and every non-empty Q ⊆ {j : 1 ≤ j ≤ N} there is a J ∈ Q with `(A j : j ∈ Q : g.J ≤ g.j)`*. The recursion is the from-`1` specialization of NAT-induction's (NatInduction) generation-from-`0` principle; over the NAT-* axioms the order does not entail this induction, so neither T1's order on T nor any well-ordering of ℕ drives it — NAT-induction does. NAT-induction generates its predicate from the base element `0`, so the formal base of our induction is P(0), and the from-`1` reading is no shortcut around that base but the assertion P(0) ⇒ P(1), which the step below discharges. *Base N = 0:* the index segment {j ∈ ℕ : 1 ≤ j ≤ 0} is empty — no natural j meets 1 ≤ j ≤ 0 — so it carries no non-empty subset Q at all, and P(0)'s universal guard *(for every non-empty Q ⊆ {j : 1 ≤ j ≤ 0} …)* is unmet; P(0) holds vacuously. *Step N → N + 1:* take a non-empty Q ⊆ {j : 1 ≤ j ≤ N + 1} and set Q⁻ = Q ∩ {j : 1 ≤ j ≤ N}, the successor decomposition splitting the segment at its top index N + 1. The split rests on the segment identity {j : 1 ≤ j ≤ N + 1} = {j : 1 ≤ j ≤ N} ∪ {N + 1}, the one inference in this proof carried by the *index* arithmetic on ℕ rather than by T1's order on tumblers, and it holds in both directions by the discreteness of ℕ at a successor. For ⊇, each element of the right-hand union must meet both bounds 1 ≤ j and j ≤ N + 1 of the left-hand segment. An index j with 1 ≤ j ≤ N carries its lower bound 1 ≤ j unchanged and meets the upper bound because NAT-addcompat's strict successor inequality N < N + 1 chains with j ≤ N under NAT-order's transitivity to j ≤ N + 1. The singleton's element N + 1 owes the two bounds separately. Its upper bound N + 1 ≤ N + 1 holds reflexively, by the equality disjunct of NAT-order's ≤-definition m ≤ n ⟺ m < n ∨ m = n. Its lower bound 1 ≤ N + 1 is not reflexive and must be derived; we seed it at the floor of ℕ in three steps. NAT-zero's second clause (A n ∈ ℕ :: 0 < n ∨ 0 = n) at n := N reads 0 < N ∨ 0 = N — that is, 0 ≤ N under the same ≤-definition; NAT-addcompat's right-order compatibility (A m, n, p ∈ ℕ : p ≤ n : p + m ≤ n + m) at p := 0, n := N, m := 1 discharges its antecedent 0 ≤ N and yields 0 + 1 ≤ N + 1; and NAT-closure's left identity (A n ∈ ℕ :: 0 + n = n) at n := 1 rewrites 0 + 1 to 1, delivering 1 ≤ N + 1. So N + 1 meets both bounds and lies in {j : 1 ≤ j ≤ N + 1}; the floor 0 ≤ N that NAT-zero supplies is the seed this lower bound needs, the one ingredient neither T1's order on tumblers nor the index successor inequality provides on its own. For ⊆, an index with 1 ≤ j ≤ N + 1 is either N + 1 itself — landing in the singleton — or has j ≠ N + 1, hence j < N + 1; and were N < j, NAT-discrete's m < n ⇒ m + 1 ≤ n at (N, j) would force N + 1 ≤ j, which we split on NAT-order's ≤-definition m ≤ n ⟺ m < n ∨ m = n at (N + 1, j): the case N + 1 < j chains with j < N + 1 through pure `<`-transitivity to N + 1 < N + 1, the case N + 1 = j rewrites j < N + 1 under indiscernibility of `=` to N + 1 < N + 1 — both barred by NAT-order's irreflexivity, so ¬(N < j) and thus j ≤ N by NAT-order's totality. Nothing strictly between N and N + 1 escapes the split. If Q⁻ = ∅ then Q = {N + 1} and J = N + 1 serves, `g.(N + 1) ≤ g.(N + 1)` by reflexivity (the equality disjunct of `≤`); instantiated at N = 0 — where {j : 1 ≤ j ≤ 1} = {1} forces Q⁻ = Q ∩ ∅ = ∅, hence Q = {1} and J = 1 — this branch is exactly the bridge P(0) ⇒ P(1), recovering the lone-index minimum the from-`1` reading takes as its base. Otherwise the induction hypothesis P(N), applied to g restricted to {j : 1 ≤ j ≤ N} and the non-empty Q⁻, returns a J′ ∈ Q⁻ with `g.J′ ≤ g.j` for all j ∈ Q⁻. If N + 1 ∉ Q then Q = Q⁻ and J = J′ serves. If N + 1 ∈ Q, T1's totality decides the pair (g.(N + 1), g.J′) by trichotomy: either `g.J′ ≤ g.(N + 1)`, whence J = J′ minimizes over all of Q — over Q⁻ by hypothesis and at N + 1 by this very comparison — or `g.(N + 1) < g.J′`, whence for each j ∈ Q⁻ the mixed chain `g.(N + 1) < g.J′ ≤ g.j` closes to `g.(N + 1) ≤ g.j` by T1's transitivity, split on the `≤`: `g.J′ < g.j` through pure `<`-transitivity, `g.J′ = g.j` by rewriting `g.(N + 1) < g.J′` under indiscernibility of `=`; with `g.(N + 1) ≤ g.(N + 1)` by reflexivity, J = N + 1 minimizes over Q. P(N + 1) holds, and the induction closes.

Instantiating P at g := f and Q := Q₀ returns a J ∈ Q₀ — so f.J ∈ V_1(d) — with `f.J ≤ f.j` for every j ∈ Q₀. Every v ∈ V_1(d) is f.j for some j ∈ Q₀ — f surjects onto dom(Σ.M(d)) ⊇ V_1(d), and f.j = v ∈ V_1(d) places that j in Q₀ — so `f.J ≤ v` throughout V_1(d): a least element exists, and min(V_1(d)) = f.J. Uniqueness is minimality and T1's trichotomy together, in two steps. Two least elements μ, μ′ each minimize over V_1(d), so `μ ≤ μ′` and `μ′ ≤ μ`; and T1's trichotomy admits *exactly one* of `μ < μ′`, `μ = μ′`, `μ′ < μ`. Trichotomy does not of itself bar the two strict cases — it merely names them as alternatives; each is barred only by combining the opposite minimality bound with one of T1's incompatibility clauses. Were `μ < μ′`, then `μ′ ≤ μ` — that is, `μ′ < μ ∨ μ′ = μ` — would give in its first disjunct `μ < μ′ ∧ μ′ < μ`, barred by `¬(a < b ∧ b < a)` at (a, b) := (μ, μ′), and in its second `μ < μ′ ∧ μ = μ′`, barred by `¬(a < b ∧ a = b)` at (a, b) := (μ, μ′); so `μ < μ′` is impossible. Were instead `μ′ < μ`, then `μ ≤ μ′` — that is, `μ < μ′ ∨ μ = μ′` — would give in its first disjunct `μ′ < μ ∧ μ < μ′`, again barred by `¬(a < b ∧ b < a)` at (a, b) := (μ, μ′), and in its second `μ′ < μ ∧ μ′ = μ`, barred by `¬(a < b ∧ a = b)` at (a, b) := (μ′, μ); so `μ′ < μ` is impossible too. With both strict cases eliminated, trichotomy's one surviving alternative is `μ = μ′`. So min(V_1(d)) is well-defined whenever V_1(d) ≠ ∅, grounded on S8-fin's enumeration of the single finite set and NAT-induction's principle over its length — no well-ordering of the infinite position space is invoked.

**Non-derivability from the other constraints.** D-MIN is logically independent of contiguity (D-CTG), positivity and depth (S8a), and finiteness (S8-fin) — none of them entails left-anchoring, so D-MIN cannot be a theorem over them. A depth-2 witness:

`V_1(d) = {[1, 5], [1, 6], [1, 7]}.`

It is contiguous in the sense D-CTG demands — that betweenness obligation quantifies only over the same-depth text-subspace positions (those `v` with `#v = #u` and `subspace(v) = 1`, exactly D-CTG's inner-quantifier guards), and the only such position strictly between its extremes [1, 5] and [1, 7] is [1, 6], which is present, so there is no internal gap; a deeper tumbler like [1, 5, 1] does satisfy [1, 5] < [1, 5, 1] < [1, 7] under T1's order on all of T, but D-CTG's depth guard `#v = #u` excludes it from the obligation — every component is strictly positive at the common depth 2 (S8a, S8-depth), and the set is finite (S8-fin); yet

`min({[1, 5], [1, 6], [1, 7]}) = [1, 5] ≠ [1, 1].`

A contiguous, positive, finite, fixed-depth block can thus float above the origin — exactly what D-MIN rules out.

**The base state and downstream use.** Before any operation, dom(Σ.M(d)) = ∅ for every d, so V_1(d) = ∅ and the requirement is vacuous: its guard (V_1(d) non-empty) is unmet. The first transition that populates a document's text subspace must place its initial position at [1, 1, ..., 1], and from then on min(V_1(d)) is pinned to the all-ones tuple. The downstream claims consume D-MIN in exactly this posited form: D-SEQ reads min(V_1(d)) = [1, ..., 1] to fix the shared prefix and the least last-component value, and ValidInsertionPosition / ValidFirstInsertionPosition build their satisfying positions outward from it.

*Formal Contract:*

- *Design Requirement:* For every reachable state Σ and each document d with V_1(d) ≠ ∅, min(V_1(d)) = [1, 1, ..., 1] — the length-m tuple (m the common V-position depth fixed by S8-depth) with every component 1; at depth 2, min(V_1(d)) = [1, 1]. This is posited as an invariant of every well-formed strand state (the left-anchoring of a document's text at its subspace origin); it is *not* entailed by D-CTG, S8a, and S8-fin, witnessed by the contiguous, positive, finite, depth-2 set {[1, 5], [1, 6], [1, 7]}, whose minimum is [1, 5] ≠ [1, 1].
- *Definition:* min(S) denotes the unique `<`-least element of S under T1's strict total order `<` on tumblers (LexicographicOrder, ASN-0034), which restricted to the fixed depth m is exactly lexicographic order on integer m-tuples. We apply min only to S = V_1(d), finite by S8-fin (V_1(d) ⊆ dom(Σ.M(d))). That a least element *exists and is unique* is not delivered by T1's totality and transitivity alone — these compare tumblers pairwise but do not of themselves reach a global minimum over a finite set; existence is established in the body paragraph "Existence and uniqueness of the minimum" by induction (NAT-induction) on the length N of S8-fin's enumerating bijection f : {j ∈ ℕ : 1 ≤ j ≤ N} → dom(Σ.M(d)), the dual of the greatest-element induction D-SEQ's Assembly runs, with T1 serving only as the comparison engine and uniqueness following from its trichotomy *together with* its incompatibility clauses `¬(a < b ∧ b < a)` and `¬(a < b ∧ a = b)` applied to the two minimality bounds `μ ≤ μ′` and `μ′ ≤ μ` — trichotomy alone names the strict cases but does not bar them. We need no well-ordering of the infinite position space, only the finiteness of the single set to which min is applied.

The ≤-definition is read twice in the ⊇ direction: it unfolds NAT-zero's clause 0 < N ∨ 0 = N into the floor 0 ≤ N that seeds the singleton's lower bound, and its equality disjunct (N + 1 = N + 1) supplies that same singleton's reflexive upper bound N + 1 ≤ N + 1; and once more in the ⊆ direction, where it splits NAT-discrete's N + 1 ≤ j into N + 1 < j ∨ N + 1 = j so that against j < N + 1 each disjunct yields N + 1 < N + 1 — the first by `<`-transitivity, the second by substitution of `=`. The three strict-order rules are: (i) ≤-transitivity — its exported consequence m ≤ n ∧ n ≤ p ⇒ m ≤ p — in the ⊇ direction, closing j ≤ N ∧ N ≤ N + 1 ⇒ j ≤ N + 1 once NAT-addcompat supplies N < N + 1 (weakened to N ≤ N + 1); (ii) irreflexivity (A n ∈ ℕ :: ¬(n < n)) in the ⊆ direction, discharging the N + 1 < N + 1 contradiction that the ≤-definition's split of NAT-discrete's N + 1 ≤ j yields against j < N + 1; and (iii) at-least-one trichotomy (A m, n ∈ ℕ :: m < n ∨ m = n ∨ n < m) in that same ⊆ direction, supplying j ≤ N once N < j is ruled out.
