**S3 (ReferentialIntegrity).** `(A d, v : v ∈ dom(Σ.M(d)) : Σ.M(d)(v) ∈ dom(Σ.C))`

Every V-reference resolves. If a document's arrangement says "at position `v`, display the content at I-address `a`," then `a` must lie in `dom(C)`. There are no dangling references.

We read S3 as an invariant on the reachable states — the configurations generated from the base state by the transition relation `Σ → Σ'`. So phrased, it is not a property of any single signature declaration; it constrains how `M` and `C` evolve together, and the instrument that fits is induction on the generating transitions. We are therefore looking for two ingredients — an anchor for the initial configuration and a step carrying the property across one transition — and we must name each, for neither falls out of the content-store invariants alone: those govern `C`, whereas S3 governs the interplay of `M` with `C`.

*Proof.* By induction on the transition sequence from the base state `Σ₀`.

**Base case.** AX-1 (InitialEmpty) fixes `dom(Σ₀.M(d)) = ∅` for every `d`. The range of S3's quantifier — `v ∈ dom(Σ₀.M(d))` — is then empty, so the invariant holds vacuously at `Σ₀`: there is no mapped position to witness a dangling reference.

**Inductive step.** Take the induction hypothesis

  J0:  `(A d, v : v ∈ dom(Σ.M(d)) : Σ.M(d)(v) ∈ dom(Σ.C))`

at a state `Σ`, and let `Σ → Σ'` be any transition. Fix `d` and a position `v ∈ dom(Σ'.M(d))`, and abbreviate `a = Σ'.M(d)(v)`; we must show `a ∈ dom(Σ'.C)`. The mapping `(d, v) ↦ a` carried by `Σ'` is either inherited unchanged from `Σ` or it is not, and these two cases exhaust the possibilities:

- *Inherited:* `v ∈ dom(Σ.M(d))` and `Σ'.M(d)(v) = Σ.M(d)(v)`. Then `a = Σ.M(d)(v)`, so J0 — applicable because its range `v ∈ dom(Σ.M(d))` is met — gives `a ∈ dom(Σ.C)`. S1 (StoreMonotonicity) supplies `dom(Σ.C) ⊆ dom(Σ'.C)`, whence `a ∈ dom(Σ'.C)`. This is the half S1 discharges: a reference already valid at `Σ` cannot become dangling, because the address it names cannot leave the store.

- *New or redirected:* `v ∉ dom(Σ.M(d))`, or else `v ∈ dom(Σ.M(d))` but `Σ'.M(d)(v) ≠ Σ.M(d)(v)`. This is precisely the transition type the store invariants cannot speak to — a reference that did not exist, or pointed elsewhere, in `Σ`. AX-2 (GroundedExtension) is the protocol posit that covers it: its range is exactly this disjunction, and it yields `a = Σ'.M(d)(v) ∈ dom(Σ'.C)` directly.

In both cases `a ∈ dom(Σ'.C)`. Since `d` and `v` were arbitrary, S3 holds at `Σ'`, and the induction is complete: S3 holds in every reachable state. ∎

It is worth saying why S1 alone does not close the argument — the gap the step's second case fills. S1 preserves references that are *already* valid; it is silent on whether a transition may install a fresh mapping `Σ'.M(d)(v) = a` with `a ∉ dom(Σ'.C)`. Nothing in the content-store invariants forbids an arrangement from naming an as-yet-unstored address; that prohibition lives on the write side of the protocol and is recorded as AX-2. S3 is thus the join of two independent facts — monotone retention of the store (S1) and grounded extension of arrangements (AX-2) — over a base state pinned empty (AX-1). The earlier reading, that S1 alone forces `a ∈ dom(Σ'.C)` for any mapping established by a transition, conflated these: it assumed precisely the new-reference half that AX-2, not S1, supplies.

In the other direction, S3 imposes no obligation that stored content be referenced: its quantifier ranges over `dom(M(d))`, never over `dom(C)`. Content unreferenced by any current arrangement therefore persists untouched — S1's monotonicity `dom(Σ.C) ⊆ dom(Σ'.C)` is unconditioned on whether `a` appears in any `ran(M(d))`, so orphaned content is never reclaimed. Nelson requires exactly this for history — he calls such content "deleted bytes — not currently addressable, awaiting historical backtrack functions, may remain included in other versions" — and version reconstruction depends on the continued availability of Istream fragments from prior arrangements. We record this as a remark on the reach of store monotonicity, not as a step in the proof above.

*Formal Contract:*
- *Preconditions:* AX-1 (InitialEmpty) fixes the base state with `dom(Σ₀.M(d)) = ∅` for all `d`; AX-2 (GroundedExtension) constrains every transition `Σ → Σ'`; S1 (StoreMonotonicity) holds across every transition.
- *Invariant:* In every state reachable from the base state `Σ₀` by the transition relation, `(A d, v : v ∈ dom(Σ.M(d)) : Σ.M(d)(v) ∈ dom(Σ.C))` — every V-reference resolves to a stored address. Established by induction on transitions: vacuous at `Σ₀` (AX-1); preserved across each transition by S1 (the inherited references) together with AX-2 (the newly established or redirected references).
- *Frame:* S3 constrains only the relationship between `M` and `C`. It neither asserts nor requires that every stored address be referenced — `dom(C)` may properly exceed `⋃_d ran(Σ.M(d))` — and it places no constraint on the stored values `Σ.C(a)`.

- *Depends:*
  - S1 (StoreMonotonicity) — supplies `dom(Σ.C) ⊆ dom(Σ'.C)`, which discharges the inherited case of the inductive step (an already-valid reference stays valid because its address cannot leave the store) and grounds the closing remark that unreferenced content is never reclaimed
  - AX-1 (InitialEmpty) — supplies the empty base state `dom(Σ₀.M(d)) = ∅`, on which S3's quantifier range is empty, giving the base case vacuously
  - AX-2 (GroundedExtension) — supplies the protocol constraint that every transition establishing or redirecting a V-mapping points it into `dom(Σ'.C)`, discharging the new-or-redirected case of the inductive step — the transition type the content-store invariants do not constrain
