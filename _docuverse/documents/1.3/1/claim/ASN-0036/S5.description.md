Proves that the axioms S0–S3 impose no upper bound on how many times a single I-address may be referenced — either across distinct documents or at multiple V-positions within one document. For any finite N, an explicit model exists in which some address is shared more than N times, establishing that unlimited transclusion multiplicity is fully consistent with the foundational invariants. This makes content-sharing a first-class structural relationship: the system can represent arbitrarily many quotations of the same passage without violating any core constraint.
