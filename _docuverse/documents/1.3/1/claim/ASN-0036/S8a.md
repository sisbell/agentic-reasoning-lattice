**S8a (ArrangementDomainRestriction).** The arrangement maps only well-formed V-positions: `(A d ∈ T :: dom(Σ.M(d)) ⊆ {t ∈ T : zeros(t) = 0 ∧ #t ≥ 2})` — for every document `d`, every active key is a zero-free tumbler of depth at least 2 (a subspace identifier followed by a within-subspace ordinal). The outer universal binds `d` over the tumbler carrier `T`, exactly the document-level tumblers to which `Σ.M`'s declaration scopes its assignment `d ↦ Σ.M(d)`, so that each `Σ.M(d)` — and with it the domain `dom(Σ.M(d))` this restriction confines — is a defined object, admitting no `d ∉ T` for which `Σ.M(d)` would be undefined and that domain ill-formed. Here `zeros` is T4's zero-count `zeros(t) = |{i : 1 ≤ i ≤ #t ∧ tᵢ = 0}|` (ASN-0034), and the reading `zeros(t) = 0` decomposes in two steps. Write `S = {i : 1 ≤ i ≤ #t ∧ tᵢ = 0}` for the index set `zeros` counts. NAT-card fixes `|S|` as the unique `k ∈ ℕ` admitting a strictly increasing `f : {j : 1 ≤ j ≤ k} → ℕ` that enumerates `S` as `{f.j : 1 ≤ j ≤ k}`; instantiating that axiom at `k = 0`, the domain `{j : 1 ≤ j ≤ 0}` is empty, so the lone candidate `f` is the empty function with image `∅`, whence `k = 0` enumerates `S` exactly when `S = ∅` and, by the uniqueness of that `k`, `|S| = 0 ⟺ S = ∅`. Reading this on `zeros(t) = |S|`, `zeros(t) = 0` holds exactly when `{i : 1 ≤ i ≤ #t ∧ tᵢ = 0} = ∅`, that is `(A i : 1 ≤ i ≤ #t : tᵢ ≠ 0)` — no component is zero. Each component `tᵢ` is ℕ-valued by T0's component-projection signature, so NAT-zero's `(A n ∈ ℕ :: 0 < n ∨ 0 = n)` rewrites each `tᵢ ≠ 0` as `tᵢ > 0` on that carrier. Chaining the two, `zeros(t) = 0 ⟺ (A i : 1 ≤ i ≤ #t : tᵢ > 0)`, so equivalently every active V-position has depth at least 2 with all components strictly positive.

What we have not done is *derive* this restriction, and it is worth saying why, since the prose above only unfolds what the predicate `zeros(t) = 0 ∧ #t ≥ 2` *means*, not why `dom(Σ.M(d))` is confined to it. Nothing in the content-store or transition layer fixes the shape of an arrangement key. S0, S1, S2, and S3 govern the evolution of the content stream `C`; AX-1 fixes only that the base arrangement is empty; AX-2 constrains the *targets* of newly established V-mappings, never the V-positions admitted as keys. So the confinement of every active key to a zero-free tumbler of depth at least 2 cannot follow from any of them — we adopt it as a *design constraint* on the arrangement, asserted by fiat, a protocol posit on the class of permitted arrangements. We posit it rather than derive it; the point of naming it is methodological. Two downstream consumers read S8a as a load-bearing precondition and need an explicit, citable source for it: OrdShiftHom part (b) carries it as the hypothesis it shows `shift(v, n)` preserves, and S8's forward lockstep walk takes it as the base-case guarantee that every `v ∈ dom(Σ.M(d))` is a well-formed V-position. Knowing S8a is a posit and not a theorem is exactly what tells such a consumer — a formalization tool included — that the restriction is an implementation obligation on permitted arrangements, to be discharged by the protocol's allocation discipline, rather than a consequence automatically inherited from the existing axioms.

*Formal Contract:*
- *Axiom:* For every reachable state `Σ`, every document's active arrangement keys are well-formed V-positions:
  `(A d ∈ T :: dom(Σ.M(d)) ⊆ {t ∈ T : zeros(t) = 0 ∧ #t ≥ 2})`
  — the outer universal binding `d` over the tumbler carrier `T`, exactly the document-level tumblers to which `Σ.M`'s declaration scopes its assignment `d ↦ Σ.M(d)`, so that for every admitted `d` the arrangement `Σ.M(d)` — and with it the domain `dom(Σ.M(d))` this axiom confines — is a defined object, with no `d ∉ T` let in for which `Σ.M(d)` would be undefined and that domain ill-formed; every active arrangement key is thereby a zero-free tumbler of depth at least 2 (a subspace identifier followed by at least one within-subspace ordinal), holding at every state reachable from the base state `Σ₀` by the transition relation. This is a protocol design posit on the class of permitted arrangements: it is accepted within this ASN without proof, constraining which V-positions an arrangement may admit as keys. It is not derived from any other claim — in particular not from the content-store invariants S0, S1, S2, S3, which govern the evolution of `C` alone, nor from the transition axioms AX-1 (which fixes only the empty base arrangement) and AX-2 (which constrains the targets of new V-mappings, never the shape of the keys); none of these constrains the shape of a V-position. OrdShiftHom part (b) and S8 consume the restriction as a load-bearing precondition — the well-formedness premise propagated along lockstep links and the base case of S8's forward walk — so a consumer, a formalization tool included, must treat it as an implementation obligation on permitted arrangements rather than as a theorem automatically satisfied by the existing axioms.

- *Consequence:* `(A d ∈ T :: dom(Σ.M(d)) ⊆ {t ∈ T : (A i : 1 ≤ i ≤ #t : tᵢ > 0) ∧ #t ≥ 2})` — equivalently, for every document `d`, every active arrangement key `t` has all components strictly positive (`(A i : 1 ≤ i ≤ #t : tᵢ > 0)`) and depth at least 2. This is the strict-positivity reading of the Axiom's `zeros(t) = 0`, lifted from the body to an exported contract field so a consumer needing the component-positivity of an active key cites a formal export rather than re-deriving it: the body's chain `zeros(t) = 0 ⟺ (A i : 1 ≤ i ≤ #t : tᵢ > 0)` turns the vanishing zero-count into "no component is zero" by NAT-card's empty-set characterization `|S| = 0 ⟺ S = ∅`, then rewrites each `tᵢ ≠ 0` as `tᵢ > 0` by NAT-zero's `(A n ∈ ℕ :: 0 < n ∨ 0 = n)` on the ℕ-valued components. The positivity is a derived reading of the posited Axiom, not a second posit. D-CTG-depth's zero-freeness propagation and OrdShiftHom part (b)'s well-formedness premise read component-positivity off this Consequence.
