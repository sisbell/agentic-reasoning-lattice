**S8a (ArrangementDomainRestriction).** The arrangement maps only well-formed V-positions: `dom(Σ.M(d)) ⊆ {t ∈ T : zeros(t) = 0 ∧ #t ≥ 2}` — every active key is a zero-free tumbler of depth at least 2 (a subspace identifier followed by a within-subspace ordinal). Here `zeros` is T4's zero-count `zeros(t) = |{i : 1 ≤ i ≤ #t ∧ tᵢ = 0}|` (ASN-0034), and the reading `zeros(t) = 0` decomposes in two steps. By NAT-card's empty-set characterization `|S| = 0 ⟺ S = ∅`, `zeros(t) = 0` holds exactly when `{i : 1 ≤ i ≤ #t ∧ tᵢ = 0} = ∅`, that is `(A i : 1 ≤ i ≤ #t : tᵢ ≠ 0)` — no component is zero. Each component `tᵢ` is ℕ-valued by T0's component-projection signature, so NAT-zero's `(A n ∈ ℕ :: 0 < n ∨ 0 = n)` rewrites each `tᵢ ≠ 0` as `tᵢ > 0` on that carrier. Chaining the two, `zeros(t) = 0 ⟺ (A i : 1 ≤ i ≤ #t : tᵢ > 0)`, so equivalently every active V-position has depth at least 2 with all components strictly positive.

  - NAT-card (NatFiniteSetCardinality, ASN-0034) — supplies the empty-set characterization `|S| = 0 ⟺ S = ∅` of the cardinality operator `|·|`, the first step turning `zeros(t) = 0` into "no component is zero"
