**S8a (ArrangementDomainRestriction).** The arrangement maps only well-formed V-positions: `dom(Σ.M(d)) ⊆ {t ∈ T : zeros(t) = 0 ∧ #t ≥ 2}` — every active key is a zero-free tumbler of depth at least 2 (a subspace identifier followed by a within-subspace ordinal). Here `zeros` is T4's zero-count `zeros(t) = |{i : 1 ≤ i ≤ #t ∧ tᵢ = 0}|` (ASN-0034), and the reading `zeros(t) = 0` decomposes in two steps. Write `S = {i : 1 ≤ i ≤ #t ∧ tᵢ = 0}` for the index set `zeros` counts. NAT-card fixes `|S|` as the unique `k ∈ ℕ` admitting a strictly increasing `f : {j : 1 ≤ j ≤ k} → ℕ` that enumerates `S` as `{f.j : 1 ≤ j ≤ k}`; instantiating that axiom at `k = 0`, the domain `{j : 1 ≤ j ≤ 0}` is empty, so the lone candidate `f` is the empty function with image `∅`, whence `k = 0` enumerates `S` exactly when `S = ∅` and, by the uniqueness of that `k`, `|S| = 0 ⟺ S = ∅`. Reading this on `zeros(t) = |S|`, `zeros(t) = 0` holds exactly when `{i : 1 ≤ i ≤ #t ∧ tᵢ = 0} = ∅`, that is `(A i : 1 ≤ i ≤ #t : tᵢ ≠ 0)` — no component is zero. Each component `tᵢ` is ℕ-valued by T0's component-projection signature, so NAT-zero's `(A n ∈ ℕ :: 0 < n ∨ 0 = n)` rewrites each `tᵢ ≠ 0` as `tᵢ > 0` on that carrier. Chaining the two, `zeros(t) = 0 ⟺ (A i : 1 ≤ i ≤ #t : tᵢ > 0)`, so equivalently every active V-position has depth at least 2 with all components strictly positive.

What we have not done is *derive* this restriction, and it is worth saying why, since the prose above only unfolds what the predicate `zeros(t) = 0 ∧ #t ≥ 2` *means*, not why `dom(Σ.M(d))` is confined to it. Nothing in the content-store or transition layer fixes the shape of an arrangement key. S0, S1, S2, and S3 govern the evolution of the content stream `C`; AX-1 fixes only that the base arrangement is empty; AX-2 constrains the *targets* of newly established V-mappings, never the V-positions admitted as keys. So the confinement of every active key to a zero-free tumbler of depth at least 2 cannot follow from any of them — we adopt it as a *design constraint* on the arrangement, asserted by fiat, a protocol posit on the class of permitted arrangements. We posit it rather than derive it; the point of naming it is methodological. Two downstream consumers read S8a as a load-bearing precondition and need an explicit, citable source for it: OrdShiftHom part (b) carries it as the hypothesis it shows `shift(v, n)` preserves, and S8's forward lockstep walk takes it as the base-case guarantee that every `v ∈ dom(M(d))` is a well-formed V-position. Knowing S8a is a posit and not a theorem is exactly what tells such a consumer — a formalization tool included — that the restriction is an implementation obligation on permitted arrangements, to be discharged by the protocol's allocation discipline, rather than a consequence automatically inherited from the existing axioms.

*Formal Contract:*
- *Axiom:* For every reachable state `Σ` and every document `d`, `dom(Σ.M(d)) ⊆ {t ∈ T : zeros(t) = 0 ∧ #t ≥ 2}` — every active arrangement key is a zero-free tumbler of depth at least 2 (a subspace identifier followed by at least one within-subspace ordinal). This is a protocol design posit on the class of permitted arrangements: it is accepted within this ASN without proof, constraining which V-positions an arrangement may admit as keys. It is not derived from any other claim — in particular not from the content-store invariants S0, S1, S2, S3, which govern the evolution of `C` alone, nor from the transition axioms AX-1 (which fixes only the empty base arrangement) and AX-2 (which constrains the targets of new V-mappings, never the shape of the keys); none of these constrains the shape of a V-position. OrdShiftHom part (b) and S8 consume the restriction as a load-bearing precondition — the well-formedness premise propagated along lockstep links and the base case of S8's forward walk — so a consumer, a formalization tool included, must treat it as an implementation obligation on permitted arrangements rather than as a theorem automatically satisfied by the existing axioms.
