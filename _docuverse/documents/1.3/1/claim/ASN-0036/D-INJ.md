**D-INJ (InjectiveImageCardinality).** For every `n ∈ ℕ`, every `P ∈ ℕ` with `P ≥ 1`, and every injective map `h : {k ∈ ℕ : 1 ≤ k ≤ P} → {j ∈ ℕ : 1 ≤ j ≤ n}`, the image of the segment has cardinality equal to the segment's length:

`|{h.k : 1 ≤ k ≤ P}| = P`.

Here injectivity is `(A a, b : 1 ≤ a < b ≤ P : h.a ≠ h.b)`, and `|·|` is NAT-card's cardinality, well-defined because the image `{h.k : 1 ≤ k ≤ P}` is a subset of the bounded segment `{j ∈ ℕ : 1 ≤ j ≤ n}`.

*Proof.* We are counting the image of an injection out of an initial segment, and the only handle NAT-card (NatFiniteSetCardinality, ASN-0034) gives on a cardinality is its value clause: `|S|` is the unique `q ∈ ℕ` admitting a strictly increasing enumeration `f : {r ∈ ℕ : 1 ≤ r ≤ q} → ℕ` with `S = {f.r : 1 ≤ r ≤ q}`. So to read `|{h.k : 1 ≤ k ≤ P}| = P` we must *exhibit* a strictly increasing enumeration of the image whose length is exactly `P`; that the image's members are totally ordered — NAT-order's trichotomy — does not of itself hand us such an enumeration, which must be built, not posited, and built to a length we control. We build it by induction on `P`, holding `n` fixed. But NAT-induction (NatInduction) posits induction only in its generation-from-`0` set form `(A S : S ⊆ ℕ ∧ 0 ∈ S ∧ (A k ∈ ℕ : k ∈ S : k + 1 ∈ S) : S = ℕ)`, while the count runs over `P ≥ 1`; so — exactly as D-PRED (PredecessorExistence) packages the same recursion — we derive the from-`1` induction as an instance of the from-`0` principle rather than invoke it bare. Write `L.P` for the claim at length `P`, that every injective `h : {k ∈ ℕ : 1 ≤ k ≤ P} → {j ∈ ℕ : 1 ≤ j ≤ n}` has `|{h.k : 1 ≤ k ≤ P}| = P`, and let `W = {P ∈ ℕ : P < 1 ∨ L.P}` collect the lengths at which `L` holds together with those below `1`. We show `W = ℕ` by NAT-induction, which asks two things of `W`. *`0 ∈ W`*: the left disjunct holds at `P = 0`, since `0 < 1` is NAT-closure's (NatArithmeticClosureAndIdentity, ASN-0034) Consequence — no appeal to `L`. *`W` closed under successor*: fix `k ∈ ℕ` with `k ∈ W` and place `k + 1` in `W`, the two regimes of `k` dividing the work. At `k = 0` the successor `0 + 1` is `1` — NAT-closure's left identity `0 + n = n` at `n := 1` — so the closure obligation `0 + 1 ∈ W` reads as `1 ∈ W`, met through its right disjunct `L.1`, the **base** below, established outright with the hypothesis `k ∈ W` never consulted, just as D-PRED's successor step reads `k + 1` as a successor without consulting `k`. At `k ≥ 1` the disjunct `k < 1` is excluded by NAT-order's (NatStrictTotalOrder, ASN-0034) trichotomy, so `k ∈ W` delivers `L.k`, which the **step** below carries to `L.(k + 1)`, its right disjunct placing `k + 1` in `W`. The base case and the inductive step are thus precisely NAT-induction's two halves of `W`'s successor-closure; we establish them in turn, and NAT-induction then closes `W = ℕ` (below). NAT-wellorder's role in this proof is the separate, object-level one of extracting the least image value at each step (below).

**Base `P = 1`.** The segment `{k ∈ ℕ : 1 ≤ k ≤ 1}` is the singleton `{1}` — `1 ∈ ℕ` by NAT-closure (NatArithmeticClosureAndIdentity, ASN-0034) — so the image is the singleton `{h.1}`. The map `f : {r ∈ ℕ : 1 ≤ r ≤ 1} → ℕ` with `f.1 = h.1` is strictly increasing *vacuously*: its strict-increase clause `(A a, b : 1 ≤ a < b ≤ 1 : f.a < f.b)` ranges over an empty domain, there being no `a, b` with `1 ≤ a < b ≤ 1`. Its image is `{h.1}`. By NAT-card's value clause at `q := 1`, `|{h.1}| = 1`, which is `L.1`.

**Step `P → P + 1`.** Assume the claim at `P` (the induction hypothesis J: every injection from `{k ∈ ℕ : 1 ≤ k ≤ P}` into `{j ∈ ℕ : 1 ≤ j ≤ n}` has image of cardinality `P`). Let `h : {k ∈ ℕ : 1 ≤ k ≤ P + 1} → {j ∈ ℕ : 1 ≤ j ≤ n}` be injective, and write `S = {h.k : 1 ≤ k ≤ P + 1}` for its image — a non-empty subset of `{j ∈ ℕ : 1 ≤ j ≤ n}`, since it contains `h.1` (the index `1` lies in the segment, `1 ≤ P + 1`).

*The least image value and its unique index.* By NAT-wellorder the non-empty `S ⊆ ℕ` has a least element; call it `μ`, so `μ ∈ S` and `(A s : s ∈ S : μ ≤ s)`. Since `μ ∈ S` there is an index `k₀` with `1 ≤ k₀ ≤ P + 1` and `h.k₀ = μ`, and that index is unique: were `h.a = μ = h.b` with `a ≠ b`, the injectivity of `h` would be contradicted.

*Deleting that index and renumbering.* We reduce to an injection out of the shorter segment `{k ∈ ℕ : 1 ≤ k ≤ P}` by skipping `k₀`. Let `ρ : {k ∈ ℕ : 1 ≤ k ≤ P} → {k ∈ ℕ : 1 ≤ k ≤ P + 1}` renumber by `ρ.i = i` for `i < k₀` and `ρ.i = i + 1` for `k₀ ≤ i ≤ P`. Each value lands in the larger segment: for `i < k₀` plainly `1 ≤ i ≤ P < P + 1`, and for `k₀ ≤ i ≤ P` the successor `i + 1` is in `ℕ` (NAT-closure) and satisfies `i + 1 ≤ P + 1` by NAT-addcompat (NatAdditionOrderAndSuccessor, ASN-0034), its right order-compatibility lifting `i ≤ P` by the summand `1`. `ρ` is injective, and indeed a bijection onto `{k ∈ ℕ : 1 ≤ k ≤ P + 1} \ {k₀}`. *Injectivity.* Take `1 ≤ a < b ≤ P`; we read `ρ.a ≠ ρ.b` off the placement of the pair relative to `k₀`, the three placements exhausting `a < b`. When `b < k₀`, both indices sit in the identity branch and `ρ.a = a < b = ρ.b`. When `a < k₀ ≤ b`, they straddle the deleted index, `ρ.a = a` and `ρ.b = b + 1`, and the chain `a < k₀ ≤ b < b + 1` gives `a < b + 1`: its strict successor link `b < b + 1` is NAT-addcompat's, and the chain closes by pure `<`-transitivity once its sole mixed link `a < k₀ ≤ b ⟹ a < b` is bridged — NAT-order naming no mixed transitivity — through the two-case split on its `≤`-definition `k₀ ≤ b ⟺ k₀ < b ∨ k₀ = b` (`k₀ < b` gives `a < b` by pure `<`-transitivity, `k₀ = b` by rewriting `a < k₀` under indiscernibility of `=`); whence `ρ.a ≠ ρ.b` by NAT-order's trichotomy. When `k₀ ≤ a`, both sit in the successor branch, `ρ.a = a + 1` and `ρ.b = b + 1`; here NAT-addcompat's right order-compatibility lifts `a < b` only to `a + 1 ≤ b + 1`, too weak to separate the two values, so we appeal to NAT-cancel (NatAdditionCancellation, ASN-0034): were `ρ.a = ρ.b`, that is `a + 1 = b + 1`, its right cancellation at the summand `1` would force `a = b`, against `a < b` (`a ≠ b` by NAT-order's trichotomy) — hence `ρ.a ≠ ρ.b`. *Surjectivity* onto the punctured segment: every index below `k₀` is hit by itself and every index above `k₀` is hit as some `i + 1`, while `k₀` itself is missed. The first of these is the claim that an index `j` of the punctured segment with `j < k₀` satisfies `ρ.j = j`; before reading that off the identity branch we must place `j` in `ρ`'s domain `{k : 1 ≤ k ≤ P}`, that is, establish `j ≤ P`. The index `k₀` lies in `{k : 1 ≤ k ≤ P + 1}`, so `k₀ ≤ P + 1`, and `j < k₀ ≤ P + 1` chains to `j < P + 1` by the mixed `<`-then-`≤` step — bridged, as NAT-order names no mixed transitivity, through the two-case split on its `≤`-definition `k₀ ≤ P + 1 ⟺ k₀ < P + 1 ∨ k₀ = P + 1` (pure `<`-transitivity when `k₀ < P + 1`, an `=`-rewrite of `j < k₀` when `k₀ = P + 1`); NAT-discrete's (NatDiscreteness, ASN-0034) forward direction `m < n ⟹ m + 1 ≤ n`, instantiated at `(m, n) := (j, P + 1)`, descends this strict bound to `j + 1 ≤ P + 1`, whence *successor reflection* — which we establish here, once, for the three surjectivity placements that need it — returns `j ≤ P`. Reflecting a successor out of an inequality is not NAT-cancel's to settle alone: its axiom `n + m = p + m ⟹ n = p` cancels a summand from an *equation*, and `j + 1 ≤ P + 1` is an inequality, no instance of it. We reflect instead by unfolding NAT-order's `≤`-definition `n + 1 ≤ m + 1 ⟺ n + 1 < m + 1 ∨ n + 1 = m + 1` and disposing of the two cases. In the equality case `n + 1 = m + 1`, now genuinely an equation, NAT-cancel's right cancellation at the summand `1` returns `n = m`, hence `n ≤ m`. In the strict case `n + 1 < m + 1`, NAT-order's trichotomy on `(n, m)` leaves either `n < m`, already `n ≤ m`, or `m ≤ n`; this latter NAT-addcompat's right order-compatibility lifts to `m + 1 ≤ n + 1`, which set against the hypothesis `n + 1 < m + 1` closes the mixed chain `n + 1 < m + 1 ≤ n + 1` — through the same `≤`-split, pure `<`-transitivity when `m + 1 < n + 1` and an `=`-rewrite when `m + 1 = n + 1` — to the forbidden `n + 1 < n + 1`, which NAT-order's irreflexivity refutes, so `m ≤ n` cannot stand and trichotomy leaves `n < m`, again `n ≤ m`. This is *successor reflection*, `n + 1 ≤ m + 1 ⟹ n ≤ m`, the converse of NAT-addcompat's right order-compatibility; its instance at `(n, m) := (j, P)` reads `j + 1 ≤ P + 1` as `j ≤ P`. So `j` lies in `ρ`'s domain, `ρ.j = j` by the identity branch, and `j` is hit. The second sub-case is the symmetric claim that an index `j` of the punctured segment with `k₀ < j` is hit — not by itself, but as a successor `ρ.i = i + 1 = j`; here, before reading that off the successor branch, we must produce the index `i` and place it in that branch, that is, establish `k₀ ≤ i ≤ P`. The index `i` is the predecessor of `j` — the natural with `i + 1 = j`. Its existence is not free: the renumbering defines only the forward successor `i ↦ i + 1` (its values `ℕ`-valued by NAT-closure), which inverts at no `j` pointwise, and `j`'s lying above `k₀` is an order fact, not a predecessor — the NAT-* foundations posit no predecessor operation and no subtraction. We draw the predecessor from D-PRED (PredecessorExistence) instead: its guard `j ≥ 1` holds because `j > k₀` weakens to `j ≥ k₀` while `k₀ ≥ 1` (the index `k₀` lies in `{k : 1 ≤ k ≤ P + 1}`), so `j ≥ 1` by NAT-order's transitivity; D-PRED then returns an `i ∈ ℕ` with `i + 1 = j`. We place `i` by running the below-`k₀` argument in mirror. For its lower end, NAT-discrete's forward direction `m < n ⟹ m + 1 ≤ n`, instantiated this time at `(m, n) := (k₀, j)`, descends `k₀ < j` to `k₀ + 1 ≤ j`; rewriting `j` as `i + 1` gives `k₀ + 1 ≤ i + 1`, whence successor reflection at `(n, m) := (k₀, i)` returns `k₀ ≤ i`, putting `i` at or above the deletion point, where the successor branch governs it. For its upper end, `j` lies in the punctured segment `{k : 1 ≤ k ≤ P + 1} \ {k₀}`, so `j ≤ P + 1`, that is `i + 1 ≤ P + 1`, and successor reflection at `(n, m) := (i, P)` returns `i ≤ P`; with `1 ≤ k₀ ≤ i` this places `i` in `ρ`'s domain `{k : 1 ≤ k ≤ P}`. So `ρ.i = i + 1 = j` by the successor branch, and `j` is hit. That `k₀` itself is missed: no `i < k₀` equals `k₀`, and no value `i + 1` with `i ≥ k₀` equals `k₀`, since `i + 1 > k₀`, read off `k₀ ≤ i` and the strict successor `i < i + 1` (NAT-addcompat's `n < n + 1`): NAT-order posits transitivity only in the pure strict form, so this mixed `≤`-then-`<` chain is closed by the two-case split its `≤`-definition `k₀ ≤ i ⟺ k₀ < i ∨ k₀ = i` opens — `k₀ < i` yields `k₀ < i + 1` by pure `<`-transitivity, `k₀ = i` yields it by rewriting `i < i + 1` under indiscernibility of `=` — whence `i + 1 ≠ k₀` by NAT-order's trichotomy. Set `h′ = h ∘ ρ : {k ∈ ℕ : 1 ≤ k ≤ P} → {j ∈ ℕ : 1 ≤ j ≤ n}`. As the composite of the injective `ρ` with the injective `h`, `h′` is injective, and its image is `{h.k : 1 ≤ k ≤ P + 1 ∧ k ≠ k₀}`, which is exactly `S \ {μ}`: deleting the lone index `k₀` deletes exactly the value `μ = h.k₀` and no other, again because `h` is injective. Write `S′ = S \ {μ}`.

*Counting the smaller image, then re-attaching `μ`.* The induction hypothesis J applied to `h′` gives `|S′| = P`; read in the existence direction, NAT-card's value clause turns `|S′| = P` into a strictly increasing enumeration `g′ : {r ∈ ℕ : 1 ≤ r ≤ P} → ℕ` with `S′ = {g′.r : 1 ≤ r ≤ P}`. We prepend `μ`. Define `g : {r ∈ ℕ : 1 ≤ r ≤ P + 1} → ℕ` by `g.1 = μ` and `g.(r + 1) = g′.r` for `1 ≤ r ≤ P`. Its image is `{μ} ∪ {g′.r : 1 ≤ r ≤ P} = {μ} ∪ S′ = S`, since `μ ∈ S` and `S′ = S \ {μ}`. And `g` is strictly increasing, which we check as the named invariant — `g` enumerates `{μ} ∪ S′` in order with `μ` first:

- *across the seam,* `g.1 = μ < g′.1 = g.2`: `μ ≤ g′.1` because `μ` is least in `S` and `g′.1 ∈ S′ ⊆ S`, while `μ ≠ g′.1` because `g′.1 ∈ S′ = S \ {μ}`; NAT-order's (NatStrictTotalOrder, ASN-0034) trichotomy then forces the strict `μ < g′.1`;
- *beyond the seam,* for `1 ≤ r < r′ ≤ P`, `g.(r + 1) = g′.r < g′.r′ = g.(r′ + 1)`, the strict increase of `g′` itself;
- *spanning the seam,* for `1 ≤ r ≤ P`, `g.1 = μ < g′.1 ≤ g′.r = g.(r + 1)` (using `g′.1 ≤ g′.r` from `g′`'s monotonicity) closes by the mixed `<`-then-`≤` chain `μ < g′.1 ≤ g′.r ⟹ μ < g′.r`. NAT-order names no such mixed form — only pure `<`-transitivity — so we split on its `≤`-definition `g′.1 ≤ g′.r ⟺ g′.1 < g′.r ∨ g′.1 = g′.r`: when `g′.1 < g′.r`, pure `<`-transitivity gives `μ < g′.r`; when `g′.1 = g′.r`, indiscernibility of `=` rewrites `μ < g′.1` to `μ < g′.r`.

So `g` is a strictly increasing enumeration of `S` of length `P + 1`, the witness NAT-card's value clause requires at `q := P + 1`; by that clause's uniqueness of the cardinality, `|S| = P + 1`. This is `L.(P + 1)`, completing the inductive step `L.P ⟹ L.(P + 1)`.

The two obligations of NAT-induction on `W` now stand: `0 ∈ W`, and `W` closed under successor — its `k = 0` sub-case discharged by the base `L.1`, its `k ≥ 1` sub-case by the step `L.k ⟹ L.(k + 1)`. NAT-induction concludes `W = ℕ`. Any `P ≥ 1` then lies in `W` with its disjunct `P < 1` excluded by NAT-order's trichotomy against the guard `1 ≤ P`, leaving `L.P`: every injective `h : {k ∈ ℕ : 1 ≤ k ≤ P} → {j ∈ ℕ : 1 ≤ j ≤ n}` has `|{h.k : 1 ≤ k ≤ P}| = P`. With `n ∈ ℕ` arbitrary throughout, this is the lemma. ∎

The construction nowhere assumes `P ≤ n` — it locates the least value, deletes its index, renumbers, and prepends regardless of how `P` and `n` compare — so the count `|{h.k : 1 ≤ k ≤ P}| = P` stands even when `P` exceeds `n`. That is the regime the finiteness arguments exploit: NAT-card's upper-bound clause gives `|{h.k : 1 ≤ k ≤ P}| ≤ n` for an image inside `{j ∈ ℕ : 1 ≤ j ≤ n}`, so an injection from a longer segment into a strictly shorter one collides with its own image count, forcing the impossible `P ≤ n` against `P > n`. D-CTG-depth consumes the lemma at `P := N + 1`, `n := N`, where the exact count `N + 1 = |{jₖ : 1 ≤ k ≤ N + 1}|` set against the upper bound `≤ N` is the contradiction that closes its finiteness step.

*Formal Contract:*

- *Lemma:* For every `n ∈ ℕ`, every `P ∈ ℕ` with `P ≥ 1`, and every injective `h : {k ∈ ℕ : 1 ≤ k ≤ P} → {j ∈ ℕ : 1 ≤ j ≤ n}` (injectivity `(A a, b : 1 ≤ a < b ≤ P : h.a ≠ h.b)`), `|{h.k : 1 ≤ k ≤ P}| = P`, where `|·|` is NAT-card's cardinality (well-defined because the image is a subset of `{j ∈ ℕ : 1 ≤ j ≤ n}`). The statement is not conditioned on `P ≤ n`; combined with NAT-card's upper bound `|{h.k : 1 ≤ k ≤ P}| ≤ n` it yields `P ≤ n`, so no injection out of a strictly longer initial segment into a shorter one exists. Proved by induction on `P`, the from-`1` recursion packaged (as in D-PRED) as a from-`0` instance of NAT-induction's set form through the carrier `W = {P ∈ ℕ : P < 1 ∨ L.P}` (`L.P` the lemma's conclusion at length `P`): `0 ∈ W` by NAT-closure's Consequence `0 < 1`, and `W`'s successor-closure split between the base (`k = 0`, where `k + 1 = 1` is met by `L.1`) and the step (`k ≥ 1`, where NAT-order's trichotomy excludes `k < 1` so `k ∈ W` gives `L.k`, and the step yields `L.(k + 1)`), whence NAT-induction returns `W = ℕ` and so `L.P` for every `P ≥ 1`; NAT-wellorder serving instead at the object level to extract the least image value: at `P = 1` the image is a singleton enumerated in one strictly-increasing step; at `P + 1`, deleting the index of the least image value `μ` and renumbering the remaining indices yields an injection from `{k : 1 ≤ k ≤ P}` whose image `S′ = S \ {μ}` has `|S′| = P` by the induction hypothesis, and prepending `μ` to `S′`'s strictly increasing enumeration produces a strictly increasing length-`(P + 1)` enumeration of the full image, whence NAT-card's value clause reads its cardinality as `P + 1`.

- *Depends:*
  - NAT-card (NatFiniteSetCardinality, ASN-0034) — supplies the cardinality operator `|·|` and its value clause (`|S|` is the unique `q` admitting a strictly increasing length-`q` enumeration of `S`), the sole handle on cardinality the proof uses, exercised in both directions: read in the existence direction it turns the induction hypothesis `|S′| = P` into the enumeration `g′` the construction prepends to; read in the value direction it converts the constructed strictly increasing length-`(P + 1)` enumeration `g` of the image into `|S| = P + 1`, and at the base reads the singleton image's one-point enumeration as cardinality `1`. The closing remark additionally cites NAT-card's upper-bound clause `|S| ≤ n` (for `S ⊆ {j ∈ ℕ : 1 ≤ j ≤ n}`) to draw the pigeonhole consequence `P ≤ n`. Every `|·|` is well-defined only because the image lies in the bounded segment `{j ∈ ℕ : 1 ≤ j ≤ n}` the clauses require
  - NAT-induction (NatInduction) — supplies the generation-from-`0` set form `(A S : S ⊆ ℕ ∧ 0 ∈ S ∧ (A k ∈ ℕ : k ∈ S : k + 1 ∈ S) : S = ℕ)` that structures the whole proof. The from-`1` count is not invoked as a bare 'specialization' but derived from this set form, exactly as in D-PRED: the principle is applied to the carrier `W = {P ∈ ℕ : P < 1 ∨ L.P}` (`L.P` the image-count claim at length `P`), whose two obligations are `0 ∈ W` — the left disjunct `0 < 1`, NAT-closure's Consequence — and successor-closure, discharged between the base case (at `k = 0`, where `k + 1 = 1` is met by `L.1`) and the inductive step (at `k ≥ 1`, where NAT-order's trichotomy excludes `k < 1` so `k ∈ W` yields `L.k` and the step gives `L.(k + 1)`); NAT-induction then returns `W = ℕ`, whence `L.P` for every `P ≥ 1`, its disjunct `P < 1` excluded by trichotomy against the guard. The NAT-* group's well-ordering does not by itself underwrite this induction — that induction is independent of the order-and-addition axioms is a classical fact (those axioms are not categorical, admitting a carrier with an element unreachable from `0` by finite succession), so a putative well-ordering induction stalls at such an unreachable least counterexample — hence the inductive scaffolding is drawn from NAT-induction, exactly as in D-PRED
  - NAT-wellorder (NatWellOrdering, ASN-0034) — supplies the least element `μ = min S` of the non-empty image `S ⊆ ℕ` extracted at each step — the value whose index is deleted and which is prepended to drive the construction. This is the object-level use; the induction on `P` that structures the proof is underwritten not by well-ordering but by NAT-induction (preceding bullet), the least-element principle alone not yielding the induction principle over the NAT-* foundation
  - NAT-order (NatStrictTotalOrder, ASN-0034) — supplies the strict total order `<` (with its non-strict companion `≤`, defined `m ≤ n ⟺ m < n ∨ m = n`) in which the enumerations are strictly increasing: its trichotomy turns `μ ≤ g′.1` together with `μ ≠ g′.1` into the strict seam inequality `μ < g′.1`; its pure `<`-transitivity Axiom, together with that `≤`-definition, underwrites every mixed `<`/`≤` step the construction needs — the seam-crossing `μ < g′.1 ≤ g′.r ⟹ μ < g.(r + 1)` that orders `g`, and the renumbering's chains (`a < k₀ ≤ b ⟹ a < b`, `j < k₀ ≤ P + 1 ⟹ j < P + 1`, and `k₀ ≤ i < i + 1 ⟹ i + 1 > k₀`) that make `ρ` order-faithful — each built inline by a two-case split on `≤` (pure `<`-transitivity on the strict case, indiscernibility of `=` on the equality case), NAT-order exporting no mixed-transitivity form of its own; its trichotomy and irreflexivity together additionally drive *successor reflection* `n + 1 ≤ m + 1 ⟹ n ≤ m` — trichotomy on `(n, m)` reducing the strict sub-case `n + 1 < m + 1` to the alternatives `n < m` or `m ≤ n`, and irreflexivity refuting the latter once NAT-addcompat lifts it to `m + 1 ≤ n + 1` against the hypothesis — the reflection by which `ρ`'s surjectivity placements descend the bounds `j + 1 ≤ P + 1`, `k₀ + 1 ≤ i + 1`, and `i + 1 ≤ P + 1` to `j ≤ P`, `k₀ ≤ i`, and `i ≤ P`; these make both `g` and `ρ` order-faithful; the same order is what makes "strictly increasing enumeration" a well-formed predicate, as NAT-card itself relies on; and its trichotomy serves once more in the from-`0` packaging of the induction (see the NAT-induction bullet), excluding `k < 1` in the successor-closure's `k ≥ 1` case and `P < 1` in the final `P ≥ 1` extraction from `W = {P ∈ ℕ : P < 1 ∨ L.P}`
  - NAT-closure (NatArithmeticClosureAndIdentity, ASN-0034) — supplies `1 ∈ ℕ` (the lone index of the base segment `{k : 1 ≤ k ≤ 1}` and the summand in every successor `i + 1`, `r + 1`, `P + 1`) and the closure of `+` on `ℕ`, so the renumbering `ρ`'s values `i + 1`, the prepended enumeration's indices `r + 1`, and the segments `{k : 1 ≤ k ≤ P + 1}` and `{r : 1 ≤ r ≤ P + 1}` are all ℕ-valued and well-formed; and supplies, for the from-`0` packaging of the induction (see the NAT-induction bullet), both the Consequence `0 < 1` — the witness placing `0` in the left disjunct `P < 1` of the carrier `W = {P ∈ ℕ : P < 1 ∨ L.P}`, so `0 ∈ W` — and the left identity `0 + n = n` at `n := 1`, reading the successor `0 + 1` of `0` as `1` so that the successor-closure's `k = 0` obligation `0 + 1 ∈ W` is the base `L.1`
  - NAT-addcompat (NatAdditionOrderAndSuccessor, ASN-0034) — supplies right order-compatibility, lifting `i ≤ P` to `i + 1 ≤ P + 1` so the renumbering `ρ`'s skipped values stay inside the larger index segment, and the strict successor inequality `n < n + 1`, giving `i + 1 > i ≥ k₀` so `ρ` misses exactly the deleted index `k₀`; this is the index arithmetic by which deletion-and-renumbering reduces the step to the induction hypothesis. That same right order-compatibility further supplies the strict sub-case of *successor reflection* `n + 1 ≤ m + 1 ⟹ n ≤ m` (see the NAT-order bullet), lifting the trichotomy alternative `m ≤ n` to `m + 1 ≤ n + 1` for refutation against `n + 1 < m + 1` by irreflexivity — the reflection by which `ρ`'s surjectivity placements pass the discreteness-derived bounds back to `j ≤ P`, `k₀ ≤ i`, and `i ≤ P`
  - NAT-cancel (NatAdditionCancellation, ASN-0034) — supplies right cancellation of `+`, `n + m = p + m ⟹ n = p`, at the summand `m := 1`, to settle the renumbering `ρ`'s injectivity in its same-branch upper case: for `k₀ ≤ a < b ≤ P` both indices map through the successor branch to `ρ.a = a + 1` and `ρ.b = b + 1`, and right cancellation turns the hypothetical collision `a + 1 = b + 1` into `a = b`, against `a < b`. This is the lone injectivity case NAT-addcompat cannot reach — its right order-compatibility weakens `a < b` only to `a + 1 ≤ b + 1`, which leaves `a + 1 = b + 1` admissible — so without cancellation `ρ`, and with it the composite `h′ = h ∘ ρ`, would be unestablished as injective. Cancellation reappears in `ρ`'s surjectivity placements (see the NAT-discrete bullet), but there only as one case of *successor reflection* `n + 1 ≤ m + 1 ⟹ n ≤ m`, not as the whole of it: an inequality `n + 1 ≤ m + 1` is no instance of the cancellation axiom, which takes an equation on its left, so the placements that read the discreteness-derived bounds `j + 1 ≤ P + 1`, `k₀ + 1 ≤ i + 1`, and `i + 1 ≤ P + 1` as `j ≤ P`, `k₀ ≤ i`, and `i ≤ P` proceed by splitting NAT-order's `≤`-definition — NAT-cancel settling only the equality sub-case `n + 1 = m + 1 ⟹ n = m`, the strict sub-case falling to NAT-addcompat's right order-compatibility and NAT-order's trichotomy and irreflexivity instead (see those bullets). The bounds `k₀ ≤ i` and `i ≤ P` so obtained are the pair that puts the predecessor `i` in the successor branch's index range `{k : k₀ ≤ k ≤ P}`
  - NAT-discrete (NatDiscreteness, ASN-0034) — supplies discreteness `m < n ⟹ m + 1 ≤ n`, its forward direction grounding both sub-cases of the renumbering `ρ`'s surjectivity onto the punctured segment. In the below-`k₀` sub-case, instantiated at `(m, n) := (j, P + 1)`: a punctured-segment index `j < k₀` is hit by itself, `ρ.j = j`, only once `j` is placed in `ρ`'s domain `{k : 1 ≤ k ≤ P}`, and the chain `j < k₀ ≤ P + 1` (its mixed `<`-then-`≤` link bridged by the two-case split on NAT-order's `≤`-definition, NAT-order naming no mixed transitivity) descends through this discreteness to `j + 1 ≤ P + 1`, which successor reflection `n + 1 ≤ m + 1 ⟹ n ≤ m` (NAT-cancel for its equality sub-case, NAT-addcompat and NAT-order for its strict sub-case; see those bullets) reads as `j ≤ P`. In the above-`k₀` sub-case, instantiated at `(m, n) := (k₀, j)`: a punctured-segment index `k₀ < j` is hit as the successor `ρ.i = i + 1 = j` of its predecessor `i` (whose existence is D-PRED's, not discreteness's — discreteness only bounds `i` once it is in hand), and `k₀ < j` descends through this discreteness to `k₀ + 1 ≤ j = i + 1`, which the same successor reflection reads as `k₀ ≤ i`, putting `i` at or above the deletion point so the successor branch governs it (its companion bound `i ≤ P`, from `i + 1 ≤ P + 1` by the same reflection, completes the domain membership). These are the surjectivity sub-cases the listed order axioms cannot reach — NAT-order alone passes `j < k₀ ≤ P + 1` only to the strict `j < P + 1`, one short of the `j ≤ P` domain membership demands, and passes `k₀ < j` only to itself, never to the `k₀ ≤ i` the successor branch demands — so without discreteness the sub-cases "`j < k₀` is hit by itself" and "`k₀ < j` is hit as `i + 1`" are ungrounded, `ρ`'s bijection onto `{k : 1 ≤ k ≤ P + 1} \ {k₀}` fails, and the image identity `{h.k : 1 ≤ k ≤ P + 1 ∧ k ≠ k₀} = S \ {μ}` on which the induction hypothesis and the prepend-`μ` construction turn cannot be drawn
  - D-PRED (PredecessorExistence) — supplies the existence of the predecessor `i ∈ ℕ` with `i + 1 = j` that the renumbering `ρ`'s above-`k₀` surjectivity sub-case turns on: a punctured-segment index `j > k₀` is hit not by itself but as a successor `ρ.i = i + 1 = j`, and naming that `i` demands a natural whose successor is `j`. The forward renumbering furnishes only `i ↦ i + 1`, and the NAT-* foundations posit no predecessor or subtraction, so existence cannot be read off a term — D-PRED proves it by induction (its guard `j ≥ 1` met here by `j ≥ k₀ ≥ 1`, NAT-order's transitivity). Only existence is consumed: the bounds `k₀ ≤ i ≤ P` that seat `i` in the successor branch's index range `{k : k₀ ≤ k ≤ P}` are then read off `i + 1 = j` by NAT-discrete and successor reflection (above), and the predecessor's uniqueness is never needed. Without D-PRED the above-`k₀` sub-case "`k₀ < j` is hit as `i + 1`" would rest on the ungrounded assertion that `j`, lying above `k₀`, "is a successor"; with it that sub-case — and so `ρ`'s surjectivity onto `{k : 1 ≤ k ≤ P + 1} \ {k₀}` — stands
