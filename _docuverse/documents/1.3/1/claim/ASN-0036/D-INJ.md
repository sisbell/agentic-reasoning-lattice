**D-INJ (InjectiveImageCardinality).** For every `n ∈ ℕ`, every `P ∈ ℕ` with `P ≥ 1`, and every injective map `h : {k ∈ ℕ : 1 ≤ k ≤ P} → {j ∈ ℕ : 1 ≤ j ≤ n}`, the image of the segment has cardinality equal to the segment's length:

`|{h.k : 1 ≤ k ≤ P}| = P`.

Here injectivity is `(A a, b : 1 ≤ a < b ≤ P : h.a ≠ h.b)`, and `|·|` is NAT-card's cardinality, well-defined because the image `{h.k : 1 ≤ k ≤ P}` is a subset of the bounded segment `{j ∈ ℕ : 1 ≤ j ≤ n}`.

*Proof.* We are counting the image of an injection out of an initial segment, and the only handle NAT-card (NatFiniteSetCardinality, ASN-0034) gives on a cardinality is its value clause: `|S|` is the unique `q ∈ ℕ` admitting a strictly increasing enumeration `f : {r ∈ ℕ : 1 ≤ r ≤ q} → ℕ` with `S = {f.r : 1 ≤ r ≤ q}`. So to read `|{h.k : 1 ≤ k ≤ P}| = P` we must *exhibit* a strictly increasing enumeration of the image whose length is exactly `P`; that the image's members are totally ordered — NAT-order's trichotomy — does not of itself hand us such an enumeration, which must be built, not posited, and built to a length we control. We build it by induction on `P` — the induction principle on `P ≥ 1` underwritten by NAT-wellorder (NatWellOrdering, ASN-0034), the role the least-element principle plays for the depth inductions of ASN-0034 — holding `n` fixed.

**Base `P = 1`.** The segment `{k ∈ ℕ : 1 ≤ k ≤ 1}` is the singleton `{1}` — `1 ∈ ℕ` by NAT-closure (NatArithmeticClosureAndIdentity, ASN-0034) — so the image is the singleton `{h.1}`. The map `f : {r ∈ ℕ : 1 ≤ r ≤ 1} → ℕ` with `f.1 = h.1` is strictly increasing *vacuously*: its strict-increase clause `(A a, b : 1 ≤ a < b ≤ 1 : f.a < f.b)` ranges over an empty domain, there being no `a, b` with `1 ≤ a < b ≤ 1`. Its image is `{h.1}`. By NAT-card's value clause at `q := 1`, `|{h.1}| = 1`, which is the claim at `P = 1`.

**Step `P → P + 1`.** Assume the claim at `P` (the induction hypothesis J: every injection from `{k ∈ ℕ : 1 ≤ k ≤ P}` into `{j ∈ ℕ : 1 ≤ j ≤ n}` has image of cardinality `P`). Let `h : {k ∈ ℕ : 1 ≤ k ≤ P + 1} → {j ∈ ℕ : 1 ≤ j ≤ n}` be injective, and write `S = {h.k : 1 ≤ k ≤ P + 1}` for its image — a non-empty subset of `{j ∈ ℕ : 1 ≤ j ≤ n}`, since it contains `h.1` (the index `1` lies in the segment, `1 ≤ P + 1`).

*The least image value and its unique index.* By NAT-wellorder the non-empty `S ⊆ ℕ` has a least element; call it `μ`, so `μ ∈ S` and `(A s : s ∈ S : μ ≤ s)`. Since `μ ∈ S` there is an index `k₀` with `1 ≤ k₀ ≤ P + 1` and `h.k₀ = μ`, and that index is unique: were `h.a = μ = h.b` with `a ≠ b`, the injectivity of `h` would be contradicted.

*Deleting that index and renumbering.* We reduce to an injection out of the shorter segment `{k ∈ ℕ : 1 ≤ k ≤ P}` by skipping `k₀`. Let `ρ : {k ∈ ℕ : 1 ≤ k ≤ P} → {k ∈ ℕ : 1 ≤ k ≤ P + 1}` renumber by `ρ.i = i` for `i < k₀` and `ρ.i = i + 1` for `k₀ ≤ i ≤ P`. Each value lands in the larger segment: for `i < k₀` plainly `1 ≤ i ≤ P < P + 1`, and for `k₀ ≤ i ≤ P` the successor `i + 1` is in `ℕ` (NAT-closure) and satisfies `i + 1 ≤ P + 1` by NAT-addcompat (NatAdditionOrderAndSuccessor, ASN-0034), its right order-compatibility lifting `i ≤ P` by the summand `1`. `ρ` is injective, and indeed a bijection onto `{k ∈ ℕ : 1 ≤ k ≤ P + 1} \ {k₀}`. *Injectivity.* Take `1 ≤ a < b ≤ P`; we read `ρ.a ≠ ρ.b` off the placement of the pair relative to `k₀`, the three placements exhausting `a < b`. When `b < k₀`, both indices sit in the identity branch and `ρ.a = a < b = ρ.b`. When `a < k₀ ≤ b`, they straddle the deleted index, `ρ.a = a` and `ρ.b = b + 1`, and the chain `a < k₀ ≤ b < b + 1` — its last link the strict successor `b < b + 1` from NAT-addcompat, the whole closed by NAT-order's transitivity — gives `a < b + 1`, whence `ρ.a ≠ ρ.b` by NAT-order's trichotomy. When `k₀ ≤ a`, both sit in the successor branch, `ρ.a = a + 1` and `ρ.b = b + 1`; here NAT-addcompat's right order-compatibility lifts `a < b` only to `a + 1 ≤ b + 1`, too weak to separate the two values, so we appeal to NAT-cancel (NatAdditionCancellation, ASN-0034): were `ρ.a = ρ.b`, that is `a + 1 = b + 1`, its right cancellation at the summand `1` would force `a = b`, against `a < b` (`a ≠ b` by NAT-order's trichotomy) — hence `ρ.a ≠ ρ.b`. *Surjectivity* onto the punctured segment: every index below `k₀` is hit by itself and every index above `k₀` is hit as some `i + 1`, while `k₀` itself is missed. The first of these is the claim that an index `j` of the punctured segment with `j < k₀` satisfies `ρ.j = j`; before reading that off the identity branch we must place `j` in `ρ`'s domain `{k : 1 ≤ k ≤ P}`, that is, establish `j ≤ P`. The index `k₀` lies in `{k : 1 ≤ k ≤ P + 1}`, so `k₀ ≤ P + 1`, and `j < k₀ ≤ P + 1` chains through NAT-order's transitivity to `j < P + 1`; NAT-discrete's (NatDiscreteness, ASN-0034) forward direction `m < n ⟹ m + 1 ≤ n`, instantiated at `(m, n) := (j, P + 1)`, descends this strict bound to `j + 1 ≤ P + 1`, whence right cancellation of the summand `1` (NAT-cancel) returns `j ≤ P`. So `j` lies in `ρ`'s domain, `ρ.j = j` by the identity branch, and `j` is hit. The second sub-case is the symmetric claim that an index `j` of the punctured segment with `k₀ < j` is hit — not by itself, but as a successor `ρ.i = i + 1 = j`; here, before reading that off the successor branch, we must produce the index `i` and place it in that branch, that is, establish `k₀ ≤ i ≤ P`. The index `i` is the predecessor of `j` — the natural with `i + 1 = j`, which exists because `j`, lying strictly above `k₀ ≥ 1`, is a successor; this is the backward reading of the very successor step the renumbering already trades on when it ranges `i + 1` over `k₀ ≤ i ≤ P` (the values `ℕ`-valued by NAT-closure). We place `i` by running the below-`k₀` argument in mirror. For its lower end, NAT-discrete's forward direction `m < n ⟹ m + 1 ≤ n`, instantiated this time at `(m, n) := (k₀, j)`, descends `k₀ < j` to `k₀ + 1 ≤ j`; rewriting `j` as `i + 1` gives `k₀ + 1 ≤ i + 1`, whence right cancellation of the summand `1` (NAT-cancel) returns `k₀ ≤ i`, putting `i` at or above the deletion point, where the successor branch governs it. For its upper end, `j` lies in the punctured segment `{k : 1 ≤ k ≤ P + 1} \ {k₀}`, so `j ≤ P + 1`, that is `i + 1 ≤ P + 1`, and the same right cancellation of the summand `1` (NAT-cancel) returns `i ≤ P`; with `1 ≤ k₀ ≤ i` this places `i` in `ρ`'s domain `{k : 1 ≤ k ≤ P}`. So `ρ.i = i + 1 = j` by the successor branch, and `j` is hit. That `k₀` itself is missed: no `i < k₀` equals `k₀`, and no value `i + 1` with `i ≥ k₀` equals `k₀`, since `i + 1 > i ≥ k₀` by NAT-addcompat's strict successor inequality `n < n + 1` chained through NAT-order's transitivity. Set `h′ = h ∘ ρ : {k ∈ ℕ : 1 ≤ k ≤ P} → {j ∈ ℕ : 1 ≤ j ≤ n}`. As the composite of the injective `ρ` with the injective `h`, `h′` is injective, and its image is `{h.k : 1 ≤ k ≤ P + 1 ∧ k ≠ k₀}`, which is exactly `S \ {μ}`: deleting the lone index `k₀` deletes exactly the value `μ = h.k₀` and no other, again because `h` is injective. Write `S′ = S \ {μ}`.

*Counting the smaller image, then re-attaching `μ`.* The induction hypothesis J applied to `h′` gives `|S′| = P`; read in the existence direction, NAT-card's value clause turns `|S′| = P` into a strictly increasing enumeration `g′ : {r ∈ ℕ : 1 ≤ r ≤ P} → ℕ` with `S′ = {g′.r : 1 ≤ r ≤ P}`. We prepend `μ`. Define `g : {r ∈ ℕ : 1 ≤ r ≤ P + 1} → ℕ` by `g.1 = μ` and `g.(r + 1) = g′.r` for `1 ≤ r ≤ P`. Its image is `{μ} ∪ {g′.r : 1 ≤ r ≤ P} = {μ} ∪ S′ = S`, since `μ ∈ S` and `S′ = S \ {μ}`. And `g` is strictly increasing, which we check as the named invariant — `g` enumerates `{μ} ∪ S′` in order with `μ` first:

- *across the seam,* `g.1 = μ < g′.1 = g.2`: `μ ≤ g′.1` because `μ` is least in `S` and `g′.1 ∈ S′ ⊆ S`, while `μ ≠ g′.1` because `g′.1 ∈ S′ = S \ {μ}`; NAT-order's (NatStrictTotalOrder, ASN-0034) trichotomy then forces the strict `μ < g′.1`;
- *beyond the seam,* for `1 ≤ r < r′ ≤ P`, `g.(r + 1) = g′.r < g′.r′ = g.(r′ + 1)`, the strict increase of `g′` itself;
- *spanning the seam,* for `1 ≤ r ≤ P`, `g.1 = μ < g′.1 ≤ g′.r = g.(r + 1)` (using `g′.1 ≤ g′.r` from `g′`'s monotonicity) closes by NAT-order's transitivity in its mixed `<`-then-`≤` form `a < b ∧ b ≤ c ⟹ a < c`.

So `g` is a strictly increasing enumeration of `S` of length `P + 1`, the witness NAT-card's value clause requires at `q := P + 1`; by that clause's uniqueness of the cardinality, `|S| = P + 1`. This is the claim at `P + 1`, and the induction is complete. ∎

The construction nowhere assumes `P ≤ n` — it locates the least value, deletes its index, renumbers, and prepends regardless of how `P` and `n` compare — so the count `|{h.k : 1 ≤ k ≤ P}| = P` stands even when `P` exceeds `n`. That is the regime the finiteness arguments exploit: NAT-card's upper-bound clause gives `|{h.k : 1 ≤ k ≤ P}| ≤ n` for an image inside `{j ∈ ℕ : 1 ≤ j ≤ n}`, so an injection from a longer segment into a strictly shorter one collides with its own image count, forcing the impossible `P ≤ n` against `P > n`. D-CTG-depth consumes the lemma at `P := N + 1`, `n := N`, where the exact count `N + 1 = |{jₖ : 1 ≤ k ≤ N + 1}|` set against the upper bound `≤ N` is the contradiction that closes its finiteness step.

*Formal Contract:*

- *Lemma:* For every `n ∈ ℕ`, every `P ∈ ℕ` with `P ≥ 1`, and every injective `h : {k ∈ ℕ : 1 ≤ k ≤ P} → {j ∈ ℕ : 1 ≤ j ≤ n}` (injectivity `(A a, b : 1 ≤ a < b ≤ P : h.a ≠ h.b)`), `|{h.k : 1 ≤ k ≤ P}| = P`, where `|·|` is NAT-card's cardinality (well-defined because the image is a subset of `{j ∈ ℕ : 1 ≤ j ≤ n}`). The statement is not conditioned on `P ≤ n`; combined with NAT-card's upper bound `|{h.k : 1 ≤ k ≤ P}| ≤ n` it yields `P ≤ n`, so no injection out of a strictly longer initial segment into a shorter one exists. Proved by induction on `P` (the induction principle underwritten by NAT-wellorder): at `P = 1` the image is a singleton enumerated in one strictly-increasing step; at `P + 1`, deleting the index of the least image value `μ` and renumbering the remaining indices yields an injection from `{k : 1 ≤ k ≤ P}` whose image `S′ = S \ {μ}` has `|S′| = P` by the induction hypothesis, and prepending `μ` to `S′`'s strictly increasing enumeration produces a strictly increasing length-`(P + 1)` enumeration of the full image, whence NAT-card's value clause reads its cardinality as `P + 1`.

- *Depends:*
  - NAT-card (NatFiniteSetCardinality, ASN-0034) — supplies the cardinality operator `|·|` and its value clause (`|S|` is the unique `q` admitting a strictly increasing length-`q` enumeration of `S`), the sole handle on cardinality the proof uses, exercised in both directions: read in the existence direction it turns the induction hypothesis `|S′| = P` into the enumeration `g′` the construction prepends to; read in the value direction it converts the constructed strictly increasing length-`(P + 1)` enumeration `g` of the image into `|S| = P + 1`, and at the base reads the singleton image's one-point enumeration as cardinality `1`. The closing remark additionally cites NAT-card's upper-bound clause `|S| ≤ n` (for `S ⊆ {j ∈ ℕ : 1 ≤ j ≤ n}`) to draw the pigeonhole consequence `P ≤ n`. Every `|·|` is well-defined only because the image lies in the bounded segment `{j ∈ ℕ : 1 ≤ j ≤ n}` the clauses require
  - NAT-wellorder (NatWellOrdering, ASN-0034) — supplies, at (i) the meta level, the induction principle on `P ≥ 1` that underwrites the whole proof (base `P = 1`, step `P → P + 1`), the least-element principle in the same role it plays for the depth inductions of ASN-0034; and at (ii) the object level, the least element `μ = min S` of the non-empty image `S ⊆ ℕ` extracted at each step — the value whose index is deleted and which is prepended to drive the construction
  - NAT-order (NatStrictTotalOrder, ASN-0034) — supplies the strict total order `<` (with its non-strict companion `≤`) in which the enumerations are strictly increasing: its trichotomy turns `μ ≤ g′.1` together with `μ ≠ g′.1` into the strict seam inequality `μ < g′.1`; its transitivity (both the pure `<` form and the mixed `a < b ∧ b ≤ c ⟹ a < c` form) lifts the seam-crossing comparisons `μ < g′.1 ≤ g′.r` to `μ < g.(r + 1)` and chains `i + 1 > i ≥ k₀` in the renumbering, making both `g` and `ρ` order-faithful; the same order is what makes "strictly increasing enumeration" a well-formed predicate, as NAT-card itself relies on
  - NAT-closure (NatArithmeticClosureAndIdentity, ASN-0034) — supplies `1 ∈ ℕ` (the lone index of the base segment `{k : 1 ≤ k ≤ 1}` and the summand in every successor `i + 1`, `r + 1`, `P + 1`) and the closure of `+` on `ℕ`, so the renumbering `ρ`'s values `i + 1`, the prepended enumeration's indices `r + 1`, and the segments `{k : 1 ≤ k ≤ P + 1}` and `{r : 1 ≤ r ≤ P + 1}` are all ℕ-valued and well-formed
  - NAT-addcompat (NatAdditionOrderAndSuccessor, ASN-0034) — supplies right order-compatibility, lifting `i ≤ P` to `i + 1 ≤ P + 1` so the renumbering `ρ`'s skipped values stay inside the larger index segment, and the strict successor inequality `n < n + 1`, giving `i + 1 > i ≥ k₀` so `ρ` misses exactly the deleted index `k₀`; this is the index arithmetic by which deletion-and-renumbering reduces the step to the induction hypothesis
  - NAT-cancel (NatAdditionCancellation, ASN-0034) — supplies right cancellation of `+`, `n + m = p + m ⟹ n = p`, at the summand `m := 1`, to settle the renumbering `ρ`'s injectivity in its same-branch upper case: for `k₀ ≤ a < b ≤ P` both indices map through the successor branch to `ρ.a = a + 1` and `ρ.b = b + 1`, and right cancellation turns the hypothetical collision `a + 1 = b + 1` into `a = b`, against `a < b`. This is the lone injectivity case NAT-addcompat cannot reach — its right order-compatibility weakens `a < b` only to `a + 1 ≤ b + 1`, which leaves `a + 1 = b + 1` admissible — so without cancellation `ρ`, and with it the composite `h′ = h ∘ ρ`, would be unestablished as injective. The same right cancellation at the summand `1` also discharges `ρ`'s surjectivity placements (see the NAT-discrete bullet): it reads the discreteness-derived bound `j + 1 ≤ P + 1` as `j ≤ P` in the below-`k₀` sub-case, and the bounds `k₀ + 1 ≤ i + 1` and `i + 1 ≤ P + 1` as `k₀ ≤ i` and `i ≤ P` in the above-`k₀` sub-case, the pair that puts the predecessor `i` in the successor branch's index range `{k : k₀ ≤ k ≤ P}`
  - NAT-discrete (NatDiscreteness, ASN-0034) — supplies discreteness `m < n ⟹ m + 1 ≤ n`, its forward direction grounding both sub-cases of the renumbering `ρ`'s surjectivity onto the punctured segment. In the below-`k₀` sub-case, instantiated at `(m, n) := (j, P + 1)`: a punctured-segment index `j < k₀` is hit by itself, `ρ.j = j`, only once `j` is placed in `ρ`'s domain `{k : 1 ≤ k ≤ P}`, and the chain `j < k₀ ≤ P + 1` (closed by NAT-order's transitivity) descends through this discreteness to `j + 1 ≤ P + 1`, which right cancellation at the summand `1` (NAT-cancel) reads as `j ≤ P`. In the above-`k₀` sub-case, instantiated at `(m, n) := (k₀, j)`: a punctured-segment index `k₀ < j` is hit as the successor `ρ.i = i + 1 = j` of its predecessor `i`, and `k₀ < j` descends through this discreteness to `k₀ + 1 ≤ j = i + 1`, which right cancellation at the summand `1` (NAT-cancel) reads as `k₀ ≤ i`, putting `i` at or above the deletion point so the successor branch governs it (its companion bound `i ≤ P`, from `i + 1 ≤ P + 1` by the same cancellation, completes the domain membership). These are the surjectivity sub-cases the listed order axioms cannot reach — NAT-order alone passes `j < k₀ ≤ P + 1` only to the strict `j < P + 1`, one short of the `j ≤ P` domain membership demands, and passes `k₀ < j` only to itself, never to the `k₀ ≤ i` the successor branch demands — so without discreteness the sub-cases "`j < k₀` is hit by itself" and "`k₀ < j` is hit as `i + 1`" are ungrounded, `ρ`'s bijection onto `{k : 1 ≤ k ≤ P + 1} \ {k₀}` fails, and the image identity `{h.k : 1 ≤ k ≤ P + 1 ∧ k ≠ k₀} = S \ {μ}` on which the induction hypothesis and the prepend-`μ` construction turn cannot be drawn
