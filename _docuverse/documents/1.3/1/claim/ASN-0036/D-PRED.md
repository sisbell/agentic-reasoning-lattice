**D-PRED (PredecessorExistence).** Every natural at or above `1` is a successor — it has a predecessor inside `ℕ`:

`(A j ∈ ℕ : j ≥ 1 : (E i ∈ ℕ :: i + 1 = j))`.

Equivalently, every strictly positive natural `j` (the regime `j ≥ 1`, which over `ℕ` is `j > 0`) is `i + 1` for some `i ∈ ℕ`.

*Proof.* We want, for an arbitrary `j ∈ ℕ` with `j ≥ 1`, a natural `i` whose successor is `j`. The signature of `ℕ` runs the other way: NAT-closure (NatArithmeticClosureAndIdentity, ASN-0034) gives the *forward* successor `i ↦ i + 1`, but the foundations posit no predecessor operation and no subtraction, so there is no term to evaluate at `j`. Nor does the bare order fact `j ≥ 1` name an `i` with `i + 1 = j`; that `i` must be produced.

It cannot be produced from well-ordering alone. One is tempted to argue by descent — suppose some `j ≥ 1` had no predecessor, take the least such `j₀` by NAT-wellorder, and seek a contradiction — but the contradiction never closes: nothing in the NAT-* group forces a least counterexample `j₀ > 1` to be a successor, so nothing dislodges it. The gap is not in the argument but in the foundation. The order type `ω · 2` — the standard naturals trailed by a second copy `ω < ω + 1 < ⋯`, with `+` extended injectively — models every NAT-* axiom: it is strictly, totally, discretely well-ordered, its addition closed, cancellative, order-compatible, with `0` least and identity. Yet `ω` is positive with no predecessor. Well-ordering, discreteness, and ordered cancellative addition simply do not entail that every positive natural is reached from `0` by succession; that is an independent fact about how `ℕ` is *generated*, and it is exactly what NAT-induction (NatInduction) posits.

So we reason from NAT-induction. Let `H = {n ∈ ℕ : n = 0 ∨ (E i ∈ ℕ :: i + 1 = n)}` — the naturals that are either zero or a successor. We show `H = ℕ` by NAT-induction, which asks just two things of `H`.

**`0 ∈ H`.** Immediate: the left disjunct `n = 0` holds at `n = 0`.

**`H` is closed under successor.** Let `k ∈ ℕ`; we show `k + 1 ∈ H`. The successor `k + 1` lies in `ℕ` by NAT-closure's successor closure `n + 1 ∈ ℕ`, and `i := k` witnesses the right disjunct `(E i ∈ ℕ :: i + 1 = k + 1)` — the witness `k` is in `ℕ` by hypothesis. So `k + 1 ∈ H`, and this holds whether or not `k ∈ H`: membership of `k` is never consulted, the successor form of `k + 1` being read directly off its presentation. This is the one move the descent argument could not make — we are not asserting that an arbitrary `n` is a successor, but only that an `n` *already presented as* `k + 1` is one, and it is NAT-induction that propagates this from the generators to all of `ℕ`.

By NAT-induction the only subset of `ℕ` containing `0` and closed under successor is `ℕ` itself, so `H = ℕ`: every natural is `0` or a successor.

Now fix `j ∈ ℕ` with `j ≥ 1`. Membership `j ∈ H` gives `j = 0 ∨ (E i ∈ ℕ :: i + 1 = j)`. The left disjunct is excluded: `0 < 0 + 1 = 1` by NAT-addcompat's (NatAdditionOrderAndSuccessor, ASN-0034) strict successor inequality `n < n + 1` read at `n := 0`, with `0 + 1 = 1` by NAT-closure's left identity `0 + n = n` at `n := 1`; chaining `0 < 1` with the hypothesis `1 ≤ j` gives `0 < j` — not through a named mixed transitivity of NAT-order (NatStrictTotalOrder, ASN-0034), which posits transitivity only in the pure strict form `a < b ∧ b < c ⟹ a < c`, but through the two-case split its `≤`-definition `1 ≤ j ⟺ 1 < j ∨ 1 = j` opens: when `1 < j`, the pure `<`-transitivity Axiom closes `0 < 1 ∧ 1 < j ⟹ 0 < j`; when `1 = j`, indiscernibility of `=` rewrites `0 < 1` to `0 < j`. Either way `0 < j`, whence `j ≠ 0` by NAT-order's irreflexivity `¬(n < n)`. So the right disjunct stands: there is an `i ∈ ℕ` with `i + 1 = j`. The base predecessor is the visible instance: at `j = 1` the witness is `i = 0`, with `0 ∈ ℕ` by NAT-zero (NatZeroMinimum, ASN-0034) and `0 + 1 = 1` by NAT-closure. ∎

The lemma exports existence only — which is all its consumer needs. D-INJ's renumbering meets the lemma in its above-`k₀` surjectivity sub-case: there a punctured-segment value `j > k₀` must be exhibited as `ρ.i = i + 1 = j`, and D-PRED hands the index `i` before the bounds `k₀ ≤ i ≤ P` are read off `i + 1 = j`. That consumer needs only *some* predecessor, never a *unique* one, so we prove and export existence alone and make no uniqueness claim — keeping the lemma's footing to the foundations the construction actually uses.

*Formal Contract:*

- *Lemma:* `(A j ∈ ℕ : j ≥ 1 : (E i ∈ ℕ :: i + 1 = j))` — every natural `j ≥ 1` (equivalently, over `ℕ`, every `j > 0`) is the successor `i + 1` of some natural `i`. Proved from NAT-induction: the set `H = {n ∈ ℕ : n = 0 ∨ (E i ∈ ℕ :: i + 1 = n)}` contains `0` (left disjunct) and is closed under successor (`k + 1` witnesses the right disjunct via `i = k`, with `k + 1 ∈ ℕ` by NAT-closure's successor closure), so NAT-induction gives `H = ℕ` — every natural is `0` or a successor. For `j ≥ 1` the zero alternative is excluded (`0 < 1` from NAT-addcompat's strict successor, then `0 < 1 ≤ j` closed to `0 < j` by a two-case split on NAT-order's `≤`-definition — pure `<`-transitivity when `1 < j`, indiscernibility of `=` when `1 = j` — so `j ≠ 0` by irreflexivity), leaving the successor alternative; at `j = 1` the witness is `i = 0` (`0 ∈ ℕ` by NAT-zero, `0 + 1 = 1` by NAT-closure's left identity). Well-ordering does not establish this — the order type `ω · 2` satisfies every NAT-* axiom yet has the predecessorless positive element `ω` — so the proof rests on NAT-induction, not on a least-counterexample descent. Only existence is exported — the downstream use (D-INJ) needs some predecessor, not a unique one, so the lemma makes no uniqueness claim.

- *Depends:*
  - NAT-induction (NatInduction) — the load-bearing axiom: it supplies the generation-from-`0` principle by which the set `H` of zeros-and-successors, shown to contain `0` and be closed under successor, exhausts `ℕ`. This is the structural fact the bare order axioms lack — NAT-wellorder yields a least counterexample but cannot force it to be a successor, the order type `ω · 2` being a NAT-* model with a predecessorless positive element — so predecessor existence is read from induction, not from well-ordering
  - NAT-zero (NatZeroMinimum, ASN-0034) — supplies `0 ∈ ℕ`, the base-case predecessor witness `i = 0` for `j = 1`, so that the predecessor of `1` lies inside the carrier rather than outside it
  - NAT-closure (NatArithmeticClosureAndIdentity, ASN-0034) — supplies the successor closure `n + 1 ∈ ℕ`, which keeps the successor-closure step's witness `i = k` and its successor `k + 1` ℕ-valued, and the left-identity clause `0 + n = n`, instantiated at `n := 1` to read `0 + 1 = 1` (closing the `j = 1` witness and, with NAT-addcompat, the `0 < 1` step); it is also the foundation that furnishes the forward successor `i ↦ i + 1` while furnishing no predecessor inverse, which is why existence must be established rather than read off a term
  - NAT-addcompat (NatAdditionOrderAndSuccessor, ASN-0034) — supplies the strict successor inequality `n < n + 1`, read at `n := 0` as `0 < 0 + 1 = 1`, the strict half of the `0 < 1 ≤ j` chain that excludes the zero alternative for `j ≥ 1`
  - NAT-order (NatStrictTotalOrder, ASN-0034) — supplies the pure strict transitivity Axiom `a < b ∧ b < c ⟹ a < c` and the `≤`-definition `m ≤ n ⟺ m < n ∨ m = n`, from which the mixed chain `0 < 1 ≤ j ⟹ 0 < j` is built inline by a two-case split (pure `<`-transitivity when `1 < j`; indiscernibility of `=` rewriting `0 < 1` to `0 < j` when `1 = j`) — NAT-order exports no mixed-transitivity form, so this bridge is assembled here from those tools rather than cited as a postcondition; and the irreflexivity `¬(n < n)` that turns the resulting `0 < j` into `j ≠ 0`, the step that discharges the `j ≥ 1` guard into the successor alternative of `H`
- *Forward References:*
  - D-INJ (InjectiveImageCardinality) — downstream consumer of this lemma; its above-k₀ surjectivity sub-case draws the predecessor `i` from D-PRED and is the motivating use that bounds the lemma to existence alone
