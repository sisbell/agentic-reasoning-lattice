**ValidInsertionPosition (ValidInsertionPosition).** For a document `d` with `V_1(d) ≠ ∅`, the *binary* predicate `ValidInsertionPosition(d, v)` is satisfied when:

- The common V-position depth `m` of V_1(d) is fixed by S8-depth. By S8a, `m ≥ 2`.
- Setting `N = |{k ∈ ℕ : [1, ..., 1, k] ∈ V_1(d)}|` — the number of last-component values attained in `V_1(d)`, equivalently the document's V-position count, grounded as a natural in the proof via D-SEQ — the predicate holds iff `v = min(V_1(d))` or `v = shift(min(V_1(d)), j)` for some `j ∈ {1, ..., N}`.

*Proof.* We must first see that `N` is a natural, so that the index range `{1, ..., N}` is well-formed. The only cardinality primitive, NAT-card (ASN-0034), posits `|·|` solely on subsets of an initial segment `{j ∈ ℕ : 1 ≤ j ≤ n}`; `V_1(d)` is a set of tumblers — never such a subset — so `|V_1(d)|` is not a count NAT-card supplies, and we must instead count a set already lying in `ℕ`. Just as S8a invokes NAT-card only after exhibiting its index set as a `{1, ..., #t}`-subset, we take the *last-component set* `L = {k ∈ ℕ : [1, ..., 1, k] ∈ V_1(d)}`, a subset of `ℕ` by construction. D-SEQ (SequentialPositions) identifies it: it exhibits `V_1(d)` as the finite block `{[1, ..., 1, k] : 1 ≤ k ≤ n}` for some `n ≥ 1`, every tuple of the common depth `m`, so the last components attained are exactly `{1, ..., n}` — that is, `L = {1, ..., n}`, itself an initial segment. On it NAT-card gives `|{1, ..., n}| = n` directly, the strictly increasing enumerator being the identity `f.j = j` with image `{1, ..., n}`. Hence `N = |L| = n ∈ ℕ` with `n ≥ 1`, and `{1, ..., N}` is a well-formed index range. (Equivalently, one may take `N` to be D-SEQ's `n` outright.)

By D-MIN, `min(V_1(d)) = [1, 1, ..., 1]` of depth `m`. By OrdinalShift (ASN-0034), `shift([1, ..., 1], j)` leaves the leading `m − 1` components unchanged and advances the last component to `1 + j`, so `shift([1, ..., 1], j) = [1, ..., 1, 1 + j]` for `j ≥ 1`; at `j = 0` the position is `v = min(V_1(d)) = [1, ..., 1]` by D-MIN. Every component is then `≥ 1` — the leading `m − 1` equal 1, the last `1 + j ≥ 1` — so `zeros(v) = 0` with componentwise positivity, and OrdShiftHom (a) fixes `v₁ = 1` as the text subspace identifier. For `j ≠ j'` in `{0, ..., N}` — distinct indices of the range under the strict total order (NAT-order, ASN-0034) — the last components satisfy `1 + j ≠ 1 + j'`: were `1 + j = 1 + j'`, left cancellation instantiated at `m = 1` would force `j = j'` (NAT-cancel, ASN-0034), contradicting `j ≠ j'`. The length-`m` tumblers then diverge at position `m` and are distinct by T3 (ASN-0034), giving exactly `N + 1` positions. ∎

*Formal Contract:*

- *Preconditions:* `V_1(d) ≠ ∅`; the common V-position depth `m` of `V_1(d)` is fixed by S8-depth and satisfies `m ≥ 2` by S8a.
- *Definition:* With `N = |{k ∈ ℕ : [1, ..., 1, k] ∈ V_1(d)}|` — grounded as D-SEQ's natural `n ≥ 1`: D-SEQ gives `V_1(d) = {[1, ..., 1, k] : 1 ≤ k ≤ n}`, so the last-component set `{k ∈ ℕ : [1, ..., 1, k] ∈ V_1(d)}` is exactly the initial segment `{1, ..., n}`, on which NAT-card fixes `|{1, ..., n}| = n`, giving `N = n` — `ValidInsertionPosition(d, v)` holds iff `v = min(V_1(d))` or `v = shift(min(V_1(d)), j)` for some `j ∈ {1, ..., N}`. By D-MIN, `min(V_1(d)) = [1, ..., 1]` of depth `m`, and by OrdinalShift (ASN-0034) `shift([1, ..., 1], j) = [1, ..., 1, 1 + j]`; equivalently the satisfying set is `{[1, ..., 1, 1 + j] : j ∈ {0, ..., N}}`.
- *Postconditions:* The satisfying set contains exactly `N + 1` pairwise-distinct positions (NAT-cancel, NAT-order, and T3, ASN-0034). Each satisfying `v` has `v₁ = 1` as the text subspace identifier (OrdShiftHom) and `zeros(v) = 0` with every component `≥ 1` (componentwise positivity).
