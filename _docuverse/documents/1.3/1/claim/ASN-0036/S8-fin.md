**S8-fin (FiniteArrangement).** For each document `d`, the active V-position set `dom(Σ.M(d))` is finite — no document arrangement is permitted to hold infinitely many V-positions. We are after a statement of this finiteness that stays within grounded notation, and here we must take care. The natural reflex is to write `|dom(Σ.M(d))| ∈ ℕ`, but NAT-card axiomatises `|·|` only for subsets `S ⊆ {j ∈ ℕ : 1 ≤ j ≤ n}` of an initial segment of ℕ, whereas `dom(Σ.M(d)) ⊆ T` is a set of *tumblers* — finite sequences over ℕ, not naturals — and so falls outside that operator's defined scope. We therefore express finiteness directly, by the device that needs no cardinality operator on the carrier in question: a set is finite exactly when an initial segment of ℕ can be put in bijection with it. Concretely, for every reachable state `Σ` and every document `d` we posit some `n ∈ ℕ` and a bijection `f : {j ∈ ℕ : 1 ≤ j ≤ n} → dom(Σ.M(d))` — total into `dom(Σ.M(d))`, injective, and onto. The index domain `{j ∈ ℕ : 1 ≤ j ≤ n}` rests on three foundations at once — NAT-carrier's `ℕ` (the set its members are drawn from, and over which the bound `n ∈ ℕ` is quantified), NAT-closure's `1 ∈ ℕ` (its lower bound), and NAT-order's `≤` (the relation bounding `j` between `1` and `n`) — while the codomain `dom(Σ.M(d)) ⊆ T` rests on T0's tumbler carrier `T`. We are careful not to charge the initial-segment device to T0: T0 writes the same `{j ∈ ℕ : 1 ≤ j ≤ ·}` into its own component-projection and comprehension clauses, but grounds that device through *its own* dependence on NAT-closure and NAT-order rather than exporting it as a postcondition — so a consumer that writes the segment directly, as we do, must ground its `1` and `≤` from those foundations itself, taking from T0 only the carrier `T` that T0 genuinely exports. No appeal to `|·|` is made, so the notation stays within its grounded scope. The empty arrangement is the case `n = 0`, where the index domain `{j ∈ ℕ : 1 ≤ j ≤ 0}` is empty, `f` the empty function, and both the injectivity and surjectivity clauses hold vacuously — so `dom(Σ.M(d)) = ∅` is admitted, exactly as NAT-card's `k = 0` case admits the empty set.

This is a design requirement on every reachable state. We posit it rather than derive it; the point of naming it is methodological — several downstream proofs need an explicit, citable finiteness premise, most sharply S8, whose forward lockstep walk on `dom(M(d))` terminates only because the domain is finite and whose maximal-run decomposition is finite for the same reason. Every consumer (S8, D-SEQ, D-CTG-depth, D-MIN) reads S8-fin solely as the property that `dom(M(d))` is finite — forward walks terminate, a non-empty subset has a least element, no infinite strictly-increasing sequence of positions fits inside it — and never as a numeric cardinality value, so the bijection formulation discharges exactly what they consume.

*Formal Contract:*
- *Axiom:* For every reachable state `Σ` and every document `d`, `dom(Σ.M(d))` is finite — stated without the `|·|` operator, which NAT-card scopes to subsets of initial segments of ℕ and not to the tumbler set `T ⊇ dom(Σ.M(d))` — as the existence of an enumerating bijection from an initial segment of ℕ:
  `(A d :: (E n : n ∈ ℕ : (E f :: f : {j ∈ ℕ : 1 ≤ j ≤ n} → dom(Σ.M(d)) ∧ (A i, j : 1 ≤ i < j ≤ n : f.i ≠ f.j) ∧ (A v : v ∈ dom(Σ.M(d)) : (E j : 1 ≤ j ≤ n : f.j = v)))))`
  — `f` total into `dom(Σ.M(d))`, injective (the clause `(A i, j : 1 ≤ i < j ≤ n : f.i ≠ f.j)`: distinct indices give distinct positions) and surjective (the clause `(A v : v ∈ dom(Σ.M(d)) : (E j : 1 ≤ j ≤ n : f.j = v))`: every active position is enumerated) — holding at every state reachable from the base state `Σ₀` by the transition relation. This is a protocol design posit, accepted within this ASN without proof — it constrains the class of permitted implementations, admitting no reachable arrangement that maps infinitely many V-positions to a single document. It is not derived from any other claim; S8 and the other consumers invoke it only as the finiteness property — to terminate the forward lockstep walk and to bound the maximal-run decomposition — never as a numeric cardinality value.
- *Depends:*
  - NAT-carrier (NatCarrierSet, ASN-0034) — supplies `ℕ`, the carrier over which the witness `n` is quantified (`n ∈ ℕ`) and from which the bijection's index domain `{j ∈ ℕ : 1 ≤ j ≤ n}` draws its members; its lower bound `1` and the bounding relation `≤` come not from NAT-carrier but from NAT-closure and NAT-order below. Supplying `ℕ` is what lets finiteness be stated as a bijection from an initial segment of ℕ, replacing the out-of-scope `|·|`
  - NAT-closure (NatArithmeticClosureAndIdentity, ASN-0034) — supplies `1 ∈ ℕ`, the lower bound `1` written directly into the bijection's index domain `{j ∈ ℕ : 1 ≤ j ≤ n}` and into the injectivity clause `1 ≤ i < j ≤ n` and surjectivity witness range `1 ≤ j ≤ n` of the axiom. T0 uses this same lower bound `1` in its own index domains but grounds it through T0's own dependence on NAT-closure rather than exporting it; the axiom writes `1` as a first-class constant, so it is grounded here directly
  - NAT-order (NatStrictTotalOrder, ASN-0034) — supplies the strict order `<` and its non-strict companion `≤` on ℕ, both written directly into the axiom: `≤` bounds the bijection's index domain `{j ∈ ℕ : 1 ≤ j ≤ n}` and the surjectivity witness range `1 ≤ j ≤ n`, while the injectivity clause `1 ≤ i < j ≤ n` uses `≤` together with the strict `<` ordering the two indices. T0 consumes the same `≤` internally to bound its own index domains but grounds it through T0's own dependence on NAT-order rather than exporting it; the axiom consumes `<` and `≤` as first-class operators, so they are grounded here directly
  - T0 (CarrierSetDefinition, ASN-0034) — supplies the tumbler carrier `T ⊇ dom(Σ.M(d))` that types the bijection's codomain `dom(Σ.M(d)) ⊆ T`. This is the whole of what T0 exports to S8-fin: the bijection's domain `{j ∈ ℕ : 1 ≤ j ≤ n}` is *not* among T0's postconditions — those cover the carrier `T`, the length operator `#·`, the component-projection signature, the comprehension clause, and extensionality — so the initial-segment domain is grounded directly from NAT-carrier, NAT-closure, and NAT-order above, not from T0
