**S8-fin (FiniteArrangement).** For each document `d`, `dom(Σ.M(d))` is finite. This is a design requirement on every reachable state: no document arrangement is permitted to hold infinitely many V-positions. We posit it rather than derive it; the point of naming it is methodological — several downstream proofs need an explicit, citable finiteness premise, most sharply S8, whose forward lockstep walk on `dom(M(d))` terminates only because the domain is finite and whose maximal-run decomposition is finite for the same reason.

*Formal Contract:*
- *Axiom:* For every reachable state `Σ` and every document `d`, `dom(Σ.M(d))` is finite: `(A d :: |dom(Σ.M(d))| ∈ ℕ)` holds at every state reachable from the base state `Σ₀` by the transition relation. This is a protocol design posit, accepted within this ASN without proof — it constrains the class of permitted implementations, admitting no reachable arrangement that maps infinitely many V-positions to a single document. It is not derived from any other claim; S8 invokes it to terminate the forward lockstep walk and to bound the maximal-run decomposition.
