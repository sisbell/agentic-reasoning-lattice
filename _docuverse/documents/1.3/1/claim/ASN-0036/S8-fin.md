**S8-fin (FiniteArrangement).** For each document `d`, the active V-position set `dom(Σ.M(d))` is finite — no document arrangement is permitted to hold infinitely many V-positions. We are after a statement of this finiteness that stays within grounded notation, and here we must take care. The natural reflex is to write `|dom(Σ.M(d))| ∈ ℕ`, but NAT-card axiomatises `|·|` only for subsets `S ⊆ {j ∈ ℕ : 1 ≤ j ≤ n}` of an initial segment of ℕ, whereas `dom(Σ.M(d)) ⊆ T` is a set of *tumblers* — finite sequences over ℕ, not naturals — and so falls outside that operator's defined scope. We therefore express finiteness directly, by the device that needs no cardinality operator on the carrier in question: a set is finite exactly when an initial segment of ℕ can be put in bijection with it. Concretely, for every reachable state `Σ` and every document `d` we posit some `n ∈ ℕ` and a bijection `f : {j ∈ ℕ : 1 ≤ j ≤ n} → dom(Σ.M(d))` — total into `dom(Σ.M(d))`, injective, and onto. The index domain `{j ∈ ℕ : 1 ≤ j ≤ n}` and its bound `n ∈ ℕ` rest on NAT-carrier's `ℕ` and T0's typed initial-segment construction; the codomain `dom(Σ.M(d)) ⊆ T` rests on T0's tumbler carrier `T`. No appeal to `|·|` is made, so the notation stays within its grounded scope. The empty arrangement is the case `n = 0`, where the index domain `{j ∈ ℕ : 1 ≤ j ≤ 0}` is empty, `f` the empty function, and both the injectivity and surjectivity clauses hold vacuously — so `dom(Σ.M(d)) = ∅` is admitted, exactly as NAT-card's `k = 0` case admits the empty set.

This is a design requirement on every reachable state. We posit it rather than derive it; the point of naming it is methodological — several downstream proofs need an explicit, citable finiteness premise, most sharply S8, whose forward lockstep walk on `dom(M(d))` terminates only because the domain is finite and whose maximal-run decomposition is finite for the same reason. Every consumer (S8, D-SEQ, D-CTG-depth, D-MIN) reads S8-fin solely as the property that `dom(M(d))` is finite — forward walks terminate, a non-empty subset has a least element, no infinite strictly-increasing sequence of positions fits inside it — and never as a numeric cardinality value, so the bijection formulation discharges exactly what they consume.

*Formal Contract:*
- *Axiom:* For every reachable state `Σ` and every document `d`, `dom(Σ.M(d))` is finite — stated without the `|·|` operator, which NAT-card scopes to subsets of initial segments of ℕ and not to the tumbler set `T ⊇ dom(Σ.M(d))` — as the existence of an enumerating bijection from an initial segment of ℕ:
  `(A d :: (E n : n ∈ ℕ : (E f :: f : {j ∈ ℕ : 1 ≤ j ≤ n} → dom(Σ.M(d)) ∧ (A i, j : 1 ≤ i < j ≤ n : f.i ≠ f.j) ∧ (A v : v ∈ dom(Σ.M(d)) : (E j : 1 ≤ j ≤ n : f.j = v)))))`
  — `f` total into `dom(Σ.M(d))`, injective (the clause `(A i, j : 1 ≤ i < j ≤ n : f.i ≠ f.j)`: distinct indices give distinct positions) and surjective (the clause `(A v : v ∈ dom(Σ.M(d)) : (E j : 1 ≤ j ≤ n : f.j = v))`: every active position is enumerated) — holding at every state reachable from the base state `Σ₀` by the transition relation. This is a protocol design posit, accepted within this ASN without proof — it constrains the class of permitted implementations, admitting no reachable arrangement that maps infinitely many V-positions to a single document. It is not derived from any other claim; S8 and the other consumers invoke it only as the finiteness property — to terminate the forward lockstep walk and to bound the maximal-run decomposition — never as a numeric cardinality value.
- *Depends:*
  - NAT-carrier (NatCarrierSet, ASN-0034) — supplies `ℕ`, the carrier over which the witness `n` is quantified (`n ∈ ℕ`) and from which the enumerating function's index domain `{j ∈ ℕ : 1 ≤ j ≤ n}` is carved; this is what lets finiteness be stated as a bijection from an initial segment of ℕ, replacing the out-of-scope `|·|`
  - T0 (CarrierSetDefinition, ASN-0034) — supplies the tumbler carrier `T ⊇ dom(Σ.M(d))` that types the bijection's codomain, and the typed initial-segment construction `{j ∈ ℕ : 1 ≤ j ≤ n}` (T0's own index-domain device) used as the bijection's domain; together these keep the finiteness statement within grounded, typed notation
