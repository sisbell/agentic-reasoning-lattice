# Note Extract

Note-extract is a producer agent whose primary substrate effect is granting a new workshop-ASN identity from claims selected for separate refinement: emitting a `note` classifier on the new ASN, `extract` linkage to the source, and `provenance.extract` on the carried claims. The workshop ASN evolves independently and may eventually be absorbed back.

## Triggers

- Operator-invoked, when the operator decides selected claims should be lifted into a separate workshop ASN.
