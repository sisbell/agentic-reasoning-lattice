# Note Absorb

Note-absorb is a refiner agent whose primary substrate effect is closing the integration of an extension ASN back into its base note: emitting `absorb` linkage between the two, retracting the extension, and emitting a patch-scoped review of the integrated claims. Drives the integration question to closure.

## Triggers

- Operator-invoked, after dropping an absorb spec for an extension ASN ready to merge into its base.
