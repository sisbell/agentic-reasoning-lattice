# Note Promote Out Of Scope

Note-promote-out-of-scope is a producer agent whose primary substrate effect is granting a new inquiry identity from OUT_OF_SCOPE review findings on a parent note: emitting an `inquiry` classifier on the new doc and `promotion.out-of-scope` linking parent to child. The new inquiry enters the inquiry-consult / note-draft cycle as a first-class substrate citizen.

## Triggers

- Operator-invoked, when the operator decides a review's OUT_OF_SCOPE flag warrants its own ASN-scale inquiry.
