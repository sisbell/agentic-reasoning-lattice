The same recommendation has surfaced before (review-30); per project policy, structural splits at this scale are operator-level lattice work and were already deferred for that reason. The finding is well-formed and the trigger (pre-protocol-docs window) is real, but the resolution belongs to a dedicated multi-step operator session, not to in-place revision.
