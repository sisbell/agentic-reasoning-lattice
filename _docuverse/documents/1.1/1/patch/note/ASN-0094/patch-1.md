# Bundled Citations — ASN-0094

The implementation needs `citation.depends` to admit bundled
multi-target emissions — one citing doc, many cited targets in a
single tuple — to carry the cascade-fresh signal for note review.
A review doc would record the foundation heads it read by emitting
one bundled `citation.depends`; the cascade-fresh predicate would
then walk that link's to-set checking each target's version status.

The Sh5 catalog has no row supporting cardinality `*` on G. Retraction
catalogues `*` on F at `(*, 1, A, A_rel, ⊤)`, but the symmetric
G-side cardinality is uncatalogued. Sh-conf cannot admit bundled
`citation.depends` emissions under the current registration.

Legacy single-target `citation.depends` emissions must remain
conformant.
