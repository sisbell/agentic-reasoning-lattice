### Body proof collapse step in D-MIN: missing case split on ≤ in the ⊆ direction
**Class**: REVISE
**Foundation**: NAT-order (NatStrictTotalOrder, ASN-0034) — ≤-definition `m ≤ n ⟺ m < n ∨ m = n`; NAT-order < transitivity; NAT-order irreflexivity
**ASN**: D-MIN (VMinimumPosition), body paragraph "Existence and uniqueness of the minimum," inductive step ⊆ direction — *"and were N < j, NAT-discrete's m < n ⇒ m + 1 ≤ n at (N, j) would force N + 1 ≤ j, collapsing against j < N + 1 to N + 1 < N + 1, barred by NAT-order's irreflexivity"*; identically in the Depends section — *"discharging the N + 1 < N + 1 contradiction that NAT-discrete's N < j ⇒ N + 1 ≤ j produces against j < N + 1"*
**Issue**: The step claims that `N+1 ≤ j ∧ j < N+1` collapses to `N+1 < N+1` in one move. This is a ≤-< composition on ℕ. NAT-order does not export mixed ≤-< transitivity as a postcondition; it exports only strict `<` transitivity and `≤` transitivity separately. Reducing the compound premise to `N+1 < N+1` requires splitting on NAT-order's ≤-definition (`N+1 ≤ j ⟺ N+1 < j ∨ N+1 = j`) and dispatching each disjunct:
- `N+1 < j ∧ j < N+1 ⟹ N+1 < N+1` (by `<` transitivity).
- `N+1 = j ∧ j < N+1 ⟹ N+1 < N+1` (by substitution of `=`).

Neither the body nor the Depends section performs this split. The Depends section credits NAT-order's ≤-definition as "read twice in the ⊇ direction" but does not cite it in the ⊆ direction where the composition actually occurs. This is inconsistent with the body's own treatment of the mixed chain `g.(N+1) < g.J′ ≤ g.j` in the inductive sub-case N+1 ∈ Q, where the split *is* written out explicitly: *"split on the ≤: g.J′ < g.j through pure <-transitivity, g.J′ = g.j by rewriting g.(N+1) < g.J′ under indiscernibility of ="*. The ⊆-direction collapse is the same shape of argument and warrants the same treatment.
**What needs resolving**: In the ⊆ direction of the segment identity, replace "collapsing against j < N+1 to N+1 < N+1" with an explicit case split on NAT-order's ≤-definition for `N+1 ≤ j`: case `N+1 < j`, close by `<` transitivity with `j < N+1`; case `N+1 = j`, close by equality substitution into `j < N+1`. Both sub-cases yield `N+1 < N+1`, discharged by irreflexivity. The Depends section should correspondingly list NAT-order's ≤-definition as consumed in the ⊆ direction, parallel to its explicit entry for the ⊇ direction.
