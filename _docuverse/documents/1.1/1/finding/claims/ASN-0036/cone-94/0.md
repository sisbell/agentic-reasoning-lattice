### D-INJ renumbering surjectivity: above-k₀ case asserted, not proved
**Class**: REVISE
**Foundation**: NAT-discrete (NatDiscreteness), NAT-cancel (NatAdditionCancellation)
**ASN**: D-INJ (InjectiveImageCardinality), induction step, surjectivity paragraph — *"every index below k₀ is hit by itself and every index above k₀ is hit as some i + 1, while k₀ itself is missed."* The proof then spends a paragraph on the below-k₀ case and the k₀-not-hit case, but never returns to the above-k₀ case.
**Issue**: The below-k₀ case is argued in full: j < k₀ ≤ P+1 chains to j < P+1 (NAT-order transitivity), NAT-discrete descends this to j+1 ≤ P+1, and NAT-cancel right-cancels the summand 1 to yield j ≤ P, placing j in ρ's domain before reading off ρ.j = j. The above-k₀ case needs the symmetric argument: for j with k₀ < j ≤ P+1, exhibit i ∈ {k₀,...,P} such that i+1 = j. The steps required are exactly the same axioms already listed in D-INJ's Depends — NAT-discrete converts k₀ < j to k₀+1 ≤ j (so the candidate i = j−1 satisfies i ≥ k₀), and NAT-cancel right-cancels the summand 1 from j ≤ P+1 to yield i ≤ P — but the proof provides no argument, only the assertion. The image identity {h.k : 1 ≤ k ≤ P+1 ∧ k ≠ k₀} = S \ {μ}, on which the IH application and the prepend-μ construction turn, depends directly on ρ being surjective onto {1,...,P+1} \ {k₀}. The claim is correct but ungrounded.
**What needs resolving**: Supply the above-k₀ surjectivity argument: for j with k₀ < j ≤ P+1, apply NAT-discrete at (k₀, j) to obtain k₀+1 ≤ j, establishing that a candidate i satisfying i+1 = j meets i ≥ k₀; apply NAT-cancel right-cancellation at the summand 1 to obtain i ≤ P from j ≤ P+1; conclude ρ.i = i+1 = j via the successor branch. The existence of i with i+1 = j in ℕ is the same predecessor-style step the proof already performs (in the k₀-not-hit paragraph: "i+1 > i ≥ k₀" uses NAT-addcompat's n < n+1); making the parallel explicit closes the gap.

VERDICT: REVISE
