### D-CTG-depth finiteness proof silently assumes N ≥ 1
**Class**: REVISE
**Foundation**: S8-fin (FiniteArrangement); NAT-zero (NatZeroMinimum)
**ASN**: D-CTG-depth body, finiteness step: *"By the surjectivity clause each is enumerated, so for 1 ≤ k ≤ N + 1 we may choose rₖ ∈ {r ∈ ℕ : 1 ≤ r ≤ N} with f.rₖ = w⁽ᵏ⁾."* The same language appears in the Preconditions block: *"pulls them back through its surjectivity to N + 1 pairwise-distinct indices in {r ∈ ℕ : 1 ≤ r ≤ N}, the impossible N + 1 ≤ N being the contradiction."*
**Issue**: S8-fin delivers a bound N ∈ ℕ; it does not guarantee N ≥ 1. When N = 0, the target set {r ∈ ℕ : 1 ≤ r ≤ 0} is empty (0 < 1, NAT-closure Consequence), so no rₖ exists and the "choose rₖ" step fails outright. The cardinality route then cannot proceed: D-INJ's injection k ↦ rₖ from {k ∈ ℕ : 1 ≤ k ≤ N+1} = {1} into {r ∈ ℕ : 1 ≤ r ≤ 0} = ∅ is a map from a non-empty set to an empty one, which cannot be exhibited. The proof as written assumes this choice always succeeds, but the N = 0 case requires a different argument: S8-fin's surjectivity clause applied to any w⁽¹⁾ ∈ dom(Σ.M(d)) asserts ∃ j ∈ {j ∈ ℕ : 1 ≤ j ≤ 0}, which is false (empty domain), contradicting S8-fin when dom(Σ.M(d)) ≠ ∅. Since V_1(d) ≠ ∅ is a precondition and V_1(d) ⊆ dom(Σ.M(d)), the contradiction is immediate in the N = 0 case — but via a path the proof never takes. A formal verifier encounters an unjustified existential instantiation and cannot proceed without N ≥ 1 being established.
**What needs resolving**: Before the "choose rₖ" step, derive N ≥ 1. One route: V_1(d) ≠ ∅ gives u ∈ dom(Σ.M(d)); S8-fin's surjectivity at v := u yields ∃ r ∈ {r ∈ ℕ : 1 ≤ r ≤ N}, so N ≥ 1. Alternatively, dispatch the N = 0 case as a separate branch: S8-fin's surjectivity applied to any w⁽¹⁾ ∈ dom(M(d)) asserts ∃ j ∈ ∅, which is false, giving the contradiction directly without building N+1 witnesses. Either treatment closes the gap; the D-INJ + NAT-card route applies only once N ≥ 1 is in hand (ensuring the injection's target is non-empty and D-INJ's image-count result is meaningful).

VERDICT: REVISE
