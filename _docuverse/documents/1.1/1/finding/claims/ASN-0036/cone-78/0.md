**ASN**: D-CTG-depth, Precondition 5 ("V_1(d) is contiguous (D-CTG): if u, x ∈ V_1(d), u < w < x, subspace(w) = 1, #w = #u, **and w satisfies S8a**, then w ∈ V_1(d)"); and proof body ("We also verify that w satisfies S8a — **necessary because D-CTG ranges over V_1(d) ⊆ dom(M(d))**")
**Issue**: D-CTG's actual inner-quantifier guard is `zeros(v) = 0` (plus v ∈ T, subspace(v) = 1, #v = #u, u < v < q). S8a is `zeros(t) = 0 ∧ #t ≥ 2`. Precondition 5 substitutes "w satisfies S8a" for D-CTG's guard, overstating it by adding the `#w ≥ 2` conjunct that D-CTG does not check. In the current proof's scope (m ≥ 3, so #w = m ≥ 3 ≥ 2 always), no soundness gap results — D-CTG's guard is satisfied and the contradiction holds — but the precondition and explanation misrepresent D-CTG's interface to any downstream reader.

In the proof body, correct the causal explanation: S8a is not a guard for D-CTG; what the proof verifies before invoking D-CTG is zeros(w) = 0 (part of D-CTG's guard), and `#w ≥ 2` follows independently from #w = m ≥ 3.
