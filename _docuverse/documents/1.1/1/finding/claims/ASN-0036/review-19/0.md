### Cardinality |·| applied outside NAT-card's domain
**Class**: REVISE
**Foundation**: NAT-card (NatFiniteSetCardinality) — `|·|` is posited only on `S ⊆ {j ∈ ℕ : 1 ≤ j ≤ n}`, characterised by a strictly increasing `f : {1,…,k} → ℕ` with `image f = S`.
**ASN**: ValidInsertionPosition Definition: `N = |V_1(d)|`, and its NAT-card Depends entry: *"transported across D-SEQ's bijection from that segment onto V_1(d), this fixes `N = |V_1(d)| = n`."* Also S5 Postcondition: `… |{(d, v) : v ∈ dom(Σ.M(d)) ∧ Σ.M(d)(v) = a}| > N`.
**Issue**: `|·|` is NAT-card's operator and is defined only for subsets of an ℕ-initial-segment. `V_1(d) ⊆ T` is a set of tumblers and `{(d,v) : …}` is a set of pairs; neither is a subset of `{j : 1 ≤ j ≤ n}`, so `|V_1(d)|` and `|{(d,v):…}|` lie outside NAT-card's domain (no `f : {1,…,k} → ℕ` can have a tumbler-set or pair-set as its image, so the "unique `k`" has no witness). ValidInsertionPosition closes the gap by "transporting `|·|` across a bijection" `{1,…,n} → V_1(d)`, but cardinality-invariance-under-bijection is not a foundation axiom — NAT-card furnishes only `|{1,…,n}| = n`. S5 has no bijection bridge at all; it asserts `|pair-set| = N+1` by informal counting. The discipline is respected everywhere else (`zeros(t) = |{i : 1 ≤ i ≤ #t ∧ tᵢ = 0}|` in S8a/S7/S7d/T4 keeps `|·|` on an `{1,…,#t}`-subset), so these two sites are inconsistent with the rest of the ASN.
**What needs resolving**: Express each count over a set that already lies in ℕ. For ValidInsertionPosition, count the last-component set `{k ∈ ℕ : [1,…,1,k] ∈ V_1(d)}` — a subset of ℕ, equal to `{1,…,n}` by D-SEQ, on which NAT-card gives `n` directly — or take `N := n` (D-SEQ's `n`) outright, dropping `|V_1(d)|` and the bijection-transport language. For S5, restate the multiplicity as the existence of `N+1` pairwise-distinct pairs (or count the explicit index set `{1,…,N+1} ⊆ ℕ`) rather than `|{(d,v):…}|`.
