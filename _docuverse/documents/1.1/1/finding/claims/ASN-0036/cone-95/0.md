### D-CTG-depth asserts an infinite witness sequence requiring dependent choice
**Class**: REVISE
**Foundation**: T0(a) (UnboundedComponentValues, ASN-0034)
**ASN**: D-CTG-depth body: *"continuing, we obtain a strictly increasing sequence n₁ < n₂ < n₃ < … of natural numbers, all exceeding uⱼ₊₁. The sequence is infinite and pairwise distinct … The sequence n₁ < n₂ < … being infinite has at least N + 1 terms, so we keep the first N + 1 witnesses."* The same claim appears in D-CTG-depth's Depends entry for T0(a): *"the extracted natural n = t′ⱼ₊₁ drives the strictly increasing sequence n₁ < n₂ < … of admissible intermediates that contradicts S8-fin."*
**Issue**: Building the infinite sequence n₁ < n₂ < n₃ < … requires ω-many applications of T0(a), each depending on the previous output — formally the Axiom of Dependent Choice (DC): from `(∀M ∈ ℕ)(∃n ∈ ℕ)(n > M)`, concluding `∃f : ℕ → ℕ` strictly increasing. DC is not among the foundations; NAT-wellorder (the least-element principle) does not imply it. The contradiction uses only N+1 witnesses for the specific N furnished by S8-fin for document d. Those N+1 values are constructible by exactly N+1 finite applications of T0(a) — apply it at M=uⱼ₊₁ to get n₁, at M=n₁ to get n₂, …, at M=n_N to get n_{N+1} — a finite iterated existential instantiation requiring no choice axiom. The "infinite" framing over-commits: it asserts the existence of an infinite object where the proof needs only a finite prefix of fixed length.
**What needs resolving**: Replace the infinite-sequence argument with a direct finite construction tied to the N from S8-fin. After instantiating S8-fin at d to obtain N, invoke T0(a) exactly N+1 times to produce n₁ < n₂ < … < n_{N+1}, all exceeding uⱼ₊₁. Remove the claim that the sequence is infinite; remove the "being infinite has at least N+1 terms" intermediary. The Depends entry for T0(a) should describe T0(a) as supplying N+1 witnesses by N+1 applications (not as "driving the strictly increasing sequence n₁ < n₂ < …").
