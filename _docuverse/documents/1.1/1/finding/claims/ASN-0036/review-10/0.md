### S7a / S7 narrative state the T10a.4 instantiation premise with a type error
**Class**: REVISE
**Foundation**: T10a (AllocatorDiscipline) — `𝒯` is "the set of allocators"; `dom(A) = {tₙ : n ≥ 0} ⊆ T` is a set of addresses (tumblers). T10a.4 (T4PreservationUnderDiscipline) — quantifies "for every allocator `A` in the tree and every `t ∈ dom(A)`."
**ASN**: Note body of S7a: *"every `a ∈ dom(Σ.C)` satisfies `a ∈ dom(A_element) ⊆ 𝒯` for a T10a-conforming element allocator `A_element` … This membership is the premise that … licenses T10a.4's preservation invariant to be instantiated at `a`."* And the S7 well-definedness proof: *"instantiating it at `A := A_element` and `t := a` — legitimate precisely because S7a places `a ∈ dom(A_element) ⊆ 𝒯` — yields that `a` is T4-valid."*
**Issue**: The chained membership `a ∈ dom(A_element) ⊆ 𝒯` asserts `dom(A_element) ⊆ 𝒯` — i.e. that the address domain (a set of tumblers in `T`) is a subset of the allocator tree (a set of allocators). That is a type error; addresses are not allocators. Read as a chain it concludes `a ∈ 𝒯` (the address is a node of the tree), which is both false and useless for the instantiation. T10a.4's instantiation at `A := A_element, t := a` requires **two memberships of distinct types** — `A_element ∈ 𝒯` (allocator-in-tree, supplying the `A` binding) and `a ∈ dom(A_element)` (address-in-domain, supplying the `t` binding) — but the narrative collapses them into one malformed expression and calls it "This membership" (singular). The claim-file versions of S7a and S7 already state this correctly: *"two memberships of distinct types — `A_element ∈ 𝒯` … and `a ∈ dom(A_element)`"* / *"S7a places `A_element ∈ 𝒯` and `a ∈ dom(A_element)`, the two memberships of distinct types the instantiation requires."* So the note carries a stale, incorrect formulation of a load-bearing well-definedness step.
**What needs resolving**: In the note body of S7a and S7, replace `a ∈ dom(A_element) ⊆ 𝒯` with the two distinct-type memberships `A_element ∈ 𝒯` and `a ∈ dom(A_element)` (matching the claim-file text), so the T10a.4 instantiation at `A := A_element, t := a` is licensed by the premises it actually requires.
