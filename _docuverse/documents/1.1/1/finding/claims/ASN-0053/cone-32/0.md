### S11 cardinality partition: case (a) trigger `α = β` is not the boundary condition the proof establishes
**Class**: REVISE
**Effective class**: OBSERVE (classifier override)
**Classifier rationale**: The proof discharges case (a) under "both boundaries coincide," which correctly yields cardinality 0, so the artifact is sound; the finding only flags a vocabulary mismatch between the postcondition's `α = β` label and the proof's boundary-coincidence trigger, a presentation refinement rather than a correctness defect.
**Foundation**: TumblerAdd (TumblerAdd) — its exported postconditions are `a ⊕ w ∈ T`, `#(a ⊕ w) = #w`, `a ⊕ w > a`, `a ⊕ w ≥ w`; it exports no left-cancellation/injectivity of `⊕`.
**ASN**: S11 *Postconditions*: "its cardinality is 0 when **α = β**, 1 when exactly one boundary coincides, and 2 when neither coincides." The proof body instead writes "(a) Both boundaries coincide (α = β): difference is empty — 0 spans."
**Issue**: The cardinality refinement is a three-way partition whose other two arms are stated in boundary-coincidence terms ("exactly one boundary coincides", "neither coincides"), but case (a) is stated as the representation-level equality `α = β`. The condition the proof actually discharges for an empty difference is *both boundaries coincide* (`start(α) = start(β) ∧ reach(α) = reach(β)`), which gives `⟦α⟧ = ⟦β⟧`. "Both boundaries coincide ⟹ α = β" requires recovering `width(α) = width(β)` from `start(α) ⊕ width(α) = start(β) ⊕ width(β)` with equal starts — i.e. left-cancellation/injectivity of `⊕`, which TumblerAdd does not export. So the three stated triggers are not demonstrably exhaustive: a both-boundaries-coincide pair that is not known to satisfy `α = β` falls under none of the three labels, yet has cardinality 0. A downstream consumer reading "cardinality 0 iff α = β" cannot verify it against the foundation.
**What needs resolving**: State case (a)'s trigger in the same boundary-coincidence vocabulary as cases (b) and (c) — e.g. "0 when both boundaries coincide" (equivalently `⟦α⟧ = ⟦β⟧`) — so the partition is manifestly exhaustive without appeal to an unestablished `⊕`-cancellation property; or, if `α = β` is intended, establish (or cite) `⊕` left-injectivity as the bridge.
