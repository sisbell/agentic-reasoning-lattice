### S11c Case 2 ⊇ direction: mixed strict-nonstrict chain cited to T1 without case analysis
**Class**: REVISE
**Foundation**: T1 (LexicographicOrder) — postcondition (c): `(A a,b,c ∈ T : a < b ∧ b < c : a < c)`; abbreviation `a ≤ b ≡ a < b ∨ a = b`
**ASN**: S11c (DifferenceOverlap), Case 2 ⊇ direction — *"The Case 2 hypothesis supplies start(α) < reach(β), so the chain start(α) < reach(β) ≤ t composes transitively (T1) to start(α) < t"*
**Issue**: T1 exports only strict-strict transitivity (postcondition (c): `a < b ∧ b < c → a < c`). The cited chain `start(α) < reach(β) ≤ t` is a mixed strict-nonstrict composition, which T1 does not export. Grounding it requires expanding `reach(β) ≤ t` via the ≤-abbreviation into `reach(β) < t ∨ reach(β) = t`, then handling each branch (T1(c) in the strict branch; substitution in the equality branch) to conclude `start(α) < t`. SC's formal contract is explicit: "Neither composition is a T1 export; each is derived in the proof by case analysis on the abbreviation." The ⊆ direction of Case 2 follows this discipline precisely (it expands `start(α) ≤ t` and handles both branches). The ⊇ direction omits the case analysis in both the proof body and the Depends section, which describes the step only as "composes the Case 2 hypothesis start(α) < reach(β) with reach(β) ≤ t" without the case split.
**What needs resolving**: The ⊇ direction must supply the missing case analysis: expand `reach(β) ≤ t` into `reach(β) < t ∨ reach(β) = t`; in the strict branch apply T1(c) to `start(α) < reach(β)` and `reach(β) < t` to obtain `start(α) < t`; in the equality branch substitute `reach(β) = t` into `start(α) < reach(β)` to obtain `start(α) < t`; conclude `start(α) ≤ t` via the ≤-abbreviation. The Depends section's description of the ⊇ direction should likewise spell out the case split, matching the precision of the ⊆ direction's entry.
