### Issue 1: K.δ frame is misdescribed in the `nullified`-monotonicity argument
**ASN-0121, "The answer is forced"**: "Within the ASN-0047 vocabulary the only operation that changes `Σ.L` is K.λ; every other operation frames the link store fixed — K.α writes only `Σ.C`; **K.δ extends `Σ.E`/`Σ.M`/`Σ.C`/`Σ.R`** but never `Σ.L`; K.μ⁺/K.μ⁺_L/K.μ⁻/K.μ~ rewrite only `Σ.M`; K.ρ writes only `Σ.R` — and so each holds `nullified` constant."

**Problem**: Per ASN-0047, K.δ (EntityCreation) has frame `C' = C; L' = L; R' = R`, extending only `Σ.E` and (in the Document case) `dom(M)`. It does **not** extend `Σ.C` (content allocation is K.α) and does **not** extend `Σ.R` (provenance recording is K.ρ). The parenthetical mischaracterizes a foundation operation's frame. The load-bearing conclusion ("each holds `nullified` constant") survives — because the actual requirement is only `L' = L`, which K.δ satisfies, and the structural argument ("`nullified` is a function of `Σ.L` alone") is independently correct — but the enumeration that the ASN explicitly offers "to avoid any gap in a per-operation enumeration" contains a factual error about what K.δ writes.

**Required**: Correct the K.δ description to its actual frame — it extends `Σ.E` and, for documents, `dom(M)`, while framing `Σ.C`, `Σ.L`, and `Σ.R` fixed. The point that matters here is only `L' = L`.
