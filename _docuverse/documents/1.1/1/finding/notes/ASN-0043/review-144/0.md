### Issue 1: The S8a check in the worked example verifies a property S8a does not state
**ASN-0043, Worked Example, S8a check**: "*S8a (VPositionWellFormedness, ASN-0036).* The V-positions of `Σ.M(d)` are `{[1.1], [1.2]}`; each V-position is an element-field tumbler whose subspace component is `1 = s_C`, restricting `Σ.M(d)` to the content subspace's V-position slice. ✓"

**Problem**: S8a (ASN-0036) requires `dom(Σ.M(d)) ⊆ {t : zeros(t) = 0 ∧ #t ≥ 2}` with all components positive. The check verifies none of these three conjuncts. Instead it asserts that the V-positions' first component is `1 = s_C` — a subspace-residence fact that is *not part of S8a* (and that conflates with ASN-0036's `subspace(v) = v₁`). This is a checkmark whose stated justification establishes the wrong claim: the actual S8a conjuncts for `[1,1]` and `[1,2]` (`zeros = 0`, `#v = 2 ≥ 2`, both components `> 0`) are never discharged against the scenario. Standard 2 (no proof by checkmark) and the depth standard (key postconditions must be verified against the concrete state) both require these to be shown, not a different property.

**Required**: Replace the subspace-residence prose with a verification of S8a's conjuncts: `zeros([1,1]) = zeros([1,2]) = 0`, `#[1,1] = #[1,2] = 2 ≥ 2`, and every component of each is positive. If the subspace observation is wanted, attach it to the S8a/D-CTG framing where `V_1(d)` (subspace 1) is the relevant object, not as the S8a justification.
