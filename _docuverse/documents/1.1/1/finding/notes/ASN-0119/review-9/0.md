### Issue 1: Referential-integrity claim contradicts the link-subspace V-positions the ASN accommodates
**ASN-0119, "What is preserved: I-address correspondence"**: "*Referential integrity is preserved — `ran(M'(d)) ⊆ dom(C)` (ASN-0036, **S3**) — because by P1 `ran(M'(d)) = ran(M(d))`, and `ran(M(d)) ⊆ dom(C)` held in the pre-state, so the inclusion is inherited verbatim.*"

**Problem**: The ASN simultaneously asserts that arrangements contain link-subspace V-positions and that `ran(M'(d)) ⊆ dom(C)`. The scope paragraph says the operation "neither names nor rewrites any link-subspace V-position, so a position-permuting transposition never has to honour the placement disciplines that govern where a document's links sit" — this presupposes link-subspace V-positions in `M(d)`, exactly the ASN-0047 link-subspace machinery (CL-OWN/CL-UNIQ, K.μ⁺_L). The imported operation reinforces this: ASN-0084's frame R-FRAME-P/S(a) is written over positions with `subspace(v) ≠ S`. But if `M(d)` carries link-subspace V-positions, their images are link addresses in `dom(L)`, not `dom(C)` (links are stored in `Σ.L`). Then `ran(M(d)) ⊆ dom(C)` does **not** hold in the pre-state, and the cited "verbatim inheritance" fails.

Conversely, if the ASN really means the ASN-0036/0043 model, then L14a (NonTranscludability) forces `M(d)(v) ∉ dom(L)` — there are **no** link-subspace V-positions in `M(d)` — and every remark about "the link subspace carried in the frame" and "any link-subspace V-position" is spurious. The two readings are mutually exclusive and the ASN commits to both.

**Required**: Pick one model and be consistent. If link-subspace V-positions populate `M(d)` (the reading the scope paragraph and ASN-0084's frame require), state referential integrity per-subspace — content positions map to `dom(C)`, link positions map to `dom(L)` — rather than citing plain ASN-0036 S3 with `ran(M'(d)) ⊆ dom(C)`. The range-invariance argument (P1) then discharges the per-subspace form unchanged. If instead the model is strictly ASN-0036/0043 with no arranged link positions, remove the link-subspace-V-position language from the scope and "What is preserved" sections, since L14a forbids them.
