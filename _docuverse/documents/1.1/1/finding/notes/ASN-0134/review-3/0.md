### Issue 1: A multi-type quiescence verdict is not realizable as "one atomic snapshot Observe"
**ASN-0134, §8 / V0 / MIC clause 4**: V0 reads "A verdict obtained by a single Observe is `Q(Σ_r)` for one index `r` ... it is a sound statement about the one state `Σ_r`." §8's soundness condition is "all of the verdict's reads must occur at one index, i.e. the verdict must be one atomic snapshot Observe." MIC clause 4 promises "Each Observe — including each quiescence verdict — is evaluated against a single committed state."

**Problem**: The note's own A1 says "an Observe ... is realized as zero steps; it reads a state and returns" — one read, one index. The inherited operation surface supplies only the *per-type* `Observe_K` (ASN-0086, ASN-0128 D1–D4/BH1–BH4): each call reads one type's active view at its own read index. A quiescence predicate over more than one type or home (the realistic case — `targets_keyed` already joins across Binary types) is therefore *several* zero-step reads at *several* indices. V0's soundness premise ("all reads at one index") is then exactly what is not delivered: by A1, the constituent reads land at distinct indices, and §8's own counterexample ("quantified over a collection of states that never coexisted") applies to the verdict's own evaluation.

MIC clause 4 does not close this. Read against the per-type surface, "each Observe ... against a single committed state" is the *per-call* guarantee A3 already gives for free (every `Observe_K` is a function of its own `Σ_k`); it does not force two `Observe_K` reads of *one verdict* to share an index. The genuine requirement — pin all of a verdict's per-type reads to one committed index — is a *reader-side* atomicity obligation, distinct in kind from clause 2's *writer-side* per-home serialization, and it appears nowhere: no whole-state `Observe` primitive is provided, no composition lemma is proved, no clause imposes it. So V0/M1(a) establish snapshot soundness only for the single-`Observe_K` (single-type) verdict; the multi-type verdict — the one a real quiescence recognizer needs — is asserted ("must be one atomic snapshot Observe") without being shown realizable from the surface the note depends on. This is the §8 headline ("the snapshot is the only honest referent for a verdict"), so the gap sits in the note's core, not in deferred territory.

**Required**: Either (a) add a MIC clause requiring all per-type reads composing one verdict to be evaluated against a single committed index — a reader-side snapshot obligation stated as carefully as clause 2 states writer serialization — and connect it to the inherited `Observe_K` surface; or (b) establish that such a composition is constructible from the surface (e.g., that a reader can pin all sub-reads to one `Σ_r`); or (c) restrict V0's soundness claim to predicates evaluable by a *single* `Observe_K`, and state explicitly that multi-type verdicts require the added reader-snapshot contract. As written, the §4 step/operation seam is mirrored by an unaddressed per-call-read / per-verdict-snapshot seam.
