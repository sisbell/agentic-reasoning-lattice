### Issue 2: §1 equates batch *contiguity* with batch *atomicity*; this is false and contradicts the note's own Open Question
**ASN-0134, §1**: "Batch atomicity, where a layer needs it, is something the layer must construct — by making the batch contiguous, which is a critical section, which is a discipline the substrate neither provides nor forbids."

**Problem**: Making a batch contiguous is, by the note's own W4, a *writer-side* exclusion: a run "occupies a contiguous block of `A_{s_C}(d)` iff no foreign allocation into `(d, s_C)` is interleaved between the run's first and last step." That prevents foreign *steps* from wedging in. It does nothing about *readers*. A reader can `Observe` at any index (A0/A3), including an interior index of a perfectly contiguous run; at `Σ_{i₁+2}` of a 3-atom contiguous run it sees a two-atom prefix. Every `m ≥ 2` batch — contiguous or split — has observable partial states. Contiguity ≠ atomicity; a critical section on `(d, s_C)` (W4) excludes writers, not readers, so it cannot deliver all-or-nothing reader visibility.

This is not a stray imprecision: it contradicts the note's own Open Question, which treats the *same* example — "a definition's content run seen whole" — as needing "the minimal additional contract that makes a multi-step batch appear atomic," i.e. as **unsolved beyond W4**. §1 says W4-style contiguity *constructs* the atomicity; the Open Question says the run's atomicity needs a further contract W4 does not supply. Both sentences are about the content run. They cannot both be right. (§6 is on the correct side — it says the corpus needs "batch *contiguity*," carefully avoiding "atomicity" — which isolates the error to §1.) A5 compounds the confusion by tying partial-effect visibility to *splitting* ("If a batch is split, then ... an Observe ... witnesses a strict, non-empty subset"), which leaves the false impression that a *non-split* (contiguous) batch is not partially observable.

**Required**: Correct §1 to state that a critical section yields *contiguity* (no foreign step interleaves the run), not *atomicity* (no reader observes a partial run); atomicity is strictly stronger and is — correctly — deferred to Open Question 3. The deferral itself is fine; only the §1 claim that contiguity already constructs atomicity must go. While there, sharpen A5: partial-batch visibility holds for *any* multi-step batch independent of splitting (an `Observe` at any interior index suffices); splitting *additionally* interleaves foreign effects.
