### Issue 1: S2 functionality — disjointness argument silently depends on pre-state D-SEQ★
**ASN-0100, §Verifying the Invariants / Arrangement functionality (S2)**: "Left positions have last component `< p_m`; Insertion positions have last component in `{p_m, ..., p_m + n − 1}`. ... *Left ∩ Shifted-right = ∅.* Left last components are `< p_m`; Shifted-right last components are `≥ p_m + n ≥ p_m + 1`."

**Problem**: The claim "Left positions have last component `< p_m`" is *not* valid from the region definition alone. Left is `{v ∈ dom(M(d)) : subspace(v) = s_C ∧ v < p}`. Without the sequential-prefix structure, a position `v < p` can have last component `≥ p_m` (e.g. `m_C = 3`, `v = [s_C, 1, 3] < p = [s_C, 2, 1]` via T1 at position 2, yet `v`'s last component 3 exceeds `p_m = 1`). The last-component comparison is only sound because pre-state D-SEQ★ forces every content position into the shared prefix `[s_C, 1, …, 1]`, under which `v < p ⟺` last component `< p_m`. The S2 proof never cites this — it is the load-bearing premise of the whole disjointness argument, and it is left implicit. (§Sequential text-subspace structure, which appears *later*, does explicitly invoke pre-state D-SEQ★ for the same structure — confirming the dependency exists and is simply uncited at the S2 site.)

**Required**: Either cite pre-state D-SEQ★ (and D-CTG-depth for `m_C ≥ 3`) at the S2 disjointness step to establish that all content positions share the prefix `[s_C, 1, …, 1]`, or replace the last-component argument with the order-based one that needs no prefix assumption: Insertion positions are `≥ p` (shift(p,0)=p; TS4 for k≥1), Left positions are `< p`, so Left ∩ Insertion = ∅ by trichotomy; and Shifted-right images exceed Insertion images by TS5/TS1 (`shift(v,n) ≥ shift(p,n) > shift(p,n−1)`).
