### Issue 4: PC6's converse discharges registry-lookup leaves "by admission," but no registry-reading atom is admitted
**ASN-0129, PC6 (converse)**: "The remaining leaves — domain memberships, registry lookups, V-PRIM primitives — are vocabulary by admission, so every syntax-directed evaluation normalizes into the grammar."
**Problem**: Registry lookups are not vocabulary. No PL atom returns registry data — `shape(K)`, the behavior set, or registration status; the only registry read PL contains is the QD base `Reg` (plus the per-K *existence* of template families, fixed at construction). The correct discharge for a registry-lookup leaf is not admission but R1 constant-folding: the lookup is state-constant, so the computation containing it is extensionally equal to one with the value inlined — a V-PRIM constant, a statically taken branch, or a `Reg` expansion. The proof omits this step and instead asserts an admission the vocabulary section never makes. The same looseness recurs in PD0's step-constants list ("registry lookups (R1)"), which names a term form PL does not contain.
**Required**: State the constant-folding clause for registry-lookup leaves explicitly (the cheap fix), or admit a registry-reading atom and account for it in the "exactly four admissions" bookkeeping. Align PD0's step-constant list with whichever is chosen.
