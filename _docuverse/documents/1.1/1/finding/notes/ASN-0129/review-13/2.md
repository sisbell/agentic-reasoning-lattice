### Issue 3: `is_doc`'s upstream grounding misstates the foundation contracts it cites
**ASN-0129, PC5**: "`is_doc` is a single membership check — the residence test the emit surface itself performs at every gated call (I1/I5, ASN-0128)." **ASN-0129, QD-audit**: "the emit surface's own gating clause (I1/I5, ASN-0128) — the one store-domain test the upstream contracts themselves perform."
**Problem**: Two precision failures against the cited foundation. (a) I1 makes home validation *branch-local*: "On a hit, `d` is not read at all: the call is admitted and answered with the existing address whatever `d` holds." An `idem = ⊤` hit is a gate-passing call (the gate is evaluated first, per I1's Order clause) on which the residence test is never performed — so "at every gated call" is false; the correct statement is "on every miss (I1) and on every `idem = ⊥` call (I5)" (and on every `Nullify_Binary` call, where S3 evaluates P0 on both branches). (b) "The one store-domain test the upstream contracts themselves perform" is falsified by `Nullify_Binary`'s P-tgt — `a ∈ A_rel^Σ`, i.e. membership in `dom(Σ.L)`, "enforced as rejecting preconditions at this surface" (S3) — a checked store-domain test on the link store. The claim survives only if silently scoped to the arrangement store.
**Required**: Reword PC5's parenthetical to match I1/I5's branch structure, and scope QD-audit's clause to "the one *arrangement-store*-domain test" (or otherwise acknowledge P-tgt's `dom(Σ.L)` membership check).
