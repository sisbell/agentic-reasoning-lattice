### Issue 1: at-least-one tacitly assumes a lower bound on zeros(t) and compresses the case chain
**ASN-0045, Well-Definedness, *At-least-one***: "Applied successively — no natural strictly between 0 and 1, between 1 and 2, between 2 and 3 — discreteness leaves exactly the four numerals 0, 1, 2, 3 in the interval `{n ∈ ℕ : n ≤ 3}`."

**Problem**: NAT-discrete (ASN-0034) is `m ≤ n < m + 1 ⟹ n = m` — its hypothesis requires the *lower* bound `m ≤ n`. To conclude `zeros(t) = 0` from the first step you must already have `0 ≤ zeros(t)`, and to walk the chain you need `0 ≤ zeros(t)` as the anchor. None of the cited NAT axioms delivers "0 is the least natural" / `0 ≤ n for all n ∈ ℕ`: NAT-order gives only trichotomy/transitivity/irreflexivity, NAT-wellorder asserts a least element exists without identifying it as 0, NAT-closure makes 0 the additive identity but not the minimum, and NAT-addcompat is silent on it. So `{n ∈ ℕ : n ≤ 3}` is bounded above but not below by the cited material, and the collapse to `{0,1,2,3}` is not discharged. The bound `≤ 3` alone, even with discreteness, does not exclude naturals "below 0" unless 0 is established as the floor — which is exactly the structural fact the ASN elsewhere insists must be cited (cf. its own ℚ≥0 caution).

Separately, "applied successively … leaves exactly the four numerals" asserts the conclusion rather than showing the case argument. The actual derivation is a four-way split (`0 ≤ n < 1`, then `1 ≤ n < 2`, then `2 ≤ n < 3`, then `n = 3`), each step invoking discreteness on a stated hypothesis. This is precisely the kind of multi-step argument the ASN's own at-most-one section spells out in full; at-least-one should match that standard.

**Required**: Either cite a foundation fact establishing `0 ≤ zeros(t)` (or that 0 = min ℕ), or justify `0 ≤ zeros(t)` from zeros(t) being a cardinality and state that justification. Then exhibit the actual successive-discreteness case chain anchored at 0, rather than asserting the result.
