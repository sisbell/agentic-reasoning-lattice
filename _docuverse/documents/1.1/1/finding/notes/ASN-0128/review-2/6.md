### Issue 7: `chain()`'s termination bound quantifies over an infinite vertex set
**ASN-0128, Behaviors (B2)**: "vertices are addresses" … "Termination: the sequence is injective into the denoted graph's finite vertex set, so `t = |vertices| − (n + 1)` is a decreasing bound."
**Problem**: With "vertices are addresses," the vertex set is all of `T` — infinite — and `|vertices|` is meaningless. The finiteness claim in the text ("the graph is finite — L-fin bounds the edges") is about edges; the termination argument needs the *vertex* set pinned, and the set actually in play is the denoted endpoints of active edges plus the start address (which may carry no edge yet still heads a chain of length one).
**Required**: Define the denoted graph's vertex set as the finite set of endpoints of its edges, note that `chain(addr)` prepends `addr`, and restate the decreasing bound over that set.
