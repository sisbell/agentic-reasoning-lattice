### Issue 1: Worked example claims an incorrect denotation for `⟦σ_A⟧`
**ASN-0071, "A worked scenario", Resolution paragraph**: "The span denotes `⟦σ_A⟧ = {v_A}` (one position)."

**Problem**: This is false. The denotation of `σ_A = (v_A, δ(1, 2))` is, by ASN-0053, the half-open interval

  `⟦σ_A⟧ = {t ∈ T : [s_C, 1] ≤ t < [s_C, 2]}`

which is infinite. By T1 case (ii), every `t` of the form `[s_C, 1, x₁, ..., x_m]` (any depth ≥ 3, any non-negative components) exceeds `[s_C, 1]`; by T1 case (i) at position 2, every such `t` is less than `[s_C, 2]`. So `[s_C, 1, 0]`, `[s_C, 1, 1]`, `[s_C, 1, 5, 3]`, ... are all in `⟦σ_A⟧`. The depth-2 tumblers in `⟦σ_A⟧` are exactly `{[s_C, 1]}`, but `⟦⋅⟧` is not depth-restricted.

The subsequent computation `iaddrs_one(d_A, σ_A)(Σ) = { M(d_A)(v) : v ∈ {v_A} ∩ dom(M(d_A)) } = { a₁ }` then substitutes `{v_A}` for `⟦σ_A⟧` and so propagates the same error — the substitution happens to land on the right answer only because `dom(M(d_A)) = {v_A}` filters out everything else.

**Required**: State the denotation correctly and let the intersection do the filtering. For example: "Although `⟦σ_A⟧` is an infinite subset of `T` (every tumbler of the form `[s_C, 1, ...]` lies in the half-open interval), the intersection `⟦σ_A⟧ ∩ dom(M(d_A)) = {v_A}` since `dom(M(d_A)) = {v_A}`. Hence `iaddrs_one(d_A, σ_A)(Σ) = { M(d_A)(v_A) } = { a₁ }`." This both fixes the claim and makes the worked example a genuine demonstration of the silent-filtering property F-FILT, which is one of the operation's load-bearing design choices.
