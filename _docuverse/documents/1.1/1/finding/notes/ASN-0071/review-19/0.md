### Issue 1: PrefixConfinement (C0a) invoked outside its stated preconditions
**ASN-0071, "The query" (cross-depth discrimination) and "Resolution"**: "With the action point pinned at `u`'s *own deepest* component `#u`, C0a (PrefixConfinement) gives that every `t ∈ ⟦σ⟧` agrees with `u` on all components `1 ≤ j < #u`" — and earlier "by C0a (PrefixConfinement) every `t ∈ ⟦σ⟧` then agrees with `u` on all components `1 ≤ j < #u`".

**Problem**: ASN-0058's C0a is stated *"For a well-formed content reference `(d_s, σ)` with `σ = (u, ℓ)` and `m ≥ 2`"*, where `m` is `d_s`'s common subspace depth and well-formedness requires `{v : u ≤ v < reach(σ) ∧ #v = m} ⊆ dom(M(d_s))`. But the vspec is *defined* as the relaxation that "drops all three" — including well-formedness — and the cross-depth case explicitly exhibits `#u = 2 < m = 3`, where C0a's `m`-indexed conclusion is not the same statement as the `#u`-indexed one the ASN needs. C0a literally cannot be invoked here: its precondition (well-formedness, `#u = m`) is the very thing the vspec discards. This is load-bearing — the entire "subtree-capture vs sibling-sweep" discrimination, the principled justification that `actionPoint(ℓ) = #u` forbids over-collection, rests on this prefix-confinement claim.

**Required**: Prove prefix confinement directly rather than citing C0a. The position-1 argument already given in the Resolution section generalizes by induction: for `j < actionPoint(ℓ) = #u`, TumblerAdd's prefix-copy gives `(u ⊕ ℓ)_j = u_j`, so `u` and `u ⊕ ℓ` agree on positions `1..#u−1`; an induction using T1 trichotomy (identical to the `j = 1` base case) then forces every `t ∈ ⟦σ⟧` to agree with `u` on `1 ≤ j < #u`. State this as the lemma the ASN needs (it holds *without* well-formedness), and stop attributing it to C0a, whose hypotheses the vspec deliberately removes.
