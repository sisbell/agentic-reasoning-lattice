### Issue 2: "sole abstract respect in which the two identity keys differ" overstates, and is duplicated
**ASN-0108, W6 body and claims table**: "Allocation-monotonicity is therefore the **sole** abstract respect in which the two identity keys differ"; table: "for the matched-content key this is the **sole** abstract respect in which it differs from the link-address key (the comparison's home)."
**Problem**: (a) The note's own composite-key caution contradicts "sole": "the bare content key is **not injective on `Match`** ... it must be composed with a permanent tiebreaker — `κ(a) = (endpoint-boundary, a)`." The address key satisfies W0/W1 unaided; the matched-content key requires an appended address tiebreaker to order `Match` at all. That augmentation requirement is a *second* abstract respect in which the two keys differ, so "sole" is overstated. (b) The exhaustiveness claim is stated in the body and re-stated in the table — duplication. (c) The table parenthetical "(the comparison's home)" is meta-commentary about argument location occupying a structural slot.
**Required**: Either narrow the claim (e.g., "their only *behavioral* divergence on W5/W8/W6 is allocation-monotonicity; the matched-content key additionally requires the address tiebreaker to satisfy W0/W1") or reconcile it explicitly with the tiebreaker requirement. State it once; drop "(the comparison's home)" from the table.
