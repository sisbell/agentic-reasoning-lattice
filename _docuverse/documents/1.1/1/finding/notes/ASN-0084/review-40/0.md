### Issue 1: CS3 necessity counterexample uses cuts that violate CS2
**ASN-0084, Sufficient Precondition section, "A second counterexample (R-PRE(iii) — CS3 violation)"**: "Take the 3-cut sequence C = ([1, 2], [2, 1], [1, 5])... CS2 (strict tumbler ordering [1, 2] < [2, 1] < [1, 5]): satisfied under T1's lexicographic strict ordering on tumblers, since the subspace coordinate dominates."

**Problem**: Under T1 lexicographic ordering, [2, 1] > [1, 5], not <. Compare first components: 2 > 1, so the subspace coordinate dominates *against* the claim. The cut sequence violates CS2 (c₁ > c₂), so the sketch fails to isolate CS3 as the unique R-PRE failure — the example simultaneously fails CS2 and CS3. The "subspace coordinate dominates" remark is correct in principle but is applied with the inequality going the wrong direction.

**Required**: Either (a) substitute a cut sequence that genuinely satisfies CS2 while violating CS3, e.g., C = ([1, 2], [1, 5], [2, 1]) where subspaces 1, 1, 2 give strictly increasing tumblers under T1; then re-derive the argument structure (the R-PRE(iv) ill-typing and frame-condition collision arguments need to be redone for the new positions); or (b) restructure the sketch to acknowledge that CS3 is *presupposed* by R-PRE(iv) and R-PRE(v) — without CS3, the operational machinery (single-subspace ordinal arithmetic, region width computation, R-PRE(iv)'s "the subspace S of the cuts" quantifier) is ill-typed rather than producing a false postcondition, so CS3 cannot be falsified by a postcondition counterexample in the same operational sense as CS2 or CS3-adjacent conjuncts.
