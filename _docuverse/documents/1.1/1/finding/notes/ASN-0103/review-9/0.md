### Issue 1: Strict-advance-over-versions proof relies on an unstated membership step
**ASN-0103, Effect One, "Strict advance over every prior address under A"**: "A version `v` extends some document `d_i = [A, 0, i] ∈ D_A` as a prefix, and `d_i ≤ d_prev = [A, 0, p−1]`, so `i ≤ p − 1 < p`."

**Problem**: This sentence carries the entire `d > v` (cross-allocator) conclusion of CND.monotone, but two load-bearing facts are asserted, not derived:

1. *That `v`'s relevant prefix is exactly `[A, 0, i]`* — i.e. `v_{#A+1} = 0` and `v_{#A+2} = i ≥ 1`. This is true (`A ≼ v`, and the version chain inherits the document's positions `#A+1, #A+2` via TA5(b) at each `k=1` step), but it is never shown.

2. *That this `d_i = [A, 0, i]` is in `D_A`* — equivalently, in `E`. The inequality `i ≤ p − 1` is obtained from `d_i ≤ max(D_A)`, which presupposes `d_i ∈ D_A`. The justification is that `v` could only have been baptised by a `K.δ` `k=1` chain rooted at a document `d_src ∈ E_doc`, with `d_src` permanent by P1 — but this chain-roots-in-`E`-and-stays argument is exactly what guarantees no version can carry a counter `i ≥ p` (which would otherwise require an absent document `[A,0,i]` with `i ≥ p`, contradicting `max(D_A) = p−1`). The proof stands or falls on this, yet it is left implicit behind "`∈ D_A`."

**Required**: Make the inference explicit — state that any `v` with `A ≼ v` and `#v > #A+2` has the form `[A, 0, i, …]` (positions `#A+1, #A+2` inherited as `0, i` through the `k=1` fork chain, TA5(b)/K.δ-ID), and that its root document `[A, 0, i]` is in `E` (hence `D_A`) by entity permanence P1, since each `k=1` fork required its operand `∈ E_doc`. Only then does `i ≤ max(D_A)`'s counter `= p−1 < p` follow.
