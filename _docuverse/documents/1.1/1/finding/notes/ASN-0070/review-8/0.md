### Issue 1: F-canonical clause (i) — start positivity justification is overstated
**ASN-0070, "Canonical Form" section, Definition (CanonicalForm) clause (i)**: "The start positivity is forced by the postcondition equality `⟦Σ_V^S⟧_V = R(d, e)|_S`: by T12(b), `s ∈ ⟦σ⟧`, and by the V-restricted denotation's positivity clause, `s ∈ ⟦σ⟧_V` only when `s` itself is positive; `R(d, e)|_S ⊆ dom(M(d))` contains only positive-component tumblers by S8a, so the equality cannot hold with a zero-component start."

**Problem**: The conclusion "the equality cannot hold with a zero-component start" is false as a logical claim. Two component spans with different starts and widths can yield the same V-restricted denotation. Concretely, σ = ([1, 0], δ(3, 2)) has `⟦σ⟧` = {[1, 0], [1, 1], [1, 2]} (plus deeper-depth tumblers), so `⟦σ⟧_V` = {[1, 1], [1, 2]} after the positivity filter excludes [1, 0]. The canonical σ' = ([1, 1], δ(2, 2)) has the same `⟦σ'⟧_V` = {[1, 1], [1, 2]}. The postcondition equality holds for σ — it's just not canonical. The chain "s ∈ ⟦σ⟧, s ∈ ⟦σ⟧_V only when s positive, ⟦σ⟧_V positive" does not establish that *every* element of ⟦σ⟧_V matching R(d, e)|_S forces s positive; it only shows s ∉ ⟦σ⟧_V when s has a zero component, which is compatible with the equality.

The actual role of positivity is to pin s = min(⟦σ⟧_V) so that (s, c) is uniquely recoverable from ⟦σ⟧_V — a uniqueness convention internal to canonical form, not a forced consequence of the postcondition. Step 2's bridge argument and F-empty's representational conclusion both depend on this convention; without it, multiple (s, ℓ) pairs would witness the same V-restricted point set and the "unique reconstruction" of Step 2 would fail.

**Required**: Replace the "forced by the postcondition equality / cannot hold with a zero-component start" framing with the actual justification: positivity is a canonical-form convention that makes s = min(⟦σ⟧_V), ensures s ∈ ⟦σ⟧_V, and uniquely pins (s, c) under the Step 2 maximal-run argument. State this before the Step 2 bridge that relies on it.
