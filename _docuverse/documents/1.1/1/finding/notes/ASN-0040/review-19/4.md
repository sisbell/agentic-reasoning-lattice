### Issue 5: T5 cited under non-canonical name
**ASN-0040, "The sibling stream"**: "lies within the set {t ∈ T : p ≼ t}, which forms a contiguous interval under T1 by T5 (PrefixContiguity)."

**Problem**: The foundation lists T5 as `ContiguousSubtrees`. The ASN cites it as `PrefixContiguity`. This is a naming inconsistency with the foundation registry.

**Required**: Use the canonical name `T5 (ContiguousSubtrees)` per the foundation, or — if `PrefixContiguity` is intended as a clearer alias — note this explicitly at first use.
