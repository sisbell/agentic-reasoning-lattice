### Issue 3: B0a "produced by baptism" predicate informally defined
**ASN-0040, B0a (Baptismal Closure)**: "`(A t : t ∈ Σ'.B \ Σ.B : t was produced by baptism(p, d) for some (p, d) satisfying B6)`".

**Problem**: The predicate "t was produced by baptism(p, d)" is not formally defined. It refers to provenance — which operation produced an element — but the state Σ does not track provenance, so this predicate has no state-level interpretation. In a closed transition system where Bop is the only operation that modifies Σ.B, B0a is automatic; if the system admits other operations, B0a constrains them. The ASN doesn't make this distinction.

**Required**: Recast B0a as a constraint on the operation vocabulary: "The only state transition that increases Σ.B is Bop, and Bop's preconditions require B6(p, d)." This converts a meta-level predicate into an operation-set axiom that future ASNs can verify when adding operations. Or define provenance explicitly as a state component.
