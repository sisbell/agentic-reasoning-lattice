### Issue 1: V8c states the correspondence set over (d_src, d_new), but V8 establishes it over (d_op, d_new)
**ASN-0069, §"Structural Correspondence", V8c**: "The corresponding-position set `{v ∈ T : v ∈ dom(M'(d_src)) ∩ dom(M'(d_new)) ∧ M'(d_src)(v) = M'(d_new)(v)}` ... V8 records a relationship between two documents in `E_doc`; it does not distinguish 'source' from 'fork.'"

**Problem**: V8 itself is carefully stated over the *content source operand* `d_op`: "For every `v ∈ V_{s_C}(d_op)`: ... `M'(d_op)(v) = M'(d_new)(v)`." The accompanying prose makes the distinction explicit — "on a subsequent fork it is correspondence between the prior version `d_op` and the fork." On a subsequent fork `d_op = d_prev ≠ d_src`, and V8 does **not** establish `M'(d_src)(v) = M'(d_new)(v)` (that would require `M(d_src) = M(d_prev)` on the inherited positions, which need not hold). Yet V8c — introduced as "an immediate corollary" of V8 — writes the corresponding-position set with `d_src`/`d_new`. As written, V8c overclaims: the set it names is established by V8 only on first forks. The symmetry observation (`∩` and `=` are symmetric) is correct for whatever pair V8 records, but the pair on a subsequent fork is `(d_op, d_new)`, not `(d_src, d_new)`.

The same imprecision appears in V8's heading, "*corollary of V4 + source frame*": the frame the derivation actually invokes is `M'(d_op) = M(d_op)` (the operand frame, since "the K.μ⁺ phase targets only `d_new`, and `d_op ≠ d_new`"), not a frame on `d_src`.

**Required**: State V8c's corresponding-position set over `d_op` (`{v : v ∈ dom(M'(d_op)) ∩ dom(M'(d_new)) ∧ M'(d_op)(v) = M'(d_new)(v)}`), so that the corollary faithfully tracks the pair V8 establishes on both first and subsequent forks; and correct V8's heading from "source frame" to the operand/content-source frame. Every other use of the `d_op` vs `d_src` distinction in the note (V4, V8 body, V11, V12(d), the worked example's V12(d) instantiation `(aᵢ, d_op²)`) is threaded correctly — V8c and the V8 heading are the lone slips.
