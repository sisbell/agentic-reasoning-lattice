## Issue 1: One bolded claim is false as stated; RE-RET's "sole exception" understates its assumptions
Reason: Whether the reviser may declare the unit-depth retraction discipline a *faithful* standing assumption — rather than concede the broader model legitimately admits wide retraction-typed links (a genuine limitation, not a stipulation) — turns on whether retraction was designed as a strictly single-target operation with its type reserved for the withdrawal mechanism. The ASN imports ASN-0086's `Nullify` (unit-depth) but does not settle whether the retraction *type* can be applied to arbitrary links, so this is a design-intent question.
Nelson question: Was link retraction (withdrawal) intended as a strictly single-target operation — each retraction nullifying exactly the one named link, with the retraction type reserved for that withdrawal mechanism — so that a retraction-typed link can never carry a wide to-set spanning a range of link addresses?
