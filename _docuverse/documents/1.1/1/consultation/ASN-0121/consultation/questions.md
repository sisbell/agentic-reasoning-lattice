# Sub-Questions — FINDLINKSFROMTOTHREE Operation

**Inquiry:** What happens when the system is asked which links match a description given as four sets — a home-set bounding where the links reside, a from-set bounding what their first endset references, a to-set bounding what their second endset references, and a third-set bounding their type or connector endset? What is returned and how must each returned link relate to all four criteria together, what relationship must the result bear to the link store as it stands at the moment of inquiry and to the union of all documents' arrangements that could surface the same links, what does combining four independent slot criteria (rather than a single content-region filter) reveal about typed and directional link navigation and about the difference between a connection's residence and its endpoints, and what invariants must the operation maintain about completeness, soundness, stability under content edits and link retraction, and the cross-document reach of the discovery?

1. [theory] When a link is requested by four bounding sets at once, what must the system guarantee about how each returned link satisfies all four criteria together rather than any one alone?
2. [theory] What is the design difference between the set that bounds where a link resides and the sets that bound what its endpoints reference, and why must residence be treated separately from endpoints?
3. [theory] What must the system guarantee about the connector or type criterion as a first-class slot, so that links can be discovered by their kind of connection and not only by what they join?
4. [theory] How does bounding a link's first endpoint separately from its second endpoint preserve the directional nature of a connection during discovery?
5. [theory] What completeness guarantee must hold so that every link meeting all four criteria is returned, with none silently omitted?
6. [theory] What soundness guarantee must hold so that no returned link fails any of the four criteria?
7. [theory] What relationship must the returned set bear to the body of links as it stands at the exact moment the inquiry is made?
8. [theory] Must the discovery reach across all documents whose arrangements could surface the same links, and what guarantee covers that cross-document scope?
9. [theory] If linked content is later edited, what must remain stable about which links this inquiry would have returned, and what is permitted to change?
10. [theory] When a link is retracted, what must the system guarantee about its absence from any subsequent answer to the same four-set inquiry?
11. [evidence] When FINDLINKSFROMTOTHREE is given all four bounding sets, must each returned link's source endset overlap the from-set AND its target endset overlap the to-set AND its type endset overlap the third-set simultaneously (conjunctive intersection), or are the slots matched disjunctively?
12. [evidence] Given EC-FIND-LINKS-GLOBAL — that `sporglset2linkset` overrides the orgl filter with `TRUE||!homeset` and a hardcoded width of 100 — does the home-set criterion actually constrain which links are returned, or is it silently ignored so the search is always global?
13. [evidence] How does the operation convert each of the from-set, to-set, and third-set V-spans into I-address spans before searching the spanfilade, and does it walk each document's POOM independently to resolve them?
14. [evidence] When matching the third-set (type/connector endset), does the search compare against the link's type endset I-addresses stored in the spanfilade, or against the registered type namespace at `1.0.2.x` — and does an empty third-set act as a wildcard matching any connector?
15. [evidence] If a slot's bounding set is left empty or unconstrained, does that slot match all links (wildcard), match no links, or short-circuit the conjunction?
16. [evidence] Does the operation distinguish directionality — i.e., would a link whose source references the to-set content and whose target references the from-set content be excluded because the from/to slots are matched positionally rather than symmetrically?
17. [evidence] Since a link's residence (its home document's link-subspace POOM entry at `2.N`) is separate from its endset I-addresses, can a link be returned even when its home orgl is no longer in any open document's POOM, as long as its endset I-spans match?
18. [evidence] Given FC-SPANFILADE-MONOTONIC and EC-STALE-SPANFILADE, will FINDLINKSFROMTOTHREE return a link whose matching endset content has been DELETEd from every document's POOM, since no `deletespanf` removes the DOCISPAN entries?
19. [evidence] Does the operation guarantee completeness — that every link whose three endsets jointly fall within the four criteria is returned regardless of which document originally created it — and is this realized as a pure I-address set intersection over the spanfilade?
20. [evidence] If the from-set, to-set, or third-set content is transcluded (COPY) into additional documents after link creation, does FINDLINKSFROMTOTHREE surface the same links through the newly shared I-addresses, and is the returned set stable under REARRANGE that preserves those I-addresses?
