### S7a/S7 body prose asserts type-incorrect `dom(A_element) ⊆ 𝒯`, contradicting the corrected per-claim contracts
**Class**: REVISE
**Foundation**: T10a (AllocatorDiscipline) — `𝒯` is *the set of allocators*; `dom(A) = {tₙ : n ≥ 0}` is a set of *tumbler addresses*. T10a.4 — quantified over allocators `A ∈ 𝒯` and domain elements `t ∈ dom(A)`.
**ASN**: The body (Structural attribution section) states S7a as: *"Consequently every `a ∈ dom(Σ.C)` satisfies `a ∈ dom(A_element) ⊆ 𝒯` for a T10a-conforming element allocator `A_element`… This membership is the premise that … licenses T10a.4's preservation invariant to be instantiated at `a`."* The body S7 proof repeats it: *"instantiating it at `A := A_element` and `t := a` — legitimate precisely because S7a places `a ∈ dom(A_element) ⊆ 𝒯` — yields that `a` is T4-valid."* The per-claim contracts at the end have been corrected to: *"two memberships of distinct types — `A_element ∈ 𝒯`, the element allocator being a node of the tree, and `a ∈ dom(A_element)`, the address lying in that node's domain … to be instantiated at `A := A_element, t := a`."*
**Issue**: `dom(A_element) ⊆ 𝒯` is a type error: it places a set of addresses inside the set of allocators, and (read as the standard `x ∈ A ⊆ B` chain) implies `a ∈ 𝒯` — an address that is an allocator. T10a.4's instantiation at `A := A_element` requires `A_element ∈ 𝒯`; the malformed chain never establishes that, so the body's discharge of the `A`-side instantiation is ungrounded (the body even says "instantiated at `a`" only, dropping `A := A_element`). The body is internally inconsistent too — it calls `A_element` "a node of the global allocator tree 𝒯" (i.e. `A_element ∈ 𝒯`) one clause before mis-stating the membership. This is body/contract divergence: the per-claim slots were repaired to the two-membership form, the body prose was left stale.
**What needs resolving**: Replace both body occurrences of `a ∈ dom(A_element) ⊆ 𝒯` (and "This membership is the premise … instantiated at `a`") with the two distinct-type memberships `A_element ∈ 𝒯 ∧ a ∈ dom(A_element)` and the full instantiation `A := A_element, t := a`, matching the per-claim S7a and S7 contracts.
